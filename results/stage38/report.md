# ステージ38: 遷移を分けた分析と、重みの作用点の拡大

全表は `results.md`(指標・順位相関・科目別・数値条件)、`bs/bs.md`(BS 表)、`real_transitions.md`(B.4)。
設計の決定と判定基準は `criteria.md`(**結果を見る前にコミット 1a6477b**)。
スクリプト: `real_transitions_stage38.py`、`make_class1_folds_stage38.py`、`run_generation_stage38.py`、
`evaluate_stage38.py`。ステージ37 は指示の途中で中断されたので実施していない。

**結論: 段階分割は採用しない。重みの作用点の拡大も採用しない。** 判定の要点は次のとおり。

- T2(class 1 → class 0 を class 1 で学習)は、向きの一致を −0.114 から +0.037 に有意に改善した。
  ただし 13 項目の違反が出た(5 社)。
- T1 と連結(T1 → T2)は、向きの一致を改善しなかった。
- 連結は違反が多い(資本金の半減、残余科目の負)。

## 1. A.2 実装の方法と理由

- **スペックの 2 つの方法は数学的に同一**である。方法 1 の W_z = BᵀWB による損失 eᵀW_z e と、方法 2 の
  ‖W^{1/2}B e‖² は、どちらも eᵀBᵀWBe に等しい(B の列の正規直交性にもよらない)。
- 損失 eᵀMe(M = Bᵀdiag(w)B)として 1 通りだけ実装した(`train_fm(loss_metric=...)`)。
  w は重みを平均 1 に正規化したもの。
- テストで 2 つを確かめた: 2 つの式が一致すること、M = I なら従来の学習と一致すること。
- **重みの版は持続性ベース**(`costs_persistence.yaml`)。スペックに指定がないので、生成の前に選んで記録した。
  理由: 全 32 科目に値がある、増減で対称なので速度場の W が一意に決まる、ステージ36 で大きさの一致が最も
  高かった。

## 2. B.4 実データでの仮説の検証(生成の前に実施、`real_transitions.md`)

1 年の遷移を使った(2 年の遷移は T1 が 3 社しかないため)。T1 は 9 組、T2 は 68 組。

| 科目(中央値 / 減った組 / 増えた組) | T1: class 2 → 1(9 組) | T2: class 1 → 0(68 組) |
|---|---|---|
| 有形固定資産 | +0.000 / 44% / 56% | −0.003 / **59%** / 40% |
| 投資その他の資産 | −0.000 / 44% / 44% | +0.006 / 28% / 72% |
| 現金預金 | **+0.054 / 22% / 78%** | +0.006 / 47% / 53% |
| 短期借入金 | +0.005 / 22% / **67%** | 0 / 49% / 32% |
| 長期借入金 | **−0.076 / 78%** / 22% | −0.004 / 60% / 21% |
| 利益剰余金 | +0.030 / 33% / 67% | **+0.041 / 12% / 88%** |
| 資本剰余金 | +0.029 / 0% / **67%** | 0 / 21% / 31% |

**仮説は一部だけ支持された。**

- T1 は「資金繰り」(長期借入金の返済・借り換え、短期借入金と現金の増加、増資)の段階だが、
  **資産売却の兆候はない**(有形固定資産・投資は中立)。
- T2 は「利益蓄積」(利益剰余金が 88% で増加)の段階だが、**設備は回復せず、むしろ減る**(59%)。
- T1 は 9 組しかなく、特徴づけは粗い。段階分割の根拠は弱い。その旨を記録したうえで生成した。

## 3. B.3 生成と実データの比較(設定 1 = 輸送等重み・射影一様・速度場一様)

| 遷移 | 符号付き順位相関 [95%] | 基準(単一遷移) | 差 [95%] | 符号が一致した科目 |
|---|---|---|---|---:|
| T1(55 社、実データ 9 組) | +0.128 [+0.080, +0.221] | +0.145 | −0.016 [−0.126, +0.074] | 12 / 32 |
| **T2(131 社、実データ 68 組)** | **+0.037** [+0.003, +0.095] | −0.114 | **+0.151 [+0.116, +0.210]** | 12 / 32 |
| 連結(55 社、実データ 回復 15 社の 2 年) | +0.272 [+0.204, +0.349] | +0.322 | −0.050 [−0.208, +0.045] | 14 / 32 |

基準は、同じ企業の単一遷移の生成を、同じ実データと比べた値である。T1・連結は最終設定(class 2 → class 0)、
T2 はステージ36 の class 1 始点(class 2 で学習)。

- **T2 だけ有意に改善した**(−0.114 → +0.037)。class 1 を始点・学習に使うと、向きの負の相関は消える。
  ただし、正の一致(+0.04)とまでは言えない。
- T1 と連結は、単一遷移と差がない。T1 の実データは 9 組で、参照値そのものが粗い。
- **有形固定資産と短期借入金の向きは、段階に分けても変わらない。** 有形固定資産は T1 +0.030、T2 +0.015
  で増加し、実際は T1 で中立・T2 で減少する。短期借入金は T1 −0.055、T2 −0.031 で減少し、実際は T1 で
  増加する。目標を class 1 にしても、「設備を増やし短期借入を返す」形は残った。

生成の特徴(設定 1):

- T1 で動く科目の上位は、利益剰余金、資本剰余金、資本金、投資その他の資産、短期借入金。
  **払込資本を減らして利益剰余金を増やす振替**の形で、実際の T1(増資で資本剰余金が増える)と逆である。
- T2 でも、利益剰余金・資本剰余金・短期借入金・資本金・長期借入金が上位。

## 6. D.1・D.2 判定(`criteria.md` の基準)

### D.1 段階分割の採否(設定 1)

| # | 基準 | 結果 | 判定 |
|---|---|---|---|
| 1 | 13 項目の違反 0 | T1: 0。**T2: 13 行(5 社、チェック 5「負債が 2 倍超」)**。**連結: 132 行**(チェック 8「資本金が半減以下」51、チェック 10「残余科目が負」110、チェック 5 が 1) | × |
| 2 | 符号付き順位相関が両遷移で改善 | T2 は改善(+0.151)、T1 は改善せず(−0.016) | × |
| 3 | 連結が単一遷移より劣らない | 純資産の改善は良い(+0.056 [+0.019, +0.077])が、\|総資産変化\| が悪い(+0.036 [+0.019, +0.057])。sparsity・proximity も悪い | × |
| 4 | B.4 の仮説が実データで支持 | 一部のみ(資産売却・設備回復は支持されない) | × |

**段階分割は採用しない。**

- T2 の違反 5 社は、負債が総資産の 4〜9% しかない創薬ベンチャー(キャンバス、メドレックス、メディネット、
  窪田製薬、モダリス)で、負債が 2〜19 倍に増えた。class 2 で学習した速度場(ステージ34)では 0 だった。
- 連結の違反は設計の帰結である。
  - α = 0.5 を段階ごとに課すと、資本金は元の 25% まで下がりうる(`criteria.md` に予想として記録していた)。
  - T1 の終点が残余科目の下限に張り付くため、T2 では下限を始点の値まで緩める必要があった
    (855 行中 273 行)。
  - 連結を使うなら、α と残余科目の下限を元の始点に対して課す設計が必要になる。

### D.2 重みの作用点の採否

**採用しない。** 両遷移で一貫して優れる設定がない(§4)。T2 で優れた設定 2・3 は、T1 で純資産の改善が
有意に悪化し、T2 自体でも違反が増える。

## 8. 想定と違った点

- **T2 で学習すると、向きの負の相関は消えた**(−0.114 → +0.037)。ただし正の一致とまでは言えず、違反も出た。
- **目標を class 1 にしても、有形固定資産を増やし短期借入金を減らす向きは変わらなかった。** 向きの不一致の
  原因は、目標が健全企業であることだけではない。
- T1 の生成は払込資本 → 利益剰余金の振替の形になった。実際の T1 は増資(資本剰余金の増加)だった。
- T1 の対応先は 131 社中 38 社に集中した(最多はキャンバスの 6 回)。
- 連結では、段階ごとの制約(α、残余科目の下限)が累積し、元の始点に対する違反になった。
- 実データの T1 は 9 組しかなく、段階の特徴づけと向きの参照値のどちらも粗い。
- 重みの効果は、ステージ36 と同じく遷移(始点の集団)によって逆転した。
