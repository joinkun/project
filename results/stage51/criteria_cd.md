## 2. 基底(C.1)

- **K = 31**: U = null(Cᵀ) の正規直交基底(`orthonormal_basis`)。C の完全 SVD で、rank を超える左特異ベクトルを取る。
  - 検査済み: max\|CᵀU\| = 5.0e−16、max\|UᵀU − I\| = 1.6e−15。
  - C は 32 × 1(貸借一致だけ。小計を含まない状態ベクトル)。
- **K = 13**: 現行の PCA(null(Cᵀ) 内の非中心化 SVD の上位 13。fold ごとに class 0 + 訓練の class 2 で作る。class 1 の生成は全 class 2 で作る)。

## 3. Flow Matching(C.2)

- **ネットワークは現行と同じ(隠れ層 128 × 3 層、50 epoch、学習率も同じ)**。
  - 理由: 入力が 13 → 31 次元に増えてもパラメータ数の増加は小さい(第 1 層だけ)。同じ網にすれば、K の効果だけを比べられる。
  - 網の規模を変えると、変える要素が増える。
- **訓練損失と検証損失**を fold ごと・epoch ごとに記録する(`--loss-log`)。報告する量:
  - 検証損失の最小 / 訓練損失の最小
  - 検証損失が最小になる epoch
  - 50 epoch 目の検証損失 / 検証損失の最小
- 「過学習の兆候」= 50 epoch 目の検証損失が最小の 1.5 倍を超える fold がある。これは報告だけで、判定には使わない。

## 4. 密度の推定(D.1、sklearn のプロセス)

- **データ**: 除外後の class 0(3,768 書類)の z = Bᵀx̃。
  - K = 13 は基底の文脈ごと(fold 0〜4 と全体の 6 つ)に推定する。
  - K = 31 は 1 つ。
- **手法 1**: ガウス混合(`sklearn.mixture.GaussianMixture`、全共分散、reg_covar = 1e-6、n_init = 3、最大反復 1,000)。
  - 成分数 1〜10 から BIC で選ぶ。
  - 乱数は 0・1・2 の 3 通りで当てはめる。目標の計算には seed 0 の当てはめを使う。
  - K = 13 の fold の文脈には、全体の文脈で選んだ成分数を使う(fold ごとに成分数を変えない)。
- **「推定できた」の判定**(全体の文脈で、次のすべてを満たす):
  1. 選んだ成分数の当てはめが、3 つの乱数すべてで収束する(`converged_`)。
  2. BIC で選ぶ成分数が、3 つの乱数で一致する。
  3. class 0 の 5 分割の交差検証で、選んだ成分数の検証対数尤度の平均が、1 成分(単一の正規)より大きい。すべての分割で有限である。
  4. 最小の成分の重みが 1% 以上(約 38 社以上)。退化した細い成分が目標を吸い寄せるのを避けるため。
- **手法 1 で満たさない場合**:
  - 手法 2(因子分析の混合: 因子 5 個 + 対角。numpy の EM で実装)を試し、同じ判定を当てる。
  - 手法 3(正規化流)は提案だけにする。
  - どれも満たさない次元では、密度モデルの設定を実施しない(K = 31 なら設定 4 を省く)。

## 5. 目標の設定(D.2・D.3、torch/cvxpy のプロセス)

始点 i(class 2、57 社)ごとに次を解く:

  x*_i = argmax_{x ∈ C_i} [ log q(Bᵀx) − λ d(x_i, x) ]

- **d**(等重みの二乗距離): d(x_i, x) = Σ_a (x_a − x_ia)²。和は非操作 3 科目(利益剰余金、その他有価証券評価差額金、非支配株主持分)を除く 29 科目にとる。現行の `nearest_na0` の距離と同じ。
- **C_i**: 最終設定 `s47_final` の射影と同じ実行可能集合。
  - 貸借一致、符号、2 科目の固定、不活性制約(規則 M)
  - 第 2 層: 小計の非負、純資産の非悪化、残余の下限、控除後純額の非負、β、γ、α、自己株式の上限
  - **目標そのものが制約を満たす**。x_i 自身が C_i に入るので、解は必ず存在する。
- **解き方**(D.3 の案 3、スペックの優先):
  - ガウス混合の成分 k ごとに凸 QP を解く: min ½(Bᵀx − μ_k)ᵀΣ_k⁻¹(Bᵀx − μ_k) + λ d(x_i, x)  s.t. x ∈ C_i。
  - 成分ごとの値 log π_k + log N(Bᵀx_k; μ_k, Σ_k) − λ d(x_i, x_k) が最大の成分の解を目標とする。
  - これは log q(log-sum-exp)そのものではなく、成分ごとの最大による下界の最大化である。採った目標の log q も報告する。
  - ソルバは cvxpy(OSQP、最適でなければ CLARABEL)。最適でなければ例外にする。
- **λ のスケール**:
  - s = 中央値_i [ (log q(Bᵀy_nn(i)) − log q(Bᵀx_i)) / d(x_i, y_nn(i)) ]。y_nn は現行の等重み最近傍の対応先(全体の文脈、K ごと)。
  - つまり「現行の対応先へ移ることが、密度の利得と距離でちょうど釣り合う交換比率」。
  - 中央値が正でなければ、絶対値の中央値を使う。
- **λ の候補**: λ = c · s、c ∈ {0.1, 0.5, 1, 5, 10}。全体の文脈で 5 つすべての目標を計算し、トレードオフ曲線を描く(c ごとの d の中央値と log q の中央値)。
- **λ の選び方**: d(x_i, x*_i) の中央値が、現行の最近傍の d(x_i, y_nn(i)) の中央値に対数で最も近い c を採る(K ごとに別に選ぶ)。
  - 「現行と同じくらい遠い目標のうち、密度の高い点」にするため。
  - 選んだ c で、fold の文脈の目標を計算する。
- **Flow Matching への接続**: z0 = Bᵀx̃_i、z1 = Bᵀx̃*_i の固定の対で学習する(輸送計画は単位行列)。
  - 検証損失は、テスト側の始点とその目標の対で測る。
  - class 1 の生成は、全体の文脈の目標(57 社)で学習した速度場を当てる(現行と同じ構造)。
  - 他は最終設定のまま。
