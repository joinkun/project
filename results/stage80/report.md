## 4. 定式化(論文の 3・4 章用、実装と一致するものだけ)

### 4.1 コスト A1(移動量 ÷ 区間面積)と命題 3

記号: 向き ± に動いた企業の規格化した幅 Z = |Δ_a| / (|x_{0,a}| + σ_a)、その経験分布関数 F±、中央値 m±、動いた割合 P± = n±/N。

  c_a^{A1,±} = min( 1 / (P_a^± W_a^±), 10³ )、 W_a^± = ∫_0^{m_a^±} (1 − F_a^±(t)) dt = E[min(Z, m_a^±)]

- **解釈**: 区間 [0, m] には、動いた企業の質量 1/2 がある。その生存面積(滞在時間)は W なので、区間の一定のハザードは h = (1/2)/W。したがって c = 2h/P で、**コストは区間のハザードに比例する**(指示文の「ハザードの逆数」ではない)。
- **命題 3(指数分布の下での比)**:
  - 条件付きの幅が指数分布 Z ~ Exp(θ) なら、m = θ ln 2、W = θ(1 − e^{−m/θ}) = θ/2。
  - よって c^{A1}/c^{R1} = m/W = 2 ln 2 ≈ 1.386(R1 = 1/(P · median Z))。この比は全科目・両方向で共通なので、輸送(中央値で正規化)と QP(s で尺度をそろえる)の結果に効かない。
  - 実測の比は中央値 1.43(四分位 1.36〜1.54)、log の相関は 0.997。A1 と R1 の違いは、分布の形が指数分布から外れる分だけである。
- R1 は (n/N) × 中央値の頑健版で、最尤推定ではない(ステージ78 の訂正)。モデル A(増加分・減少分が独立な指数分布)の最尤推定そのものは R3(規格化した変化の標本平均)。
- **A2(2 区間)**: 大きい区間の傾き c₂ = 1/(P · E[(Z − m)₊])。
  - 52 方向中 37 方向で c₂ < c₁(凹)になった。裾が重い(ステージ49、Subbotin の b < 1)ためである。
  - D1 で R1・F1 より劣った(class 2 の純資産の改善 −0.040)。

### 4.2 スパース OT(2 次正則化の片側不均衡 OT)

行で正規化した p_ij = n0 P_ij について:

  min_{p_i ∈ Δ_{n1}} Σ_ij p_ij C̃_ij + (γ'/2) Σ_ij p_ij² + (τ'/2) Σ_j (r_j − 1)²、 r_j = (n1/n0) Σ_i p_ij

- 同一企業の組は p = 0 に固定する。
- **KKT 条件**: 行 i の制約 Σ_j p_ij = 1 の乗数を α_i、列の罰則の勾配を g_j = τ' (n1/n0)(r_j − 1) とすると、最適解は次の形になる。

  p_ij* = [α_i − C̃_ij − g_j]₊ / γ'

  - α_i は Σ_j p_ij* = 1 で一意に決まる(単体への射影のしきい値)。
  - 実効コスト C̃_ij + g_j が α_i 以上の候補では、**厳密に p_ij* = 0** になる。候補の集合 S(i) = {j : p_ij* > 0} は最適解の性質として決まり、事後のカットオフは要らない。
- **ただし、候補の数は γ'・τ' で決まる。** カットオフの代わりに、これらのハイパーパラメータを決める必要がある。
  - 本研究では、τ' を「1 社の全質量を 1 つの対応先が受ける負荷で KL と勾配が等しい値」(ステージ79 §7)、γ' = 0.1 を「実効サポート 3.5〜5 の目安に全 fold で入る値」(本ステージ、事後)とした。
- **列の罰則を KL にすると、スパースにならない**: 空の列で勾配が −∞ なので、すべての列に質量が載り、各行は約 n1/n0 社に散る(命題 1 と同じ構造)。
- 解法: 行ごとの単体への厳密な射影をもつ加速射影勾配法と、勾配による再始動(`src/fsgen/models/sparse_transport.py`)。収束しなければ例外を出す。

## 5. 論文に書くべき注意

1. A1・SP-F1 の採用は、D1 の事前の規則を満たした結果ではなく、ステージ79 の結果を見たあとの選択である。
   - 事前の規則を満たしたのは R1・F1(ステージ75)と A1・F1(ステージ79・80)。
   - A1・SP-F1 は class 1 でステージ69 より優れることを示せていない(条件 3)。
2. A1・SP-F1 の利点は次の 3 つで、主指標の優位ではない。
   - 候補をカットオフなしで決められる。
   - 実効サポート 4〜5 で違反 0。
   - R1・F1 と主指標が同等。
3. γ' = 0.1 は事後に選んだ。主指標の結果は γ' に鈍い(γ' = 10⁻⁴ との差は小さい)。
4. 終点は健全企業と見分けられる(AUC 0.95)。苦境の確率の中央値は大きく下がるが、健全企業の中央値以下まで届く終点は 4%(class 2)。
5. 回復率の単調減少は、合算の 1 年の推移に限る。

## 6. 想定と違った点

1. γ' を上げても、条件 3(class 1)は満たされなかった。原因は fold f2(λ̃ = 3)と、区間の境界の小さな差である。
2. A1・F1(カットオフあり)が、ステージ79 に続いて全条件を満たす唯一の設定だった。
3. 生成の移動は、実際の回復より短い(MDS 上で約 0.7 倍)。
