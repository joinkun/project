# ステージ66: 定式化の全面改訂

**結論: 3 つの期待は、どれも期待どおりには働かなかった。提案(設定 4)は現行(設定 1)より主指標が劣り、採用しない。最終設定はステージ65 のまま。**

1. **頻度加重で、資本金の c−/c+ は 1 を超えない**(正規化 0.36 → 0.24、名目 0.20 → 0.29)。
   - 再建企業では、資本金の(比の)減少は増加より多く、大きいので、頻度を掛けると減らすコストはさらに安くなる。
   - 指示文の基準で、**原因 1 の診断は外れている**(実装前の A.1 で確認し、`criteria.md` に記録した)。
   - 生成では、頻度加重で純資産の改善が有意に下がった(class 2 で −0.148、class 1 で −0.035)。
2. **階層分離で、払込資本を増やす企業は増えなかった**(class 2: 5% → 5%、class 1: 2% → 2%。実データは 57% / 25%)。
   - 払込資本を減らす企業は 0% になり、払込資本は単に動かなくなった。
   - **原因(確認済み)**: 利益剰余金に移動コストがない(非操作科目、c = 0)ので、純資産の改善はほぼすべて利益剰余金で行われる。改善に占める利益剰余金の割合は、中央値で 1.00。
   - 払込資本が動くのは、利益剰余金が上限 γ に当たる企業(2 / 55 社)だけである。
3. **Elastic-Net は、変更された科目数を 2 → 3〜4 にしただけ**(実データ 14〜16)。純資産の改善はわずかに改善した(+0.026 / +0.039、有意)。
   - 現金が下限に張り付いた企業は、すべての設定で 0 社だった(現金の下限 β_cash が全設定に入っているため)。Elastic-Net が現金の端点解を消すかは、この比較では判定できない。
4. **1 段階統合(設定 5)は、設定 4 よりわずかに劣った**(純資産の改善 −0.023 / −0.010)。
   - 選んだ λ̃ = 10 では、K = 50 で枝刈りが完結した(追加の QP は 0)。λ̃ が小さいと下界が緩く、class 2 で 1 社あたり最大 66 個の追加の QP が要った。
5. **λ を class 1 だけで較正すると、ステージ65 の class 2 の結果は変わる。**
   - ステージ65 では class 2 を class 2 で較正し(λ̃ = 0.1)、払込資本↓ 38%(実データ 36%)だった。class 1 の λ を当てはめると 5% になる。
   - **ステージ65 の「実データと区別できない」は、class 2 を見て λ を選んだ結果だった。**

規則・決定(A_BS、w_NA、η = 1.0、K = 50、ε_σ = 1e-3、λ の較正)は、`criteria.md` に実装・生成の前に記録した(コミット cf01e56)。

## D.6 C.3: 3 つの効果の確認

| 変更 | 期待 | 結果 | 判定 |
|---|---|---|---|
| 階層分離 | 払込資本を増やす企業が増える(実データ 57% / 25%) | 5% → 5%、2% → 2%(変化なし)。減らす企業が 0% になる | **不成立** |
| 頻度加重 | 減資のコストが増資より高くなる | 資本金の c−/c+ = 0.24(< 1)。純資産の改善も下がる | **不成立**(実装前に判明) |
| Elastic-Net | 現金の端点解が消え、変更科目数が 14〜16 に回復 | 変更科目数 2 → 3〜4。現金の端点解は、全設定で現金の下限が塞いでいる(0 社) | **不成立**(科目数)/ 判定できない(現金) |

**階層分離が効かない理由(診断)**:
- 純資産の改善に占める利益剰余金の変化の割合は、中央値で 1.00 だった(設定 4・設定 1、両 class)。
- 利益剰余金は非操作科目で、移動コストがない(c = 0)。そのため、NA の目標に近づける最も安い方法は、つねに利益剰余金を動かすことになる。
- 払込資本は、利益剰余金が上限 γ = 0.757 に当たった企業(設定 4 で 2 / 55・2 / 132 社)でしか動かない。
- 実データの再建企業が増資するのを再現するには、利益剰余金の増加(利益)にもコストか上限が要る。これは設計の判断で、本ステージの範囲外である。

## D.7 想定と違った点

1. 頻度加重は、資本金の向きを反転させなかった(実装前に判明)。再建企業では、資本金の比は減少のほうが頻繁で大きい。
2. 階層分離は、払込資本を「動かす」のではなく「動かさない」方向に働いた。利益剰余金が無料の調整弁になっているため。
3. Elastic-Net の L2 の部分は、変更された科目数をほとんど増やさなかった(2 → 3〜4)。λ̃ が 10 と大きく、移動全体が抑えられているため。
4. class 1 だけで λ を較正すると、λ̃ は 10 になり(設定 3〜5)、再建の度合いが下がった。違反 0 の制約が λ を押し上げる(λ̃ ≤ 3 では class 1 に違反が 1〜4 社)。
5. ステージ65 の class 2 の「実データとの一致」は、class 2 で較正した λ に依存していた。class 1 の λ を当てはめると、払込資本↓ は 38% → 5% になる。
