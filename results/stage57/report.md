## 結論

1. **採用しない。最終設定(等重み・K = 13・n = 1)を変えない。**
   - 再建群の重みの 4 版(方向なし・方向別 × K = 13・31)は、どれも両 class で基準を満たさない。
   - 3d(方向別・K = 13)は class 1 でだけ満たす(純資産の改善 +、順位相関 +)。これまでと同じ「class 1 だけ」の型である。
2. **再建群の重みは、払込資本の減少の頻度を実データに近づけない。むしろ遠ざける。**
   - 払込資本を減らす企業: class 2 で 82%(現行)→ 91〜100%、実データは 36%。
   - class 1 で縮んだのは 3d だけ(84% → 77%、実データ 23%)。
   - **重みでも頻度は変えられない**(スペック G の「構造的な限界」に当たる)。
3. **K = 31 は、重みによらず純資産の改善を下げる**(等重みで −0.051、再建群の重みで −0.048(class 2))。交互作用は小さい。PCA の有無の効果は、重みとほぼ独立である。
4. **刻みを細かくしても改善しない。**
   - n = 4・20・100 は、純資産の改善が有意にわずかに下がる(class 2 −0.003〜−0.004、class 1 −0.006〜−0.007)。
   - 計算時間は n に比例する(class 1 で 4.8 秒 → 210 秒)。n = 1 のまま。
5. **スペックの前提で、事実と違った点が 2 つある**(§0)。

## 0. スペックの前提の訂正

- **現行の刻みは 5 点ではなく 1 ステップ(2 点)**(`_TS = (0.0, 1.0)`、ステージ48)。
  - 5 点は全件出力のための線形補間である。
  - 刻みの比較は、n = 1(現行)・4・20・100 で行った。
  - 現行の「毎ステップ射影」は、射影した点を ODE に戻さない(各点を独立に射影する)。そのため刻みが変えるのは、射影前の経路の積分の精度だけである。
- **ステージ55 の学習された重みとは逆向きにならず、同じ向きだった**(順位相関 **+0.52**、p = 0.004)。
  - ステージ55 は、よく動く科目(現金・借入金・有形固定資産・払込資本)の重みを 0 にした。本ステージも、同じ科目の重みが最小(現金と同じ 1 前後)になる。
  - 「よく動く科目ほど重みを小さく」は、ステージ55 と同じ方向である。スペックの「正反対」は成り立たない。
  - 違いは程度で、ステージ55 は 0、本ステージは等重みと同じ 1 前後に残し、動かない科目の重みを最大 100 倍に上げた。

| 刻み | 純資産の改善(class 2 / class 1、差) | 変動係数(射影後) | 射影による移動(中央値、class 2) | 計算時間(class 2 / class 1、秒) |

- **滑らかさは n で変わらない**: 隣接する変化量の変動係数は 0.067〜0.068(class 1 は 0.037)で一定。射影後の経路は、ほぼ等速である。
- スペックの「変化量の分散」(全体の変化に対する比の分散)は n² に比例して小さくなるだけで、滑らかさの比較には使えない。
- **射影による移動は、n とともに小さくなる**(0.141 → 0.051)。細かく積分した射影前の経路は、実行可能集合に近い。
- しかし終点の主指標は改善しない(純資産の改善がわずかに下がる)。違反は全 n で 0。
- **判定: どの n も基準を満たさないので、n = 1 のまま**(計算量は n に比例)。

## 9. D 判定

- **D.1**: 基準を満たす設定なし。**最終設定を変えない。**
  - 副次的な判断材料 4(実データとの乖離): 縮まない(3d の class 1 を除く)。
  - 副次的な判断材料 5(対応先の払込資本比率): 下がらない(0.888・0.833)。
- **D.2**: K = 31 は、重みによらず純資産の改善を下げる(3 回目の不採用。ステージ44・51・57)。重みの効果は小さい。
- **D.3**: 刻みは n = 1 のまま。

## 10. 想定と違った点

1. **現行の刻みは 1 ステップだった**(スペックの 5 点は補間)。
2. **ステージ55 の重みと逆向きではなかった**(+0.52)。どちらも「よく動く科目を軽く」で、違いは程度だけ。
3. **再建群の重みは、払込資本を減らす企業をむしろ増やす。** 払込資本の重みが現金並みに下がり、対応先との違いが安くなるため。
4. **刻みを細かくすると、射影前の経路は実行可能集合に近づくが、終点はかえってわずかに悪くなる。** 経路の滑らかさは変わらない(射影後は n によらずほぼ等速)。
5. **K = 31 の効果は安定して負**で、重みと独立だった。

## 構造的な限界としての記述(スペック G)

ステージ56(下限)と本ステージ(重み)の両方で、**払込資本を減らす企業の頻度(生成 82〜100%、実データ 23〜36%)は変わらなかった**。頻度は、対応先の選び方の細部ではなく、次の 2 つから来ると考えられる。

- 健全企業の払込資本比率が苦境企業より低いこと(ステージ46)
- 欠損填補の振替を許す構造(R3 + γ)

距離・下限・刻みでは変えられない。
