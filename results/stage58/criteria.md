## 0. スペックへの注意(集計の前に記録)

1. **案 2(主)の「群内」は、ステージ57 の「変化量」とほぼ同じ量である。**
   - 案 2 の σ は再建群の Δx̃ の標準偏差、ステージ57 の m は |Δx/A| の平均で、どちらも「同じ企業が動く幅」の尺度である。
   - 重み 1/σ² は、ステージ57 の重み 1/m の 2 乗に近くなると予想する。
   - そうなら、払込資本の重みはステージ57 より大きくならない(払込資本は再建で大きく動く科目なので、σ が大きい)。
   - **Gnanadesikan et al. (1995) のクラスタ内分散に当たるのは、案 1(class 内)である。** 案 2 は「企業内の時間変化」で、クラスタ構造とは別の量である。
   - スペックに従い案 2 を主とするが、理論の検証(B.4)は案 1 でも報告する。
2. **重みの発散**: 1/σ² は、丸め差の残余(値が総資産比 1e-6 程度)で極端に大きくなる。**上限 100(現金 = 1)** で切る(ステージ57 と同じ)。上限に当たった科目の数を報告する。
3. **C(対数正規の Bregman ダイバージェンス)は、ステージ50 の対数正規版でほぼ試みている。**
   - 対数正規の尤度コストの最近傍で、class 2 の純資産の改善 −0.095・違反 7 で不採用だった。
   - 凸性は射影(二次計画)で必要な性質で、対応先の選択(最近傍)には要らない(ステージ50 の前提)。
   - 対数正規の負の対数尤度は log(ỹ / x̃) について二次で、x̃ については凸でない(ステージ49 D.2: R ≤ e^(μ+1) でだけ凸)。
   - **C は B の結果を見てから判断する**(スペック C.2)。上の事実から、実施しないことを第一の候補とする。
4. **基準の比較相手**: K = 31 で統一するので、基準 1〜3 は**設定 1(等重み・K = 31)**に対して判定する(スペック B.1)。
   - ただし最終設定は K = 13 なので、**最終設定を変えるには、現行(等重み・K = 13)に対しても基準 1〜3 を満たす**ことを要する。
   - 設定 1 にだけ勝つ場合は、「K = 31 の中での改善」として報告する。
5. スペックの「class 2 の払込資本 / 総資産 = 1.14、class 0 = 0.13」は、A で確かめる(1.14 はステージ46 の値。0.13 は未確認)。

## 1. 群の定義と分散(A)

状態は総資産比 x̃(各書類の総資産で割る)。

| 案 | 群 | σ_within の定義 | データ |
|---|---|---|---|
| **2(主)** | 同一企業の年次変化 | 再建群 72 社の 1 年の変化 Δx̃ = x̃_t − x̃_{t−1}(2022→2023、2023→2024 の 144 組)の標準偏差 | 推定用パネル |
| 2r(A.5) | 同上(ロバスト) | 1.4826 × MAD(Δx̃) | 同上 |
| 1 | class 0 / 1 / 2 | class ごとの x̃ の分散を、社数で重み付けて平均した値の平方根(プールしたクラス内分散) | 生成に使う断面(除外後の class 0・1・2) |
| 3 | 業種(33 業種) | 業種ごとの x̃ の分散を、社数で重み付けて平均した値の平方根 | 同じ断面(業種「不明」は除く) |
| 全体 | なし | 同じ断面の x̃ の標準偏差 | 同じ断面 |

- **比**: σ_within / σ_total(案 1・3 は同じ断面なので比が意味を持つ。案 2 は別のデータなので参考)。
- **重み**: w_a = (σ_現金 / σ_a)²、上限 100。非操作 3 科目(利益剰余金・その他有価証券評価差額金・非支配株主持分)は 0(`nearest_na0`)。
- σ_a = 0 の科目は、上限の重みにする。
- 重みの相関(案 1・2・2r・3・全体・ステージ57)を報告する。
- **A.4 の予想**(上記 0.1): 案 2 とステージ57 の順位相関は高く、払込資本(資本金・資本剰余金)の重みはステージ57 より大きくならない。
