# ステージ39 報告: 科目の細分化と最適輸送の再評価

判定の基準は `criteria.md`(持続性・輸送・生成の前に記録、コミット 5e5ae04)。基準は変えていない。
数値の詳細: `dims.md`(A)、`persistence.md`(B)、`results.md`(C・D・E)、`bs.md`(D.3)。

## 結論

- **最終設定は変えない**(core 32 科目・等重み・最近傍、R3 + 上限 γ = 0.757)。
- **細分化(E.1)は不採用**: class 1 では勝つが、class 2 で \|総資産変化\| が有意に悪化し(+0.014 [+0.007, +0.031])、
  優れる指標がない。加えて、BS 表を読むと、細分化した生成は**有形固定資産の残余を負にして土地・建物を
  作り出す**(class 2 の 34〜54% の行。実データは 3.3%)。
- **不均衡 OT(E.2)は不採用**(D = 32・38 とも): 純資産の改善は大きく上がる(class 2 +0.09〜0.10、class 1 +0.15〜0.16)が、
  \|総資産変化\| が両 class で有意に悪化する。13 項目の違反も出る(設定 2 の class 1 で 1 行、設定 4 は各 class 1 行)。
  始点 57 社のうち 8 社を落とし、輸送される質量は 0.17〜0.18。
- **持続性の重み(E.3)は、細分化した空間の最近傍では両 class で勝つ**(設定 5 − 3。基準の上では「採用」)。
  ただし細分化自体が不採用なので、最終設定には入らない。事前に決めていない参考の比較(5 − 1)では、
  class 2 で \|総資産変化\| が有意に悪化し(+0.014)、現行に両 class で勝つとは言えない。OT での重み(6 − 4)は勝たない。

  超えるのは 4,156 書類のうち有形固定資産 5、投資その他 1、固定資産その他 10(最大 0.45、S100TMWI)。
  core の恒等式は成立しており、既存の結果には影響しない。32 科目に集約した実データの参照の差は最大 5.9e-6。

## C. 輸送の方式(`results.md` C.2・C.3、class 2 55 社、等重み)

- **全方式が収束**(バランス OT は周辺分布の誤差 < 1e-6 も検証。ε = 0.01 は 1 回 約 560 秒)。
- バランス OT(ε = 0.01・0.05・0.1): 実効サポート 96〜1,242 社、対応先の総資産は始点の 7.6〜10.6 倍(中央値)。
  \|総資産変化\| が 0.14〜0.16(最近傍 0.044〜0.056)、違反 8〜14 行。ステージ13・14 の結論(総資産の崩壊)を再現した。
- 不均衡 OT: τ = 0.1 は 8 社を落とし、輸送される質量は 0.17〜0.18。τ を上げると脱落は減る(τ = 1 で 3 社、τ = 10 で 1 社)が、
  τ = 10 はバランス OT に近づき \|総資産変化\| が悪化する。τ = 0.1 は純資産の改善が最大(+0.09〜0.10)。
- 片側制約は最近傍に近い(実効サポート 12〜14)。純資産の改善 +0.026〜0.033、\|総資産変化\| の差は有意でない。
- **D の効果は小さい**: 同じ設計で D = 38 − 32 の純資産の改善の差は、すべて区間が 0 を含むか 0.007 以下。
  最近傍の \|総資産変化\| は +0.014 [+0.007, +0.031] 悪化。32 科目に集約した proximity は、バランス OT・片側・τ = 1 で有意にわずかに下がり(−0.004〜−0.030)、他は有意差なし。
- 符号付き順位相関(回復 15 社)は方式によらず +0.23〜+0.40 で、区間が互いに重なる。
- ステージ13 の「−0.028 [−0.049, −0.0002]」は、このマシンに結果がなく確認できない(`criteria.md`)。今回の
  τ = 0.1 − 最近傍は、純資産の改善 +0.097 [+0.075, +0.129]、\|総資産変化\| +0.048 [+0.021, +0.077](D = 32)。

## D.3 BS 表(`bs.md`、設定 5 と 3、seed 0、5 社は乱数で選んだ)

- 細分化の科目は読める(東京ボード工業: 土地 2,763 → 2,909、建物 2,694 → 2,997、機械 798 → 921 百万円)。
- **問題**: 有形固定資産を持たない企業(ANAP、ソフトフロント)で、土地・建物・機械が現れ、有形固定資産の残余が
  負になる(ANAP: 土地 +14、残余 −14 百万円)。東京ボード(30 → −37)、千趣会(81 → −146)も残余が負。
  残余の符号を自由にした(`criteria.md` A、実データの 140 書類のため)ことが、残余を調整弁にしている。

| 集計(3 seed × 企業の行) | class 2 設定 3 | 設定 5 | 設定 4 | 設定 6 | 実データ |
|---|---:|---:|---:|---:|---:|
| 有形固定資産の残余 < −1e-3 × 総資産 | 34% | 40% | 54% | 47% | 3.3%(書類) |
| 土地が 0 から正になる | 47 / 99 | 47 / 99 | 21 / 99 | 30 / 99 | 1 年で 1.9%(class 1+2 は 4 / 215) |

class 1 では残余が負の行は 5%(設定 3)〜44%(設定 4)。13 項目のチェックは、有形固定資産の残余を下限の対象から
外したため、これを検出しない。有形固定資産の残余に下限を課して再生成するかどうかは、事前に決めた設計の変更に
なるので、行っていない。
