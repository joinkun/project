# ステージ52 A: ゼロパターンの集計の定義と判定規則(集計の前に記録)

この時点では、ゼロパターンの集計はまだ行っていない。

## 1. 定義

- **母集団(主)**: 生成で目標の候補に使う class 0。非金融で、ステージ28 の除外(ゴルフ場・金融 4 業種)の後の **3,768 書類**。
  - スペックの 3,951 は、非金融でステージ28 の除外の前の class 0 である。こちらも参考に同じ集計を出す。
  - class 1・2 も同じ除外の後で数える(132・57 書類)。
- **ゼロ**: 総資産比の値がちょうど 0(集計で値が欠けている科目は 0 とみなす。ステージ49・50 と同じ)。
- **科目**: 状態ベクトルの基礎科目 32(主)。
  - 参考として、4 つの丸め差の残余(資産その他、固定資産その他、負債その他、株主資本その他。ステージ49)を除く 28 科目でも出す。
  - 丸め差は「0 か否か」も丸めで決まり、パターンを細かく分けてしまう可能性があるため。
- **パターン**: S_i = {a : x_ia = 0}。

## 2. A.4 の判定規則(スペックのとおり)

- **主の判定(32 科目)**: 上位 10 パターンで **80% 以上**を覆えば「パターン混合が実装可能」。下回れば「パターンが分散している」(科目ごとに独立なゼロ確率)。
- 28 科目での値は参考。判定は 32 科目で行う。
  - 28 科目で判定が変わる場合は、その事実を報告し、B の設計の前にユーザーの判断を仰ぐ。
