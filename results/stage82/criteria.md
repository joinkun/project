## 0. 前提の確認(指示文との違い)

1. **新しい R1 は、ステージ75 の R1 のちょうど ln 2 倍である。**
   - 新しい R1 は θ = (ln 2 / m)/π、ステージ75 の R1 は 1/(π m)。
   - 輸送はコストを中央値で割り、QP は λ = λ̃ × s で尺度をそろえる。したがって、上限 10³ に当たる方向を除いて、結果は同じになる。
2. **`scale`(1/m)は、従来の abs と同じではない。** abs は、規格化しない |Δ| の中央値と n < 5 の代替規則を使っていた。
3. **Tier A / B / C の「2〜3 年・5 年・10 年超」は解釈のラベルで、実際の年数ではない。** 区切りは、実在の再建群の 2 年の移動コストの分位点である。
4. pure_lp は、コストの最小の 1 社(1-NN)を選ぶ。Sinkhorn の argmax(ステージ75)とは違う。

## 1. 基準単価 θ_a^±(5 方式)

- プール: ステージ75 と同じ 57 社。fold f のコストは、57 社から fold f を除いた約 45 社で推定する。
- 記号: z_ka = |Δ_ka| / (|x_{k,0,a}| + σ_a)、π_a^± = n^±/K、m_a^± = 動いた企業の z の中央値。
- θ_max = 10³。n^± = 0 の向きは θ = θ_max。評価差額金は 0(凍結)。利益剰余金は、輸送と QP の移動コストで 0(従来どおり)。

| 方式 | θ_a^± |
|---|---|
| R1 | min((ln 2 / m)/π, θ_max) |
| KDE0 | min(f̂(0)/π, θ_max) |
| IPW | min(1/π, θ_max) |
| scale | min(1/m, θ_max) |
| A1 | min(1/(π ω), θ_max)、ω = mean(min(z, m)) |

**KDE0 の f̂(0)**:

- 鏡像法: f̂(0) = (1/n) Σ_k 2 φ(z_k / h)/h。
- 帯域 h は、鏡像を合わせた 2n 点に対する Silverman の頑健な規則: h = 0.9 min(s, IQR/1.349)(2n)^(−1/5)。
- n < 5、または h = 0 の向きは R1 に戻す。戻した方向の数を報告する。

## 2. 個体別の単価と、不活性科目の扱い

- `indiv_scale = False`: θ_ia^± = θ_a^±。
- `indiv_scale = True`: θ_ia^± = min(θ_a^± / (|x_ia| + σ_a), θ_max)。上限に当たる方向の割合を報告する。
- **A_inact(i)**: 始点で |x_ia| < 10⁻⁶ の科目のうち、次の 15 科目に入るもの。現金・株主資本・残余科目・貸倒引当金は含めない。
  - 非負の資産: 棚卸資産、売上債権、その他流動資産、有形固定資産、無形固定資産、投資その他の資産
  - 非負の負債: 短期借入金、未払法人税等、その他流動負債、仕入債務、未払金、1 年内償還予定社債、長期借入金、社債
  - 非支配株主持分
- `inact_mode`:
  - `base`: 輸送の罰則なし。QP は従来の不活性 4 科目を固定する。
  - `stage1_penalty`: 輸送のコストと QP の両方で、a ∈ A_inact(i) の θ_ia⁺ = θ_max。QP は従来の 4 科目を固定する。
  - `unified_extended`: `stage1_penalty` に加えて、QP で a ∈ A_inact(i) を y_a = 0 に固定する。
- **始点ゼロ科目の発生率**: (企業, a ∈ A_inact(i)) の組のうち、終点で |y_ia| ≥ 10⁻⁶ になった割合(発生)と、|y_ia| ≥ 10⁻³ になった割合(実質的な発生)。

## 4. 制約の 3 階層(Tier 1〜3)

| 階層 | 制約 |
|---|---|
| tier1(会計の定義) | 貸借一致・小計の定義(恒等式)、基礎科目の符号、小計の非負、控除後の純額の非負、残余科目の下限 |
| tier2(法規制) | 自己株式の上限(会社法 461 条の近似)、資本金の下限 α = 0.00199(100% 減資の禁止) |
| tier3(実務) | 営業資産 3 割の保持(β = 0.3)、負債の上限、純資産の非悪化、利益剰余金の増加の上限、現金の下限、不活性の固定、方向制約 |

- 始点が制約を破っている場合の退却位置(下限を min(0, 始点の値) に緩める)は、従来どおり各制約に入る。
- 評価差額金の凍結は、モデルの設計なので全階層で残す。

## 6. 「最良の改訂モデル」(実験 4〜6 の主モデル)の選び方

実験 2 の 6 設定から、次の順に選ぶ。

1. ステージ75 の条件 1(違反 0)・2(ステージ69 より劣らない)・4(実効サポート ≥ 3・AUC・終点のゼロ)を満たす。
2. その中で、実質的な発生率(≥ 10⁻³、両 class の平均)が最も低いもの。
3. 差が 0.5 ポイント以内なら、単純なほうを採る(indiv = False を True より、base → stage1_penalty → unified_extended の順)。
4. 条件を満たすものがなければ、R1(False、base)とする。

- 「R1 か KDE0 か」の推奨: 実験 1 の基準 R1 との比較で、KDE0 がどの class でも「劣る」がなく、どこかで「優れる」なら KDE0、そうでなければ R1(単純なほう)。
