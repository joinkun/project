## 0. 指示文への注意(実行の前に記録)

1. **`asymmetric_ot_targets.py` は、このリポジトリにも履歴にもない。**
   - 代わりに、同じ機能を持つ既存の `src/fsgen/models/transport.py` を土台にする。
   - 対数領域の Sinkhorn(`solve_ot_normalized`)、不均衡 OT(`solve_unbalanced_normalized`)、`check_plan_health`、`effective_support_sizes` がある。
   - 不均衡 OT は今の実装では両側を同じ τ で緩めるので、τ0 = ∞(始点側を厳密に保存)の版を追加する。
2. **n1 = 3,768**(class 0、除外後)で、3,951 ではない。下限は n1 / n0 = 3,768 / 55 = **68.5**(72 ではない)。
   - 指示文のダミーデータの数値(7.6・390.6・9.0、0.00041 対 0.02312)は、このリポジトリにないので確かめられない。
   - §0 の不等式は正しい。行の質量が 1/n0、列の質量が 1/n1 で π_ij ≤ 1/n1 なので、行を正規化した p_ij ≤ n0/n1 となり、1/Σp² ≥ n1/n0 が成り立つ。
3. **τ0 = ∞ の不均衡 OT では、始点の質量が厳密に保存される。**
   - そのため「質量 0 の行」も「輸送質量 < 0.5」も起こりえない(質量は常に 1)。ステージ50 の 0.068 は、両側を緩めた版で起きた。
   - 一方で τ1 → 0 では、目標側の制約が消える。その極限は、始点ごとに独立に exp(−C̃_ij/ε) で重みを付けたもの(片側制約、ステージ13 の `onesided`)になり、ε → 0 で最近傍になる。
   - つまり A は「最近傍」と「バランス OT」の間を τ1 でつなぐもので、局所性を得る設定ほど最近傍に近づく。**B.1 で 3 案について述べられた「群から群への輸送から外れる」点は、A にも当てはまる。**
4. **ステージ59 A' の判断(A'.1 の対処、I_hard)には指示がなかった。** 次のとおり進める。
   - A'.1 の対処は推奨の a(コストはそのまま、資本金は c−/c+ = 0.36)。
   - I_hard は規則どおり(残余科目 3 つ、実質 0 科目)。
5. **QP(ステージ59 §C)は未実装なので、本ステージで実装する。** `project_onto_feasible`(白色化、s47_final の第 2 層制約、方向制約、凍結、不活性制約)に、L1 の移動コストを足す。Flow Matching は使わない。

## 1. 共通の設定

- **始点**:
  - class 2: 55 社(外れ値 2 社を除く)。
  - class 1: 132 社(金融・ゴルフ場を除く)。評価では外れ値 1 社と、再建群 72 社と重なる企業を除く(ステージ58 と同じ)。
- **目標の母集団**: class 0 の 3,768 社(除外後)。
- **コスト**: 非対称 L1、中央値の尺度、ε0 = 0.001(`weights_v2.csv`)。C̃ = C / median(C)。
  - 重みは、class 2 は D_rec 57 社、class 1 は 15 社(class 2 → 回復、**参考値**)から推定したものを使う。
  - 参照用に等重み L2² の最近傍も作る。
- **ε** ∈ {0.005, 0.02, 0.1}(C̃ の単位 = median(C) 倍)。
- **輸送はすべて対数領域で解く。** 未収束、NaN / inf、周辺の誤差 > 1e-6、質量 0 の行は例外にする(握りつぶさない)。
- **目標点**:
  - (a) バリセントリック(行で正規化、**主**)。
  - (b) 最大質量の対応先(参照)。

## 3. 生成(QP)

輸送計画が健全な(§4 の基準 2 を満たす)すべての設定について、各始点の目標点 τ_i で次の QP を解く。

min_y Σ_a w_a (y_a − τ_ia)² + λ Σ_a (c_a⁺ u_a + c_a⁻ v_a)、ただし y − x_i = u − v、u, v ≥ 0。

- 制約は s47_final と同じ:
  - 第 2 層(α・β・γ、自己株式の上限、小計の非負など)
  - 方向制約、非操作科目の凍結(利益剰余金を除く)、不活性制約(規則 M)
- **第 1 項の重み**: w_a = 1 / max(σ_a^pool, 0.001)²。σ_pool は案 1(`pooled_sd_v2.md`)。白色化してから解く。重み比を報告する。
- **λ の決め方**: λ = λ̃ × s。s = median_i [Σ_a w_a (x_ia − τ_ia)² / Σ_a c_a^± |τ_ia − x_ia|] は、第 1 項と第 2 項の大きさをそろえる係数で、設定 0 の目標点で計算して全設定に共通に使う。
  - **主は λ̃ = 1。**
  - λ̃ ∈ {0.01, 0.1, 10, 100} はトレードオフ曲線(設定 0 と各案の代表)として報告する。
- **検証**:
  - ソルバの状態の内訳。
  - min(u_a, v_a) > 1e-9 の件数(0 でなければ例外として報告する)。
  - 独立ソルバ(CLARABEL)による解の一致(ステージ10.6 の方法)。
- 出力は既存の生成と同じ形式(`x0_*`・`x1_*`)にし、`metrics_stage39.py` で指標を計算する。QP は決定的なので seed は 1 つ。

## 4. 採用基準(E.1)

各案(A・B・C)の**代表**を、次の規則で事前に 1 つ決めて判定する。

- **代表**: ε = 0.005、バリセントリックで、§4 の基準 2・3 を満たす中から、最もバランス OT に近いもの。
  - A は最大の τ1、B は最大の n1'(業種層化、seed 0)、C は最小の β。
  - C はさらに、上位 5 社の受取質量 ≤ 50% を満たすこと。
- 該当がなければ、その案は「局所性を回復できない」と判定する。

| # | 基準 |
|---|---|
| 1 | 15 項目の違反 = 0(項目別) |
| 2 | 輸送計画が健全: 収束、有限、質量 0 の行がない、輸送質量 > 0.5 |
| 3 | 実効サポートの中央値 ≤ 20 |
| 4 | 総資産の変化 ΔA/A0 の中央値(企業ごと)が、実データの 2 年の ΔA/A0 の p5〜p95 に入る(class 2 は 15 社、class 1 は 57 社) |
| 5 | 払込資本を減らした企業の割合(名目、年率 (Δ払込資本 / A0) / 5 < −0.001、ステージ56 の定義)が、設定 0 より有意に小さい(企業単位のペアのブートストラップ 2,000 回の 95% 区間が 0 を含まない)。正規化の割合も報告する |
| 6 | 5 が class 1・class 2 の両方で成立 |

- **B の安定性**: 代表の n1' で seed 0〜4 を比べる。次のどちらかなら「抽出に依存する」として不採用にする。
  - 払込資本を減らした割合の範囲が 10 ポイントを超える。
  - 純資産の改善の中央値の範囲が 0.02 を超える。
- **E.2**: 代表のどれかが 1〜6 を満たせば「OT > NN」とする。
  - 1〜6 を満たさないものについては、5 と主指標(純資産の改善・解消率・符号付き順位相関、ステージ51 の有意の定義)で、すべて有意差なしなら「OT ≈ NN」、1 つでも有意に劣れば「OT < NN」とする。
- **E.3**: 1〜6 を満たす案が複数ある場合は、主指標で優劣を付ける。同等なら A を採る。
- **設定 1(バランス OT)** は採用の対象にしない。総資産の変化(ステージ13 の −66% の再現)を報告する。
