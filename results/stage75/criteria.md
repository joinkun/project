## 1. 比率コスト(57 社または fold のプール、`stage75_weights.py`)

記号:

- N = プールの社数。
- Δ_ka = x_{k,2024,a}/A_{k,2024} − x_{k,2022,a}/A_{k,2022}(構成の差、従来と同じ)。
- x_{k,0,a} = x_{k,2022,a}/A_{k,2022}。
- σ_a = max(σ_a^pool, 10⁻³)(`results/stage59/pooled_sd.csv` の `sigma_1`)。
- n_a^± = #{k : ±Δ_ka > 0}。

| コスト | s_a^± | c_a^± |
|---|---|---|
| **abs**(従来) | median{\|Δ_ka\| : ±Δ_ka > 0} | 1/s。n < 5 は n ≥ 5 の全方向の中央値で代替。残余は 10³ で上限 |
| **R1** | (n_a^±/N) · median{\|Δ_ka\| / (\|x_{k,0,a}\| + σ_a) : ±Δ_ka > 0} | min(1/s, 10³) |
| **R2** | (n_a^±/N) · median{\|Δ_ka\| : ±Δ_ka > 0} / σ_a | min(1/s, 10³) |
| **R3** | (1/N) Σ_k (±Δ^nom_ka)_+ / (\|x_{k,0,a}\| + σ_a)。Δ^nom_ka = (X_{k,2024,a} − X_{k,2022,a}) / A_{k,2022}(名目の変化を始点の総資産で割る。変化しない企業は 0 として平均に入る) | min(1/s, 10³) |

- **R1〜R3 では n < 5 の代替をしない**(生起頻度が「まれ」を表すため)。s = 0(その方向に動いた企業がない)は c = 10³。
- 評価差額金は c = 0(凍結)。利益剰余金は、輸送と QP の移動コストで 0(従来と同じ)。
- R3 の Δ^nom は、QP の変数と同じ単位(始点の総資産比)で、総資産の増加による見かけの減少を含まない。
- 診断表(報告 1)には、ステージ74 の対数変化率のコストも並べる(57 社の全体で推定)。

## 2. リークのない評価・較正の設計

**D1(主、5 分割の交差適合)**: 57 社を乱数 0 で 5 分割する(fold f = 0〜4、11〜12 社)。fold ごとに、次のとおり役割を分ける。

- コストの推定: 57 社から fold f を除いた約 45 社。class 1・class 2 の生成の両方に使う。
- 較正の目標 L_f: fold f の 57 社の実データ(払込資本↓・RE↑・総資産の変化、SE はその企業の復元抽出)。
- class 1 の順位相関の参照 ref_f: T2 の組のうち、(T2 ∩ fold f)∪(T2 で 57 社にも 15 社にもない 7 社)。どちらのコストの推定にも入らない企業だけ。T2 の 1 年の遷移の差分の中央値(`metrics_stage39.real_refs` と同じ計算)。
- class 2 の順位相関の参照: 従来どおり Y 群 15 社(57 社と重複 0)。
- λ̃*_f: fold f の class 1 の格子で、違反 0 の中で L_f 最小。同じ λ を class 2 に当てはめる。
- 基準(ステージ69 の設定、λ̃ = 1)も、fold ごとに ref_f と比べる。

**D2(副、役割の分割)**: コスト = 57 社の全体。較正の目標 = class 2 → 回復 15 社の実データ。class 1 の順位相関の参照 = T2 で 57 社にも 15 社にもない 7 社。

## 3. 設定(`stage75_qp.py`)

- コストの種類 {abs, R1, R2, R3} × 目標 {argmax, F1}。
  - argmax は τ1 = 0.05 の計画の最大の候補(S(i) の 1 位)。F1 は τ1 = 0.05 の S(i)(累積 0.9 まで、最大 10 社)の事後アンサンブル。
- その他はステージ74 の A1 と同じ:
  - 新設計(非支配株主持分を動かす、評価差額金だけ凍結)。
  - 𝓕⁺(s47_final + 現金の下限 + 負債の上限、1 − 10⁻⁶ の余裕)。
  - 第 1 項は全 32 科目・m = 10。λ = λ̃ × s(s は F1 の定義、class 1)。
- 輸送計画(片側不均衡 OT、ε = 0.001)は、コストと fold ごとに解き直す。
- D1 は 5 fold × 8 設定、D2 は 8 設定。各 10 点の格子、両 class。

## 4. 指標

- 違反(15 項目)、純資産の改善、解消率、符号付き順位相関、払込資本↓・↑、変更科目数。
- **少額科目の膨張**: 始点で 10⁻⁶ ≤ |x| < 10⁻³ の組のうち、終点で |y| > 10⁻³ の割合。
- F1 の統合した企業数、候補の集合の識別 AUC、終点のゼロ(|y| < 10⁻⁶)。

## 5. 判定(事前、D1 で行う)

**基準との比較**: fold ごとに、企業単位のペア比較(純資産の改善・解消率・順位相関)を行う。設定が基準より、

- 「優れる」: fold 平均の差が正、かつ 5 fold 中 3 fold 以上で 95% 区間が 0 より上。
- 「劣る」: 同様に負の側。

**採用**: 次をすべて満たす設定で、基準(ステージ69 の設定)を置き換える。

1. 全 fold・両 class で違反 0。
2. 両 class で、主指標のどれも「劣る」でない。
3. 両 class で、少なくとも 1 つが「優れる」。
4. F1 の設定は、統合 ≥ 3、候補の集合の AUC ≤ 0.762 / 0.736、終点のゼロ ≥ 6.70。argmax は、目標の AUC が同じ上限以下。いずれも全 fold の中央値で判定する。

- 候補が複数あれば、class 1 の L_f の fold 平均が最小のもの。
- どれも満たさなければ、ステージ69 の設定のまま。
- D2 は参考として報告し、判定には使わない。
