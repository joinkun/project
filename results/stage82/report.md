# ステージ82 報告: 数理モデルの改訂と指導教員の指摘の検証

規則は `criteria.md`(コミット 41cf02a、計算の前に記録)。数値は小数第 3 位、割合は % で小数第 1 位。
D1 = ステージ75 と同じ 5 fold の交差適合(値は fold の平均、V は最大、ESS は中央値)。
記号 = 純資産の改善・解消率・順位相関(+ 優れる、− 劣る、0 差なし)。

## 要約

**推奨する主モデル: R1 + indiv_scale = False + inact_mode = stage1_penalty + 提案の輸送(γ' = 0.1)+ F1、λ̃ = 0.1**(criteria §6 の規則で選択)。

1. **実験 2(最も大きな効果)**: 輸送と QP で、始点ゼロ科目の増加の単価を上限にする(stage1_penalty)。
   - 始点ゼロ科目の実質的な発生率(≥ 10⁻³)は、31.6% / 30.6% → **0.2% / 0.3%**(class 2 / class 1)。
   - 主指標も改善する。base との差は、純資産の改善で +0.016 / +0.008(4 / 5 fold で有意)。
   - **class 1 で、ステージ69 より純資産の改善が有意に優れた**(+0.024、4 fold)。ステージ79・80 で満たせなかった条件 3 を満たす。
   - unified_extended(QP でも固定)は発生率 0.0% だが、主指標は stage1_penalty とほぼ同じ。規則(差 0.5 ポイント以内なら単純なほう)で stage1_penalty を選んだ。
   - indiv_scale = True は、順位相関を上げる(class 2 で 0.427 → 0.526)。一方で λ̃ が大きく選ばれ、空白地帯率が上がる(42.9% → 50.9%)。採らない。
2. **実験 1**: R1・KDE0・A1 は、θ の順位相関が 0.996〜0.998 で、ほぼ同じコストである。
   - 規則上は、KDE0 が R1 より「優れる」(純資産の改善 +0.006 / +0.003、劣る指標なし)。ただし差はごく小さい。
   - KDE0 と stage1_penalty の組み合わせは検証していない。そのため、主モデルは検証済みの R1 のままにすることを勧める。KDE0 にするなら、組み合わせの D1 を追加で回す必要がある。
   - IPW(頻度だけ)は、純資産の改善が R1 より劣る。scale(幅だけ)は、class 1 の順位相関が 0.007 まで落ちる。頻度と幅の両方が要る。
3. **実験 3**: 輸送の方式は、主指標にほとんど影響しない。どの方式も、提案の方式との比較で「優れる・劣る」がない。
   - pure_lp と quad_col_only は、class 2 で違反が 1 社出た。
   - quad_row_only は、候補が 2 社程度に偏る(ESS 2.2〜2.5)。
   - 提案の方式(行と列の両方の罰則)は、違反 0 のまま ESS 4〜5 を保つ。
4. **実験 4**: tier1 だけでは違反 24 / 50 社、tier1+2 では 19 / 49 社、tier1+2+3 で 0 / 0 社。
   - 法規制(tier2)は、自己株式の上限の違反を消す。
   - 残りの違反(不活性科目の移動・純資産の悪化・負債の倍増)は、実務の制約(tier3)が必要。
5. **実験 5**:
   - 滞留群は、回復群に比べて、増資(資本金⁺ 0.13 倍)と利益剰余金の減少(0.05 倍)の単価が大幅に安い。苦境が続く企業は、増資と欠損の拡大を繰り返す。
   - 苦境全体から単価を推定しても、主指標はほぼ同じ(class 2 の純資産の改善 0.432 対 0.416)。
   - Tier A / B / C は、class 2 で 63.6% / 29.1% / 7.3%、class 1 で 89.8% / 10.2% / 0.0%。Tier C(4 社)の中間点の違反は 0。
6. **実験 6**: 主モデルは、5 つの比率をすべて健全企業の IQR の側へ動かす(例: class 2 の自己資本比率の中央値 0.190 → 0.658)。
   - ただし、自己資本比率は健全企業の中央値(0.565)を超え、Q3 も 0.788 で健全企業の Q3(0.711)を上回る(行き過ぎ)。
   - [P10, P90] の適合率は、旧モデル(A1・SP-F1)のほうが高い比率が多い。

**注意**:

- 主モデルの選択は事前の規則による。ただし、unified_extended の固定の値は phase1 の後に変えた(criteria §8、選択には影響しない)。
- P_distress の class 1 は、どの設定も 0.05% 未満で、表では 0.0% と表示される。
- R_void は、共通の尺度 Ψ60 で測っている。
- class 1 の順位相関は fold ごとの参照(17〜19 社)で、検出力が低い。
- 新しい R1 は、ステージ75 の R1 の ln 2 倍で、結果は実質的に同じである(criteria §0)。
- QP の実行不可能は、最終的に全設定で 0(unified_extended の 1 社は、criteria §8 の修正で解消)。ソルバの設定は変えていない(CLARABEL → OSQP → ECOS の代替は、既存の `RecourseQP` のまま)。
