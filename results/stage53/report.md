新しい生成は行っていない。既存の出力を評価した。

- 判定基準: `criteria.md`(評価の前に記録、コミット 8652c26)
  - §5 はゼロの判定の訂正で、評価の後に追記した(後述)。
- 表: `baseline.md`(B.1)、`relations.md`(B.2〜B.5)、`settings.md`(A.3・C)
  - 当初の規則での結果は `raw_snap/`。

## 結論

**PL は採用しない**(主指標にも副指標にもしない)。理由は、事前に決めた優先順の 2 番目「振替で上がる」に当たること。

- **振替だけで PL が上がる**:
  - 純資産を変えず、欠損を資本剰余金・資本金で填補しただけの状態で、ΔPL の中央値は +2.62。50 社中 26 社で上がる(片側 Wilcoxon p = 0.0034)。
  - 利益剰余金を 0 にせず 99% だけ填補すると、中央値 +7.54、35 社で上がる。
  - **validity と同じ問題を持つ。**
- **さらに、事前の基準の外で、指標として不適切な事実が 2 つ見つかった**:
  1. **制約を課す前の出力(違反だらけ)のほうが PL が高い。**
     - 射影前の Flow Matching の出力は、全行が 15 項目のどれかに違反する。それでも終点の PL の中央値は、class 2 で 11.8(最終設定は −3.8)、class 1 で 37.0(17.3)。
     - PL と違反の件数の順位相関は +0.168 で、むしろ正。
     - **PL は会計的な破綻を検出しない。** 制約は、出力を健全企業の密度の低い方へ動かしている。
  2. **終点の PL は、ほぼ始点の PL で決まる**(Spearman ρ = 0.956)。生成の良し悪しより、どの企業から出発したかを測っている。
- **構造上、PL は貸借一致の破れも検出できない**(連続部分は null(Cᵀ) の座標だけを見る。評価の前に `criteria.md` §2 に記録)。

|---|---:|---|---:|

- 順序 class 0 > class 1 > class 2 は成り立つ。学習データと hold-out の差は小さい(31.1 対 30.7)。
- **実際に再建した企業の終点は、class 0 の中央値に届かない**(分位点 24・37)。
  - 生成に class 0 並みの PL(分位点 50)を求めるのは過大である。
- class 1 → class 0 の 57 社は、始点と終点で PL がほとんど変わらない(27.3 → 26.5)。

## 3. B.3 循環性(最終設定、class 2、55 社)

| 量 | 値 |
|---|---:|
| 対応先(実在の class 0 企業)の PL の中央値 | 10.9 |
| 生成の終点の PL の中央値 | −3.8 |
| 始点の PL の中央値 | −13.2 |
| 終点 − 対応先(中央値) | −8.2 |
| Spearman ρ(終点, 対応先) | **+0.792** |
| Spearman ρ(終点, 始点) | **+0.956** |

- 事前の基準(ρ ≥ 0.8)では「循環」に当たらない(境界のすぐ下)。
- 終点は対応先より PL が低い(終点が上回るのは 24 / 55 社)。
- **終点の PL は、対応先よりも始点で決まっている**(ρ = 0.956)。
- 対応先自体も、class 0 の中では密度の低い企業である(中央値 10.9、class 0 全体の 30.7 より低い)。最近傍は、苦境企業に似た、健全企業の中では外れた企業を選んでいる。

## 4. B.4 振替の検出

**主の検定**(事前に決定): class 2 で利益剰余金が負の 50 社について、欠損を資本剰余金、次に資本金(下限 α まで)で填補した状態を会計の操作で作り、PL を比べた。純資産は不変。

- ΔPL の中央値 **+2.62** [−4.23, +61.36]、上がった社 26 / 50、片側 Wilcoxon **p = 0.0034** → **「振替で上がる」に該当**
- 36 社では利益剰余金がちょうど 0 になる。class 0 で利益剰余金が 0 の企業はいないので、離散部分で大きく下がる。
  - 0 にしない(99% だけ填補する)と、中央値 +7.54、上がった社 35 / 50。
  - 振替の効果は、むしろこちらが実態に近い。

**参考**(スペックの方法。他の科目も動くので判定に使わない):

- 生成の出力で純資産がほとんど動かない行(\|ΔNA\| / A < 0.01)の ΔPL は、多くの設定で負だった(R1 で −15.4 など)。
- ステージ29 の R4 γ = 0(振替が主)は −2.0。
- 生成の中では、振替以外の動き(現金・負債の移動)の影響が大きく、振替の効果は分離できない。そのため主の検定を、会計の操作で作った状態にした。

## 7. C.3 第 1 層のみとの比較(射影前の出力で代用)

- 射影前の出力は、恒等式は満たすが、符号・小計・第 2 層の制約を課していない。
  - 全 558 行(class 2・1)が、15 項目のどれかに違反する。
  - 違反は延べ 2,735 件。
- その PL は、どの制約つきの設定より高い(class 1 では分位点 75 で、健全企業の上位 1/4 に入る)。
- 終点の PL と違反の件数の順位相関は **+0.168**(射影前と最終設定をまとめた行)。
- **PL が低いほど違反が多い、という関係はない。** スペックの予想(PL は会計的な破綻を検出する)と逆。
- 考えられる理由(未検証):
  - 版 I の連続部分は正規なので、符号の違反(非負の科目が負)を罰しない。
  - 制約(β・純資産の非悪化・RE の上限など)は、健全企業の典型から外れた方向にも出力を押す。

## 9. 想定と違った点

1. **振替だけで PL が上がる**(validity と同じ問題)。欠損を消すと、BS の構成が健全企業に似るため。
2. **違反だらけの射影前の出力が、最も PL が高い。** 密度は「健全企業らしい数字の組み合わせ」を測るが、「会計的に妥当か」は測らない。両者は別物である。
3. **終点の PL は始点でほぼ決まる**(ρ = 0.956)。企業間の比較には、ΔPL のほうがまだ意味がある。
4. **実際の再建企業も、2 年後に class 0 の中央値に届かない**(分位点 24・37)。
5. **最近傍の対応先は、健全企業の中では密度の低い企業**(PL 10.9 対 class 0 30.7)。
6. **ゼロの判定の規則を、評価の後に訂正した**(`criteria.md` §5)。
   - 記録した規則(\|x\| < 1e-6 を 0)は、「実データにはそうした値がほとんどない」という誤った前提に立っていた。実際は 2,160 社に丸め差の小さな値がある。
   - 実データの基準と評価する点が食い違ったため訂正した。
   - 判定はどちらの規則でも同じ。
7. **スペックの前提(PL は貸借の破れを検出する)は、版 I の構造上成り立たない**(評価の前に記録)。

## 提案

- PL は採用しないが、**ΔPL は「健全企業の分布へ近づいたか」の記述統計として、副指標の表に参考として載せる余地はある**(振替で上がる限界を明記した上で)。主指標・判定には使わない。
- 会計的な妥当性は、引き続き 15 項目のチェック(独立に効くのは 3・4・5)で見る。密度とは別の量として扱う。
