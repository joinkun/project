## 1. A.1・A.3

- **d_a** = |class 2(55 社)の平均 − class 0 の平均|(x̃)。科目ごとに d、d / median(d)(操作できる 29 科目の中央値)、順位を報告する。
- **gapmed**: m_a = d_a / median(d)、[0.01, 100] で切る。非操作 3 科目は 1。class 1 の生成では d を class 1 の平均で計算する(ステージ62 と同じ)。
- 比較は、各設計の違反 0 を制約にした λ̃*_0(ステージ62 §1 の定義)で行う。
- 6 設計(paid3・paid10・paid30・gap・invgap・invrho)と base は、すべて表に出す。

## 2. A.2: class 1 の 2 分割による選択と検証

- **分割**: 評価対象の class 1(128 社)を、乱数(seed 0)で 64 社ずつの A・B に分ける。
- **選択(A で)**: 非対称 L1 の 8 設計(base・6 設計・gapmed)× λ̃ 10 点から、A で違反企業 0 の組のうち L(ステージ61 の定義、実データは 57 社の全体)が最小の (設計, λ̃) を選ぶ。base についても、A で同じ規則で λ̃ を選ぶ。
- **検証(B で)**: 選んだ (設計, λ̃) を B に当てはめ、base(A で選んだ λ̃)と比べる。次をすべて満たせば「検証成立」とする。
  1. B で違反企業 0。
  2. B での L が base より小さい。
  3. 純資産の改善が base より有意に劣らない(企業単位のペアのブートストラップ 2,000 回、中央値の差の 95% 区間)。
- A と B を入れ替えた検証も報告する。
- **安定性**: 乱数を変えた 100 通りの分割で、A で選ばれた設計の頻度と、検証の成立率を報告する。
- class 2(55 社)は分割すると小さすぎるので、分割しない。

## 3. B.3: 現金の下限 β_cash(α と同じ方法)

- **β_cash = 0.11732**(= 推定用パネルの 1 年で、class 1+2 の始点で現金が正、かつ当期末に減った 191 組の、名目の比(当期末 / 前期末)の 1 パーセンタイル)。
  - α(ステージ46)と同じ母集団と分位点である。最小は 0.0921、0 になった組はない。
- **制約**: x_現金(t) ≥ β_cash × x_現金(0)(x0 の現金が正のとき)。第 2 層に加える(`PlausibilityConfig.cash_floor`)。
- **生成**: 非対称 L1 の base・paid10・gap、両 class、λ̃ 10 点。等重み L2 も base で同じ(対照)。
- **報告**:
  - 違反企業数(項目別)、L、純資産の改善。
  - 違反 0 を制約にした λ̃*_0 が、現金の下限のない場合から変わるか。
  - 現金の下限は 15 項目のチェックには加えない。チェック 3(現金 ≈ 0)は、下限があれば始点の現金が 0.001 / 0.117 = 0.0085 未満の企業でしか起きない(半ば循環する)ので、その旨を表に注記する。

## 4. B.4: 他の端点解

- 科目ごとに、「始点 |x0| > 1e-4 で、終点 |x1| < 0.01 |x0|」の企業数を数える。
  - 対象は、3 距離 × 各距離の λ̃*(ステージ61)と、現金の下限つきの非対称 L1。
- 実データ(57 社・15 社の 2 年、名目)で同じ条件を満たす企業数を並べる。
- **判定**: 現金の下限をつけたときに、現金以外の科目で「端点解の企業数」が増えれば、端点解が移ったとする。
  - 実データの頻度を超える科目が 1 つ以上あれば、elastic net 型(L1 + μ L2)の提案を書く(実装はしない)。

## 5. C.1: 検定力(ステージ54 と同じ考え方)

- class 1 の企業から 55 社を復元抽出し(外側 200 回)、各回で企業の復元抽出(内側 400 回)による順位相関の差(非対称 L1 − 等重み L2)の 95% 区間を求める。区間の下限 > 0 の割合を検定力とする。
- 対象は、class 1 で有意だった λ̃(ステージ62 C.1 の元の定義)のすべて。
- 判定(事前): 検定力 ≥ 0.8 なら、class 2 で有意でないのは効果の違い(または class の違い)を示唆する。< 0.8 なら、標本が小さいことで説明できる。
