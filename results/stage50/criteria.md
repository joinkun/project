## 1. コストの定義(A.1〜A.3)

### 1.1 式

科目ごとに −log P(y_a | x_a) を求め、科目について足す。x は始点(class 2)、y は目標(class 0)で、どちらも総資産比。

| 始点 x | 目標 y | c_a |
|---|---|---|
| 非 0 | 同符号の非 0 | −log P(継続 \| x ≠ 0) − log p_a(log(\|y\| / \|x\|)) |
| 非 0 | 逆符号 | −log P(符号反転 \| x ≠ 0) |
| 非 0 | 0 | −log P(消滅 \| x ≠ 0) |
| 0 | 非 0 | −log P(新規計上 \| x = 0) |
| 0 | 0 | −log P(0 のまま \| x = 0) |

コストを科目について足すのは、**科目間の独立を仮定した近似**である(会計恒等式により科目は従属する)。
実装は `src/fsgen/models/likelihood_cost.py`。

### 1.2 スペックからの変更点

- **確率は条件付き**(区分の件数 ÷ 始点の状態の件数)にする。スペックの π(全組に対する割合)を使わない。
  - 最近傍では結果が同じになる。条件付きと同時確率の差は、始点 i と科目 a ごとの定数で、j の選択に影響しない。
  - OT では結果が変わる。G の「log P(y_j | x_i)」は条件付きなので、こちらに合わせた。
- **符号反転の区分を加える**。スペックの 4 区分にはない。利益剰余金・評価差額などで実データの 2〜19% を占める。
- **密度は g = log R の尺度**で評価する(スペックの式のとおり)。
  - y の密度にすると −log\|y\| の項が加わり、保有の小さい目標ほど尤度が高くなる。そのため採らない。
  - したがって、厳密には「log P(y | x)」ではなく、g の尺度での尤度である。
- **ゼロの判定**は、ステージ49 と同じく総資産比がちょうど 0。

### 1.3 クリップ

- π_min = 1 / N、N = 10,971(推定用パネルの組の数)。−log π_min = 9.30。
- 観測 0 件の区分は π_min にする。
  - 例: 現金・投資その他の資産の新規計上(始点 0 の組が 3 件・17 件で、新規計上 0 件)
  - 例: 非負の科目の符号反転
- 始点の状態の観測が 0 件のときは、その状態の区分をすべて π_min にする(目標による差をつけない)。
- 理由: −log 0 = ∞ を避けるため。値はスペックの例のとおり。

### 1.4 自己株式の新規計上(スペックの前提との違い)

スペックは「自己株式の新規計上は実データで 0 件」とするが、これはステージ41 の数え方による。

| 数え方 | 母集団 | 始点 0 | 新規計上 | P(新規計上 \| 始点 0) |
|---|---|---:|---:|---:|
| ステージ41(終点が総資産比 1.001e-3 超) | class 1+2 | 78 | 0 | 0% |
| ステージ49(ちょうど 0 か否か) | 全組 | 1,174 | 204 | **17.4%** |
| ステージ49(ちょうど 0 か否か) | class 1+2 | 75 | 4 | 5.3% |

- ステージ49 の π(全組)では、自己株式の新規計上は稀ではない(健全企業は自社株買いをする)。
- 新規計上と 0 のままのコストの差は 1.6 nat しかない。
- したがって、**不活性制約が確率モデルの帰結として導かれる、とは事前には言えない**。

この点を確かめるため、感度分析として、**π を class 1+2 の組(367 組)から求めた版**(設定 7)を加える。
- 連続部分は設定 4 と同じ。π_min = 1/367。
- 採用の候補にはしない。

## 3. 分布の選択(A.4)

**主の版: t 分布(全件)**(設定 4)。生成の前に決める。

理由:

- 全件で AIC 最良が 23 / 32 科目。
- 対応先の選択では、苦境企業と健全企業という**別の企業どうし**を比べる。そのため、比 R は 1 年の変化の分布の裾に来ることが多い。
  - ステージ49 の QQ では、Subbotin は裾の重さが足りない。
  - 外れ値を除いた版は、まさにその裾を捨てている。
- 対数正規は、QQ で全科目棄却されている。

予想される性質: t のコストは \|g\| について対数的にしか増えない。多くの科目でよく一致し、少数の科目で大きく違う目標を選びやすい。

他の 3 版(Subbotin 全件・Subbotin 外れ値除去・対数正規)は、感度分析として生成・比較する。パラメータは `fits.csv` の値をそのまま使う。

## 5. 輸送(B.1・B.2)

- **最近傍**: j*(i) = argmin_j c(x_i, y_j)。目標は class 0 の全企業(baseline)。
  - 全社(`plan_full`)と、各 fold の訓練・テスト(`plan_train_k`、`plan_test_k`)で、現行と同じように作る。
- **不均衡 OT**(設定 6、t 分布):
  - コストは C' = (C − min C) / median(C − min C)。全体の最小値を引く。不均衡 OT では定数の加算が結果を変えるため、非負にそろえる。
  - ε = 0.05、τ = 0.1(ステージ39 と同じ)。
  - 対数領域の Sinkhorn(`solve_unbalanced_normalized`)。ポテンシャルの更新量 1e-9 未満で収束とし、収束しなければ例外。
  - 質量 0 になった訓練始点は、FM の学習から除く(`--allow-dropped-sources`、ステージ39 と同じ)。テストの始点は全社を生成する。
  - 対応先は、計画の行の最大の列。
- **class 1**: 現行と同じく、class 2 → class 0 の対応で学習した速度場を class 1 の始点に当てる。
- **他は最終設定 `s47_final` のまま**: W1 + PCFM + R3 + γ = 0.757 + 第 2 層 + β = 0.3 + 不活性制約(規則 M)+ α = 0.00199 + 目標 baseline。seed 0/1/2。

## 7. 採用基準(D.1)

| # | 基準 |
|---|---|
| 1 | 15 項目の違反 = 0(外れ値を除く class 2 55 社 × 3 seed、class 1 131 社 × 3 seed) |
| 2 | 主指標(純資産の改善 ↑、\|総資産変化\| ↓、実データとの符号付き順位相関 ↑)の 2 つ以上で設定 1 より有意に優れ、有意に劣るものがない |
| 3 | class 1 と class 2 の両方で 1・2 が成立する |

定義(ステージ40 と同じ):

- **有意**: 企業単位のペア(seed の中央値)の差の中央値について、95% ブートストラップ区間が 0 を含まない。
- **順位相関の差**: 企業を同時に復元抽出した 95% 区間(1,000 回、seed 0)。
- **順位相関**: 32 科目の変化の中央値と実データの順位相関。実データは、class 2 が再建群 15 社の 2 年、class 1 が class 1 → class 0 の 1 年の遷移 68 組。
- 債務超過の解消率・sparsity・validity・proximity は報告するが、判定に使わない(D.1 の 3 指標に従う)。

採用の手順:

1. 設定 4(主の版)を判定する。基準を満たせば採用する。
2. 設定 4 が満たさなければ、設定 6(同じ t 分布の不均衡 OT)を判定する。満たせば採用する。両方満たす場合は設定 4 を採る(不均衡 OT は始点を落とすので、仮定が少ない最近傍を優先する)。
3. 設定 2・3・5・7 は感度分析で、基準を満たしても**このステージでは採用しない**(分布を生成の前に選んだため)。満たした場合は報告し、採るなら次のステージで事前に記録して再検証する。
4. どれも満たさなければ、最終設定は変えない。結論は「分布は推定できたが、生成の改善には結びつかなかった」とする。

## 8. 不活性制約(C.4・D.2)

- **新規計上の割合**(ステージ41 の定義):
  - 始点が \|x\| / 総資産 < 1e-6、終点が 1.001e-3 超。
  - 行単位(企業 × seed)で数える。
  - 規則 M の 4 科目(自己株式は別に示す)と、その他の科目に分けて、不活性制約なしの版で比べる。
- **「不活性制約が不要」と判定する条件**: 次の 2 つを両方満たすこと。
  - 採用された尤度コストの設定を、不活性制約なしで生成した版が、**チェック 15 の違反 0 を含む 15 項目の違反 0** を両 class で満たす。チェック 15 の定義(始点 0 の対象科目が総資産比 1e-6 を超えて動いた)は変えない。
  - その版が、設定 1 に対して D.1 の基準 2・3 を満たす。
- 生成は連続な流れなので、1e-6 で動かないことを対応先の選択だけで実現するのは難しいと予想する。新規計上の割合(1.001e-3)は記述として報告する。
- 尤度コストの設定が採用されない場合も、C.4 の割合は報告するが、不活性制約は変えない。
