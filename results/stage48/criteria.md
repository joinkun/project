# ステージ48: 類型化の閾値(分類の前に記録)

記録の時点で、類型の分類はまだ行っていない(生成の値は既存の BS 表 5 社で見ている)。閾値は結果を見て変えない。

## 対象と時点

- 生成: ステージ47 の最終設定(`s47_final`)の **seed 0**(正本)。class 2 55 社(外れ値 2 社を除く)、class 1 131 社
  (外れ値 1 社を除く)。始点 t = 0 と終点 t = 1(5 年)の差で分類する。seed 1・2 で同じ類型になる企業の割合を頑健性として報告する。
- 実データ: 実際に再建した企業。class 2 → 注記なし 15 社、class 1 → class 0 57 社。2022 年度末 → 2024 年度末(2 年)の差。
  期間が違う(生成 5 年、実データ 2 年)ことは報告に明記する。
- 変化は始点の総資産 A0 で割る(総資産比)。

## 分類の軸と閾値

| 軸 | 区分 | 定義 |
|---|---|---|
| 純資産 | 債務超過を解消 | NA0 < 0 かつ NA1 > 0 |
| | 改善(解消せず) | 上以外で ΔNA / A0 > 0.01 |
| | ほぼ変わらず | \|ΔNA / A0\| ≤ 0.01 |
| | 悪化 | ΔNA / A0 < −0.01(生成は純資産の非悪化の制約で生じないはず) |
| 資産 | 増える / ほぼ変わらず / 減る | ΔA / A0 > +0.05 / \|ΔA / A0\| ≤ 0.05 / < −0.05 |
| 負債 | 増える / ほぼ変わらず / 減る | ΔL / A0 > +0.05 / \|ΔL / A0\| ≤ 0.05 / < −0.05 |
| 利益剰余金の増加 | 増加なし | ΔRE / A0 ≤ 0.01 |
| | 振替が主 | 振替 / ΔRE ≥ 2/3 |
| | 利益が主 | 振替 / ΔRE ≤ 1/3 |
| | 両方 | その間 |

- 振替と利益部分は `decompose_re_change`(払込資本の減少分を振替、残りを利益部分。生成の BS 表と同じ規則)。
- 閾値の根拠: 純資産は 1%(総資産比、丸め・ソルバ誤差より十分大きく、実質的な変化の最小単位として)。資産・負債は 5%
  (経営上意味のある規模の増減として)。利益剰余金の内訳は 2/3・1/3 で三等分。いずれも慣用的な値で、データから導いたものではない。

## 類型(組み合わせ)と代表例

- 類型 = 4 軸の区分の組み合わせ。組み合わせごとの社数を出す。
- 代表例: 生成 class 2 で社数の多い組み合わせの上位 4 つから、それぞれ乱数(seed 0)で 1 社。これに加えて、スペックが名指しした
  ジェイホールディングス(欠損填補のみで純資産が変わらない例)。代表例の説明は BS 表から書く。
