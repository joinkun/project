## 1. 決定事項(A.2・A.3・B)

- **Δ の定義**: 正規化(ステージ59 の確定)。名目は参考。
- **A_BS(第 1 項で個別に引き寄せる科目)**: 純資産の部の 9 科目と、丸め残余のうち純資産以外の 3 科目(資産その他・固定資産その他・負債その他)を除いた **20 科目**。
  - 純資産の 9 科目: 資本金・資本剰余金・利益剰余金・自己株式・株主資本その他・純資産その他・その他有価証券評価差額金・評価・換算差額等その他・非支配株主持分。
  - **非支配株主持分とその他有価証券評価差額金**: NA(y) に含め、個別には引き寄せない。どちらも非操作科目で凍結されている(始点の値に固定)ので、個別に引き寄せても目的関数の定数にしかならない。
- **NA(y)** = 純資産の部の 9 科目の和(canonical の `jppfs_cor_NetAssets` の係数)。
- **w_NA** = 1 / max(σ_NA^pool, ε_σ)²。σ_NA^pool = 断面(除外後)の NA / 総資産の、class 内でプールした標準偏差(案 1 と同じ)= **0.2156**。
- **w_a** = 1 / max(σ_a^pool, ε_σ)²、**ε_σ = 1e-3**(A_BS の科目だけ)。**m_a は廃止**。
- **第 2 項(白色化後)**: ũ = c⁺u、ṽ = c⁻v ≥ 0、y − x = ũ/c⁺ − ṽ/c⁻(c > 0 の科目)。Ψ = Σ(ũ + ṽ) + (η/2) Σ(ũ² + ṽ²)。
  - c = 0 の科目(非操作。利益剰余金は自由、他の 2 つは凍結)には移動の項がない。
- **η = 1.0**(既定、固定)。感度分析として η ∈ {0, 0.5, 2.0} も生成する。η = 0 は設定 3 と同じ。**結果を見て既定を変えない。**
- **重み c±**: 設定 1・2 はステージ59〜65 の中央値の重み。設定 3〜5 は頻度加重の重み(`weights_{c2,c1}.json`)。
  - **OT の地上コストにも同じ c± を使う**ので、設定 3〜5 では対応先を、頻度加重のコストで不均衡 OT(τ1 = 0.01、ε = 0.001)を解き直して作る。
- **制約**: s47_final の全制約(第 2 層・方向・凍結・不活性)+ 現金の下限 β_cash = 0.117(全設定)。
- **下界(A.3)**: 案 1 を採る。NA の項と制約を外した、科目ごとに分離した 1 次元問題の和を閉形式で解く。
  - 外した項は非負で、制約を外すと最小値は小さくなるので、下界として正当である。
  - A_BS の外の科目は、移動しないのが最小(0)。
- **1 段階統合(設定 5)**:
  - 各始点について、class 0 全体(3,768 社)の下界を計算し、小さい順に **K = 50** 社で QP を解く。
  - その暫定の最小 U_i 以上の下界を持つ候補を除き、残りの候補でも QP を解く。目的関数の値が最小の企業を対応先とする。
  - 設定 5 は OT を使わない(QP の目的関数での最近傍)。
- **λ の較正(C.4)**:
  - λ = λ̃ × s。s は設定ごとに class 1(生成の始点 132 社)の対応先で、s = median_i [D(x_i, τ_i) / Ψ(τ_i − x_i)] として計算する。
  - **λ̃*_0 は class 1(評価 128 社)だけで選ぶ**(違反 0 の中で L 最小、L はステージ61 の定義)。
  - class 2 には同じ λ(= λ̃*_0 × s)を当てはめるだけとする。class 2 の結果を見てパラメータを変えない。
  - 設定 1 は、ステージ65 の class 1 の λ̃*_0 = 1(s = 0.3866)を、class 2 に λ = 0.3866 として当てはめ直す。
- **グリッド**: λ̃ ∈ {0.003, 0.01, 0.03, 0.1, 0.3, 1, 3, 10, 30, 100}。class 2 も参考に全点を生成する。ただし設定 5 は、class 2 では λ̃*_0 だけ。
