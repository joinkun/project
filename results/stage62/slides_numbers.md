## 新しい知見: 第 1 項の重みは払込資本を制御できる(第 2 項ではできなかった)

λ̃ = 3 で固定したときの、払込資本を減らす企業の割合:

| | m = 1 | 払込資本 × 3 | × 10 |
|---|---:|---:|---:|
| class 2、等重み L2 | 42% | 29% | 24% |
| class 2、非対称 L1 | 16% | 5% | 2% |
| class 1、等重み L2 | 16% | 5% | 2% |
| class 1、非対称 L1 | 12% | 4% | 3% |

- 純資産の改善は悪化しない(例: class 2 等重み L2 0.072 → 0.078)
- 第 1 項を変えると λ̃* が動く(非対称 L1・class 2: 1 → 0.1)ので、再較正が要る

## 違反の原因(主張 5 の注意として)

- 非対称 L1 の class 2 の違反 4 社は、すべて「現金を総資産比 1e-10 まで使い切る」(項目 3、うち 1 社は項目 4 も)
- 始点の現金は 0.7〜31%。生成が 0 にした。L1 の移動コストは、調整を最も安い科目(現金、c が最小)に集める端点解になる
- class 1 の等重み L2 の違反は「負債が 2 倍超」(項目 5)。違反の種類が class と距離で入れ替わる
