## 1. A: 非操作科目の棚卸し

| 科目 | 現在の c± | 生成での扱い | 0 にした時期と理由 |
|---|---|---|---|
| 利益剰余金 | 0 / 0 | **自由**(R3。上限 γ = 0.757 だけ) | 下記 |
| その他有価証券評価差額金 | 0 / 0 | **凍結**(始点の値に固定) | 下記 |
| 非支配株主持分 | 0 / 0 | **凍結** | 下記 |

- **「非操作 3 科目」はこの 3 つ**(`conf/accounts/costs_equal.yaml` の `non_actionable`)。
- **当初の根拠**(`conf/accounts/costs.yaml` §1.3、ステージ8〜9 の文献ベースのコスト設計):
  - 利益剰余金 = 当期純利益の累積で、経営者が直接操作できない(リコース文献の immutable / derived 変数)。
  - その他有価証券評価差額金 = 保有有価証券の含み損益(時価変動)。
  - 非支配株主持分 = 連結範囲・子会社の損益に従属する。
- **c = 0 になった経緯**:
  - 輸送のコストでは、意図的に 0 にしている(`cost_vectors(non_actionable_mode="ignore")`、ステージ13〜15)。
    - 対応先の選択に利益剰余金の差を使うと、苦境企業(利益剰余金が大きく負)に近い企業、つまり健全でない企業が対応先になるからである。
  - 射影では、当初は巨大な重み(1e6)で固定していた(`freeze`)。
    - ステージ27〜31 の R3 で、利益剰余金だけを自由にし、上限 γ を課した(再建を表現するため)。
  - ステージ59 の QP の移動コスト(c±)は、輸送の慣行を引き継いで非操作科目を 0 にした(ステージ59 `criteria.md` §1)。
  - **QP の移動コストとして 0 にする根拠は、検討されていなかった。**
- **指示文の「派生変数だから直接操作できない」は、QP ではすべての科目が決定変数なので、移動コストを 0 にする理由にならない**(指示文の指摘のとおり)。
- **丸め残余 4 科目**(資産その他・固定資産その他・負債その他・株主資本その他)は、**現在 c = 0 ではない**。中央値の尺度では s ≈ 0 なので、c ≈ 1 / ε0 = 1,000(最も高い)になっている。指示文の「c = 0 のままでよい」は前提が違うが、値が総資産比 1e-6 程度で動かないので、現状(c ≈ 1,000)のままとする。

## 2. B: 決定

- **利益剰余金**: 他の科目と同じ規則(中央値の尺度、ε0 = 0.001、n < 5 の代替)で c_RE± を推定し、QP の移動コストに入れる。
  - class 2 用(D_rec 57 社): **c+ = 10.1、c− = 24.6**(c−/c+ = 2.44)。c+ は 60 方向の中で最も安い(1 位)。
  - class 1 用(15 社、参考値): 減少が n = 4 < 5 なので c− を c+ で代替し、**c+ = c− = 3.1**(最も安い)。
  - **予想**: 利益剰余金の増加は、コストを付けても最も安い方向なので、ΔRE/ΔNA は大きくは下がらない。
- **その他有価証券評価差額金・非支配株主持分は、凍結のまま**(c は効かない)。
  - 含み損益と子会社の持分は、再建策の手段ではないと判断する。凍結を外すと、純資産の改善の新しい「無料の手段」になりうる。
- **輸送(対応先の選択)のコストには、利益剰余金のコストを入れない**(上記の輸送の理由を維持する)。対応先はステージ64 の不均衡 OT(τ1 = 0.01、ε = 0.001)の argmax のまま。
- **γ = 0.757 は全設定で残す。** 残すべきかは、結果(γ が拘束する企業数)を見てから判断する(指示 B.3)。
