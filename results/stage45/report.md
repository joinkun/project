## 6. C.1・C.2 の記述の修正(`results/stage44/report.md` に訂正を追記)

- **(9)**: 事前に定めた基準では γ は不要と判定されたが、基準に含めていなかった振替の規模で実データとの乖離が生じるため維持した
  (振替の p95 2.035 対 再建群の帯の上限 1.574)。基準の設計が不完全であった。
- **低次元化**: 31 次元でも損失の上では過学習が見えなかった。悪化は損失ではなく生成の指標に現れる。機構は特定できていない。
  ステージ44 の報告にあった機構の推測(「主要な方向に限る役割」)は削除した。
- **会社法 461 条**: e-Gov 法令 API はこのステージの作業中もメンテナンス中で(2026-10-01、v1・v2 とも)、条文は未確認。
  ステージ44 の報告から、条文に依拠した推測の一文を削除した。近似については「実データで近似の妥当性を確認した」とのみ記述する。

## 7. 想定と違った点

1. **方向制約のチェックは存在しなかった**。チェック 8 の枠を上限のチェックに置き換え、総数は 15 のまま(「→ 14 項目」にはならない)。
2. **(5) を外すと、資本金を 0 近くまで減らす企業が実データより多い**(16〜22% 対 2.3%)。半減する企業の割合は実データに近づいたが、
   減らす深さは実データと違う。
3. 主指標はほぼ変わらなかった。ANAP のように資本金の減少を欠損填補に回しても、純資産の改善が小さくなる企業がある。
4. R1 の validity が 0.751 → 0.708 に下がった(class 2)。順位相関も +0.499 → +0.481。どちらも有意差はない。
5. 払込資本を増やす企業の少なさと、利益剰余金が全社で増えることは、今回の更新では変わらない。
