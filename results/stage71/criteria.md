## 1. 共通(ステージ70 の新設計 + 𝓕_i⁺)

- **コスト**: ステージ70 の §1 と同じ。72 社、c = 1/s、残余は 10³ で上限、評価差額金だけ 0、自分自身を除く。
- **凍結**: 評価差額金と不活性科目だけ(非支配株主持分は c = 1/s で動かす)。
- **利益剰余金**: 移動コスト 0。
- **𝓕_i⁺** = ステージ70 の 𝓕_i(s47_final + 現金の下限 0.117)+ **負債の上限** L(y) ≤ max(2 L(x_i), 0.01 A(x_i))。L(x_i) ≤ 0 の始点には課さない。始点 y = x_i で満たす。
- **輸送計画**:
  - ステージ70 の main 版と同じコストで、τ1 = 0.05(と 0.5)の片側不均衡 OT を解き直す(ステージ70 は計画を保存していない)。
  - ε = 0.001。自分自身の候補は質量 0。
- **候補の集合 S(i)**: 行の確率 p_ij の大きい順に並べ、**累積が 0.9 に達するまでの上位(ただし最大 K = 10 社)**。p̃_ij = p_ij / Σ_{k ∈ S(i)} p_ik。
- **第 1 項**: 全 32 科目、w = 1 / max(σ_pool, 10⁻³)² / m²、**m = 10**(払込資本。本ステージは m = 10 だけ)。
- **λ**:
  - λ = λ̃ × s。グリッドは 10 点(0.003〜100)。
  - **λ̃*_0 は class 1(128 社)だけで選ぶ**(違反 0 の中で L 最小)。class 2 に同じ λ を当てはめる。
  - s は設定ごとに class 1 で計算(下)。

## 2. 設定(`stage71_qp.py`)

| # | 設定 | 内容 | s(class 1 の中央値) |

## 4. 判定(事前)

**項目 5 の制約化の効果**(記述): 設定 2 の λ̃*_0 と、S100UG53 の違反の有無を、ステージ70 の `s2_m10`(λ̃*_0 = 10)と比べる。

**新しい定式化の採用**: 設定 3・4・5・5'・5'' のうち、次を**両 class で**満たすもの。

1. 15 項目の違反が 0。
2. 複数企業を使う: p̃ の実効サポートの中央値 ≥ 2。F3 は、統合に使った企業数の中央値 ≥ 2。
3. 実在企業らしさ: 終点 y* の識別 AUC(LightGBM)≤ 設定 1 の終点の AUC + 0.05。F3 はさらに、目標 τ^face の AUC ≤ 設定 1 の目標の AUC + 0.05(0.762 / 0.736)。
4. 主指標(純資産の改善・解消率・順位相関)のどれも、設定 1 より有意に劣らない。

- 候補が複数あれば、class 1 の L が最小のもの。
- どれも満たさなければ、ステージ69 の最終設定のまま。
