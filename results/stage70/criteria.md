## 1. 新しいコスト(A.1、`stage70_weights.py`)

- **プール**:
  - 主は D_rec の 72 社(class 1 → class 0 57 社 + class 2 → 回復 15 社)を、両 class の生成に使う。
  - 比較として、同じ class の参照(class 2 は 72 社、class 1 は 57 社)を A.1・A.2 で計算する(生成はしない)。
- **Δ**: Δ_ka = x_{k,2024,a}/A_{k,2024} − x_{k,2022,a}/A_{k,2022}(従来と同じ、`prep_stage59.deltas`)。
- **尺度とコスト**:
  - s_a^± = median{|Δ_ka| : ±Δ_ka > 0}(変化した企業の中央値)。
  - **c_a^± = 1 / s_a^±(ε0 なし)**。
  - **残余科目(`__OTHER__*`)だけ c = min(1/s, 10³)**(上限で切る)。
- **n < 5 の代替**(従来の `scale_table` と同じ規則):
  - その方向の c を、「n ≥ 5 の全方向の c の中央値」で置き換える。
  - 中央値の対象は、評価差額金を除く全科目(利益剰余金・非支配株主持分を含む)。
- **非操作**: その他有価証券評価差額金だけ(c = 0)。
- **自分自身を除く**: 始点と同じ EDINET コードの再建企業(class 1 の 3 社)は、その始点のコストの推定から除く。その 3 社だけ、71 社から推定した c± を使う。

## 2. 目標の構成(A.2、`stage70_ot.py`)

- **OT の地上コスト**:
  - 上の c± で、利益剰余金と評価差額金は 0。
  - **非支配株主持分は c = 1/s を与える(主)**。0 にした版も A.2 で比べる。
- **正規化と周辺分布**: C̃ = C / median(C)(候補から除く組を除いた全要素の中央値)。周辺分布は一様。
- **自分自身を除く**: 始点と同じ EDINET コードの対応先候補(E01864 の 1 件)は、その行で質量 0(C̃ を全要素の最大の 10 倍に置き換える)。
- **輸送の設定**:
  - 片側不均衡 OT(τ0 = ∞)は τ1 ∈ {0.01, 0.05, 0.1, 0.5}、ε = 0.001(`transport.solve_semi_unbalanced_normalized`)。
  - バランス OT(τ1 = ∞)は対数領域の Sinkhorn、ε = 0.001(`solve_ot_normalized`)。
- **行の確率**: p_ij = P_ij / Σ_j' P_ij'。
- **目標の構成法**:
  - **argmax**: τ_i = y_{j*}、j* = argmax_j p_ij(従来)。
  - **M1(重み付き中央値)**: 科目ごとに τ_ia = 重み付き中央値 = 値を昇順に並べ、累積重みが初めて 0.5 以上になる値(下側の中央値。ゼロの重みが 0.5 以上なら、厳密に 0)。
  - **M2(スパース重心)**: π_ia = Σ_{j: y_ja ≠ 0} p_ij。π_ia < 0.5 なら τ_ia = 0。それ以外は、**非ゼロの企業の中での条件付き重み付き平均** Σ_{j: y_ja ≠ 0} p_ij y_ja / π_ia。
  - **L2 重心**(対照): τ_i = Σ_j p_ij y_j。
  - 「ちょうど 0」は値が厳密に 0.0。
- **報告する値**: 実効サポート(1/Σp²)の中央値、argmax と最近傍(argmin C̃)の一致率(計画の性質。M1・M2 の目標そのものは実在企業ではない)、ちょうど 0 の科目数の平均、未払金が 0 の割合、識別 AUC(LightGBM・ロジスティック回帰。`identification_auc_repeated(τ, class 0, 3)`、従来と同じ)。

## 3. B: 生成の設定(`stage70_qp.py`、QP はすべて `RecourseQP`)

- **新設計**(設定 2〜6 共通):
  - c± は §1(72 社、ε0 なし)。
  - **凍結は評価差額金と不活性科目だけ**(非支配株主持分は凍結を外し、c = 1/s で動かす)。
  - 利益剰余金の移動コストは、設定 2〜5 で 0、設定 6 で c = 1/s。
- 第 1 項は全 32 科目、w = 1 / max(σ_pool, 10⁻³)² / m²、η = 0。
- 制約は s47_final + 現金の下限 0.117(従来と同じ、γ を含む)。

| 設定 | コスト・凍結 | 目標 | m |
|---|---|---|---|

- **λ**:
  - λ = λ̃ × s。s は設定ごとに class 1 の始点と目標で、s = median_i [Σ w (τ − x)² / Σ c± |τ − x|](72 社の c± で計算)。

  - 比較の基準は設定 1(ステージ69 の最終設定、`project_onto_feasible`)。企業単位のペア比較(2,000 回のブートストラップ)。

## 4. 判定(事前)

**新しいメイン手法の採用**: 設定 3a〜6b(m = 10・1 とも)のうち、次の 4 つを**両 class で**満たすもの。

1. 15 項目の違反が 0。
2. 輸送計画の実効サポートの中央値 ≥ 3(複数の企業を実際に統合している)。
3. 目標の識別 AUC(LightGBM)≤ 設定 1 の目標の AUC + 0.05(class 2 で ≤ 0.762、class 1 で ≤ 0.736)。
4. 主指標(純資産の改善・債務超過の解消率・符号付き順位相関)のどれも、設定 1 より有意に劣らない(記号が「−」でない)。

- 採用候補が複数あれば、class 1 の L が最小のもの。同じなら m = 1(事後選択なし)を優先する。
- どれも満たさなければ、ステージ69 の最終設定のまま。
- 設定 2(新設計のコスト・凍結、argmax)は、コストの純粋化の効果として 1・4 を報告する。採用の判定には使わない。
- A.2 の問い(複数企業に質量を広げても、M1・M2 でゼロの構造と AUC が保たれるか)は記述として報告する。
