# ステージ51: 主指標の見直し(判定規則は A.1 の集計の前に記録)

この時点では、A.1 の実データの総資産変化の分布はまだ集計していない。過去の判定の再計算(A.4)もまだ行っていない。
「A.1 の結果」の節だけは集計の後に追記する(追記であることを明記する)。

## 1. A.1 の集計方法

**集団**(推定用パネル `data/interim/stage23/panel/`、2022 → 2024 年度末の 2 年。両年度の書類がある企業):

| 集団 | 定義 |
|---|---|
| 再建群(class 2 → 回復) | `results/stage30/recovery_firms.csv` の group Y、除外理由なし、パネルにある(15 社) |
| 再建群(class 1 → class 0) | 2022 年度 class 1、2024 年度 class 0、ステージ28 の除外規則に当たらない(ステージ47 の 57 社と同じ抽出) |
| 非再建群(class 2 → class 2) | 同じファイルの group Z、除外理由なし、パネルにある(30 社) |
| 健全企業 | 2022 年度 class 0 で、ステージ28 の除外規則に当たらない企業から、乱数(seed 0)で 500 社 |

**総資産の変化**:

- 2 年の比 R2 = A_2024 / A_2022。
- **5 年への換算は複利**: R5 = R2^(5/2)。ΔA / A0 = R5 − 1。
- 線形の換算(2 年の変化 × 2.5)も参考に出す。
- 生成の値(t = 1、5 年)は (A1 − A0) / A0。

## 2. A.2 の判定規則

- **再建群の「中心」**: 5 年換算の ΔA / A0 の中央値。
- **「0 付近」**: 中央値の 95% ブートストラップ区間(企業の復元抽出 2,000 回、seed 0)が 0 を含むこと。
- **2 つの再建群(15 社・57 社)の両方で 0 を含めば**「中心が 0 付近」とし、\|総資産変化\| の最小化を主指標に残す。
- **どちらか一方でも 0 を含まなければ**「中心が 0 でない」とし、指標を変える。

## 3. A.3 の決定(A.2 で「中心が 0 でない」場合)

**案 3 を採る: \|総資産変化\| を主指標から外す。** 極端な値はチェック項目で防ぐ。

理由:

- 総資産の変化そのものに、良し悪しの基準がない(増資・資産売却・DES はいずれも正当)。
- 案 1(実データの中央値との差)は、2 年の観測を 5 年に換算した、15 社の中央値に依存する。換算の仮定と標本の少なさで、基準点が不安定になる。
- 案 2(p10〜p90 に入る割合)も同じ換算に依存する。生成のほうが期間が長い。

案 2 の割合は、**副指標(参考)として報告する**。判定には使わない。

A.2 で「中心が 0 付近」と判定した場合は、\|総資産変化\| を主指標に残す(次節の集合に加える)。

## 4. 新しい主指標(v2)

スペック E.1 に従う。

| 区分 | 指標 | 良い向き |
|---|---|---|
| 主(改善) | 純資産の改善 | 大 |
| 主(改善) | 債務超過の解消率(始点で債務超過の企業、3 seed のうち解消した割合) | 大 |
| 主(妥当性) | 実データとの符号付き順位相関 | 大 |
| 主(実行可能性) | sparsity(総資産比 1% 超で動いた科目数) | 小 |
| 副 | validity、proximity、総資産の変化が実データの p10〜p90 に入る割合 | — |

**判定規則**(F.1 と同じ):

1. 15 項目の違反 = 0(項目別に報告する)。
2. 上の主指標 4 つのうち 2 つ以上で有意に優れ、有意に劣るものがない。
3. class 1 と class 2 の両方で成立する。

**有意の定義**:

- 純資産の改善・解消率・sparsity: 企業単位のペア(seed の中央値。解消率は seed の平均)の差の中央値について、95% ブートストラップ区間(2,000 回)が 0 を含まない。
- 順位相関の差: 企業の同時復元抽出(1,000 回、seed 0)の 95% 区間が 0 を含まない。
