## 2. 遷移確率(A.1・A.2・A.4)

- **ゼロ**: 総資産比がちょうど 0(ステージ49 と同じ)。
- **ステージ49 の集計は条件付き確率ではない**(全組に対する割合: 両期 0、新規計上、消滅、両期非 0、符号反転)。条件付きに直す:
  - p(0 → 0) = 両期 0 / (両期 0 + 新規計上)
  - p(0 → 非 0) = 新規計上 / (両期 0 + 新規計上)
  - p(非 0 → 0) = 消滅 / (消滅 + 両期非 0 + 符号反転)
  - p(非 0 → 非 0) = (両期非 0 + 符号反転) / (消滅 + 両期非 0 + 符号反転)
  - 各条件の下で和が 1 になることを確かめる。
- **推定元**:
  - **主: 案 1、推定用パネル全体**(10,971 組、1 年)
  - 報告だけ: 案 2(再建群 72 社 = class 2 → 回復 15 社 + class 1 → class 0 57 社、2022 → 2024 年度末の 2 年)、案 3(class 1+2 の組、1 年)
  - **案 2・3 では生成しない。**
- **クリップ**: 各条件付き確率を [1/N, 1 − 1/N] に収める。N は推定元の組の数(案 1 は 10,971)。
  - 理由: 観測 0 件の区分を有限にするため(ステージ50 と同じ考え方)。
  - 始点の状態の観測が 0 件の科目(現金など)は、両方の遷移を 1/2 にする(目標による差をつけない)。
- **期間の違い**: 遷移は 1 年(案 2 は 2 年)、生成は 5 年。そのまま使う(ステージ50 の案 1 と同じ)。
- 遷移は「同じ企業の翌年」の確率だが、目標の選択では「別の健全企業」に当てはめる(ステージ50 と同じ限界)。

## 4. 評価(C)と採用基準(D)

| # | 設定 | 出典 |
|---|---|---|
| 1 | 等重み最近傍(現行) | ステージ50 の `equal`(ステージ47 と完全一致) |
| 2 | 周辺密度 + 距離(ステージ52 版 I) | ステージ52 の `indep` |
| 3 | **条件付き密度 + 距離** | 新規に生成(seed 0/1/2、class 2・class 1、不活性制約あり、他は `s47_final`) |

- **主指標**: 純資産の改善 ↑、債務超過の解消率 ↑、符号付き順位相関 ↑。
- **有意**: ステージ51 と同じ定義。
- **基準(設定 3 対 設定 1)**:
  1. 15 項目の違反 = 0(項目別に報告)
  2. 主指標の 2 つ以上で有意に優れ、劣るものがない
  3. class 1 と class 2 の両方で成立
- **C.3 検定力**(class 2、n = 55):
  - 純資産の改善:
    - class 2 の企業単位のペアの差の分布を、中央値が class 1 の差の中央値に一致するよう平行移動する。
    - そこから 55 社を復元抽出し、95% ブートストラップ区間(内側 1,000 回)が 0 を含まない割合を、検定力とする(外側 2,000 回、seed 0)。
    - 参考に、class 1 の分布そのものから 55 社を抜いた検定力も出す。
  - 順位相関: 平行移動ができないので、**class 2 の差の 95% 区間の半幅**と class 1 の差の点推定を比べる。半幅のほうが大きければ「n = 55 では検出できない大きさ」とする(検定力 ≈ 50% 未満に当たる)。
  - **「class 2 では検出力が不足する」の定義**: class 1 で有意に優れた主指標のうち 1 つでも、上の量で検出できない(検定力 < 0.8、または半幅 > class 1 の点推定)こと。
- **検出力が不足する場合の扱い(D.1 の追加の判断材料。生成の前に固定する)**: 次のすべてを満たせば「**採用(class 2 では検出できない、と明記)**」とする。
  1. class 1 で基準 1・2 を満たす。
  2. class 2 で違反 0。
  3. class 2 で、有意に劣る主指標がない。
  4. class 1 で有意に優れた各主指標について、class 2 の点推定が改善の向き(差 > 0)。
  5. 上の「検出力が不足する」に当たる。

  1 つでも満たさなければ採用しない。基準をこれ以上緩めない。
- **D.2**: 採用に至らなくても、B.1 で自己株式の数が 9 を下回れば、設計上の改善として報告する。
- **これが密度モデルの最終試行である**(スペック G)。採用に至らなければ、密度モデルの方向を打ち切る。
