## 1. コスト関数の確率的な意味(指摘 1)

記号: 科目 a の変化 Δ_a(総資産比)、増加分 u_a = (Δ_a)₊、減少分 v_a = (−Δ_a)₊。移動コスト Ψ(Δ) = Σ_a c_a⁺ u_a + c_a⁻ v_a。QP の変数も u, v に分けている。

### 1.1 Ψ = 負の対数尤度(作用)

遷移の密度を科目ごとに独立とし、p(Δ) = Π_a p_a(Δ_a) とおく。−log p_a が Δ_a の両側で線形なら、

  −log p(Δ) = Σ_a (u_a / θ_a⁺ + v_a / θ_a⁻) + 定数

となり、c± = 1/θ± とおけば Ψ と一致する。

- **輸送(最小作用)**: Σ π_ij C_ij を最小にする計画は、遷移の対数尤度の期待値を最大にする計画である。
  - エントロピー正則化つきの OT は、参照の核 K_ij = exp(−C_ij / ε') からの KL を最小にする結合を求める問題と等しい(恒等式)。
  - ここで ε' = ε × median(C) である(C̃ = C / median(C)、ε = 0.001)。したがって、参照の核は遷移の尤度 exp(−C) そのものではなく、その 1/ε' 乗(鋭くした尤度)である。
- **QP(事後最大化)**:
  - 第 1 項 ½ Σ w (y − τ)² は、目標 τ のまわりのガウス尤度の負の対数である。
  - λ Ψ(y − x) は、遷移の事前分布の λ 乗の負の対数である。
  - したがって y* は 𝓕⁺ の上での事後最頻値(MAP)で、λ は事前分布の温度にあたる。

### 1.2 どの確率モデルが、どのコストを与えるか

| モデル | 密度 | 単位あたりの傾き c± | 生起頻度の入り方 | 対応するコスト |
|---|---|---|---|---|
| A: u, v を独立な指数分布 | p(u, v) = exp(−u/θ⁺ − v/θ⁻) / (θ⁺θ⁻) | 1/θ±、最尤推定 θ± = (1/N) Σ_k (±Δ_k)₊ = (n±/N) × 平均(\|Δ\| \| 符号 ±) | **傾きに入る**(頻度 × 条件付きの幅) | **R3**(平均)。R2 はその中央値版、R1 は企業ごとに規格化した版 |
| B: 非対称ラプラス | p(Δ) = exp(−u/s⁺ − v/s⁻) / (s⁺ + s⁻) | 1/s±、最尤推定 s± = m± + √(m⁺m⁻)、m± はモデル A の θ± | 傾きに入るが弱まる: **c⁻/c⁺ = √(m⁺/m⁻)**(R3 の比の平方根) | R3 の非対称を平方根に縮めたもの |
| C: ハードル(動かない質量 + 向き + 幅) | P(Δ = 0) = p₀、Δ ≠ 0 では p±/s± · exp(−\|Δ\|/s±) | 1/s±(条件付きの幅) | **固定費 log(s±/p±)** として入る(凸でない) | **abs**(ステージ69)は、固定費を除いた凸緩和 |

- B の最尤推定の式は、対数尤度 −N log(s⁺ + s⁻) − S⁺/s⁺ − S⁻/s⁻ の停留条件から導いた。数値の最適化と一致することを確かめた。
- B は C の特別な場合(p₀ = 0、p± = s±/(s⁺ + s⁻))。このとき固定費 log(s⁺ + s⁻) は向きによらない定数になり、傾きだけが残る。
- **指示文の「R1〜R3 は非対称ラプラスの負の対数尤度にまさに対応する」は、正確にはモデル A について成り立つ。** 非対称ラプラス(B)なら、非対称の比は R3 の比の平方根になる。
  - 例: 資本金の c⁻/c⁺ は、R3 の 0.33 に対し、B では 0.57。
  - **どのモデルでも、減資は増資より安い**(ステージ75 §1)。
- モデル A は、変化しない企業(Δ = 0)を「指数分布から 0 が出た」として扱う。ステージ49 は、科目によって不動の質量が大きいことを示した。この点では C のほうがデータに合う。
  - C の傾き(abs)は頻度を含まない。頻度は「その向きに動き始めること」の固定費になる。
  - 生成で変更科目数が少ないこと(ステージ69 で 5)は、この固定費を明示的には持たない。λ と 𝓕⁺ の結果である。

### 1.3 ステージ49(Subbotin)との関係

- ステージ49 は、科目別の変化率 g = log R に Subbotin を当てはめた。形状 b は 32 科目中 31 科目で 1 未満(中央値 0.55)だった。
  - −log p ∝ |g/s|^b は、最頻値の両側で凹になり、凸にならない。
- b < 1 の関数の凸包は、変化の範囲を [g_min, g_max] に限ると、最頻値から両端への弦(左右で傾きの違う線形)になる。
  - ステージ49 の「区分線形の凸包は、左右で傾きの違う線形の重みに退化する」はこれにあたる。
  - **ただし傾きは範囲の端で決まり、分布だけでは決まらない。** 範囲を無限に広げると、凸包の傾きは 0 に向かう。
- また、ステージ49 の変数は対数の変化率 g で、R1〜R3 の総資産比の差 Δ とは違う。対応は定性的なものに留まる。

**論文での書き方(案)**: 「移動コスト Ψ は、科目ごとの増加分・減少分を独立な指数分布とする遷移モデルの負の対数尤度であり、輸送は期待対数尤度の最大化、QP は 𝓕⁺ 上の事後最頻値と読める。観測される変化の分布は Laplace より裾が重く(ステージ49)、その負の対数尤度は凸でない。そのため、凸包として非対称な線形を使う。」

## 2. 苦境の確率の変化(指摘 2-1)

分類器: 苦境(class 1・2)vs 健全、GC(class 2)vs 健全の 2 種類。LogReg と LightGBM を、企業単位の 5 分割(乱数 42)で学習した。始点・終点は、その企業を学習に含まない fold のモデルで予測した。

| 目的変数 | 分類器 | out-of-fold の AUC |
|---|---|---:|
| 苦境 vs 健全 | LogReg / LightGBM | 0.890 / 0.899 |
| GC vs 健全 | LogReg / LightGBM | 0.941 / 0.975 |

確率は、クラス重み均衡のスコアを学習データの有病率(n₁/n₀ = 0.0515 / 0.0151)に戻したもの。**「この構成の書類が苦境の書類である確率」で、実際の倒産確率ではない。**

| class | 分類器(苦境 vs 健全) | 確率の中央値 | 確率の平均 | スコアの差の中央値 [95%] | 下がった割合 | 終点 ≤ 健全の中央値 |
|---|---|---|---|---|---:|---:|
| 2(55 社) | LogReg | 72.9% → 49.3% | 65.4% → 53.0% | −0.019 [−0.055, −0.000] | 85% | 2% |
| 2 | LightGBM | 37.6% → 13.6% | 44.0% → 32.3% | −0.045 [−0.107, −0.013] | 91% | 2% |
| 1(128 社) | LogReg | 16.5% → 4.7% | 29.7% → 17.2% | −0.134 [−0.179, −0.098] | 92% | 18% |
| 1 | LightGBM | 0.99% → 0.04% | 16.3% → 7.3% | −0.034 [−0.063, −0.008] | 86% | 18% |

- 全分類器で、85〜96% の企業の確率が下がった。
- **しかし class 2 の終点は、2% しか健全企業の中央値まで下がらない。** LogReg の確率の中央値は 49% に留まる。
  - ステージ69 の設定は、変更科目数 5 で大きく動かない(λ̃ = 1)。終点は「健全に近づいた苦境企業」であって、「健全企業」ではない。
- GC vs 健全(`feasibility_report.md`)では、LightGBM の確率の中央値が 1.88% → 0.01% になる。ただし、平均は 24.7% → 16.4% で、一部の企業は高いまま残る。

## 3. 年次推移に基づく実行可能性(指摘 2-2)

実在の推移: パネル(全上場企業 3,657 社、2021〜2024 年度)の 1・2・3 年の推移と、再建群 72 社(2022 → 2024)。Ψ は最終設定の class ごとの c±。

| class | 実在の分布 | 実在の中央値 / 95% 点 | 生成のパーセンタイル(中央値 / 90% 点) | 95% 点以内 | 99% 点以内 |
|---|---|---|---|---:|---:|
| 2 | 全上場企業 1 年 | 18.9 / 86.5 | 60% / 99% | 82% | 87% |
| 2 | 全上場企業 3 年 | 36.1 / 145 | 23% / 98% | 84% | 93% |
| 2 | 再建群 72 社(2 年) | 37.2 / 190 | 21% / 96% | 87% | 93% |
| 1 | 全上場企業 1 年 | 22.0 / 94.7 | 8% / 59% | 99% | 100% |
| 1 | 再建群 72 社(2 年) | 41.2 / 169 | 1% / 27% | 100% | 100% |

- **期間の注意**: 生成の終点は 5 年後とみなしている(`GEN_Y`)が、実在の推移は最長 3 年である。5 年の推移は 3 年より大きいはずなので、「3 年の 95% 点以内」は実行可能性を厳しめに見た判定になる。
- **class 2**:
  - 中央値は実在の 1 年の推移程度で、87% が再建群の 95% 点以内に収まる。
  - ただし上位 10% は、1 年の推移の 99% 点、3 年の推移の 98% 点を超える。最大は 835 で、1 年の 99% 点(187.5)の約 4.5 倍になる。
- **class 1**: 生成はほとんど動かない(中央値 7.8、1 年の推移の 8 パーセンタイル)。実在の回復(中央値 41)より 1 桁小さい。

**コストと「実行・回復の確率」の対応(実データ)**:

- 始点で class 1・2 の企業の推移(ラベルはステージ38 の遷移)を、Ψ の四分位ごとに見た。回復(終点で class 0)の割合は次のとおり:
  - class 2 の Ψ で測ると、1 年は 37% → 25% → 15% → 11%、2 年は 49% → 53% → 37% → 21%。
  - class 1 の Ψ で測ると、1 年は 38% → 22% → 18% → 10%、2 年は 60% → 44% → 33% → 23%。
  - 件数は 1 年 348、2 年 172(四分位あたり 87 / 43)。
- **大きく動いた企業ほど、回復の割合は低い。**
  - 「コストが小さい = 起きやすい」(1 − F̂(c) が大きい)には合う。
  - 一方で「大きく動けば回復する」わけではない。境界に近い企業は小さな変化で class が変わり、大きな変化は混乱(事業の縮小・売却)を含むと考えられる。因果ではない。
- 生成の 1 − F̂(c) の中央値(全上場企業 1 年): class 2 で 40%、class 1 で 92%。

**方向**:

- 生成の Δ と、同じ群の実際の回復の平均 Δ の余弦の中央値は、class 2 で +0.76、class 1 で +0.73。
- 実際の回復企業どうしの余弦(自分を除いた平均との余弦)は +0.35 / +0.46 で、生成のほうが高い。**生成は「平均的な回復の方向」に揃いすぎている。** 実在の多様さは再現していない。
  - 構成の生の Δ の余弦なので、大きい科目(利益剰余金・負債)が支配している。

## 4. 近傍の実在密度(指摘 2-3)

Ψ(z − y) ≤ r の健全企業の数(自社を除く)。r は、健全企業どうしの最近傍の Ψ の 90% 点(class 2 で 68.2、class 1 で 63.1)。

| class | 終点: 中央値(0 社の割合) | 始点: 中央値(0 社の割合) | 健全企業(300 社の標本): 中央値(0 社の割合) |
|---|---|---|---|
| 2 | 0(65%) | 0(76%) | 64(11%) |
| 1 | 8(16%) | 8(30%) | 30(11%) |

- 始点より終点のほうが、近くに健全企業がない割合は下がる(76% → 65%、30% → 16%)。
- **しかし class 2 の終点の 65% は、健全企業から r90 以内に 1 社もない「空白地帯」に残る。** 健全企業自身では、その割合は 11% である。
- class 1 の終点は、健全企業の密度にかなり近い。

## 5. 距離空間の地図(指摘 3、`bs_manifold_mapping.png`)

- 距離: 対称化した移動コスト δ(a, b) = Σ (c⁺ + c⁻)/2 · |a − b|。
- 地図: 古典的 MDS で、健全企業 1,500 社をランドマーク(乱数 0)にし、ほかの点は Gower の公式で埋め込んだ。
- 等高線: 苦境スコア(LightGBM、out-of-fold)を、2 次元の 30 近傍で平均したもの。
- 矢印: 紫 = 生成(x_i → y_i*)、緑 = 実際の回復(2022 → 2024)。

**図から言えること・言えないこと**:

- **上位 2 成分の寄与は 27%**(class 2・class 1 とも)。2 次元の距離は、元の距離のごく一部しか表さない。
- **苦境スコアの等高線は、ほとんど 0〜0.3 で平らである。**
  - 苦境企業は全体の約 5% で、2 次元の近傍平均では健全企業に薄められる。
  - また、2 次元では苦境と健全がほとんど分かれていない(元の 32 次元では AUC 0.90)。
  - 「谷に向かう」絵にはならなかった。
- class 2 の生成の矢印は短く、健全企業の密集部(図 (a) の右下)へ向かうものは一部である。実際の回復の矢印(緑)は長く、向きもまちまちである。
- **図は補助にとどめ、主張には §2〜§4 の数値を使うべきである。** 見栄えのために等高線を描き直す(色の範囲を絞る・対数をとる)ことはしていない。

## 6. 想定と違った点

1. R1〜R3 は、非対称ラプラスではなく、u・v を独立な指数分布とするモデルの最尤推定にあたる(§1.2)。
2. 実データでは、大きく動いた苦境企業ほど回復の割合が低い。コストと回復の確率は逆向きに対応する(§3)。
3. class 2 の終点の 3 分の 2 は、健全企業の近傍に入らない(§4)。
4. 2 次元の地図では、苦境の確率の山と谷が見えない(§5)。
