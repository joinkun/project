# ステージ63 発表資料の数値(ステージ61・62 からの更新分)

## 主張 4 の注記: 第 1 項の重みは「事後に選んだ」

- 事前に決めた 6 設計のうち、払込資本 × 10 を両 class の結果を見て選んだ(**事後選択**)

| 設計 | 払込資本↓ c2 / c1 | 純資産の改善 c2 / c1 |
|---|---|---|
| 払込資本 × 3 | 13% / 23% | 0.271 / 0.163 |
| **払込資本 × 10(事後に選択)** | 36% / 19% | 0.329 / 0.163 |
| 払込資本 × 30 | 36% / 19% | 0.329 / 0.163 |
| 群間差に比例 | 40% / 18% | 0.362 / 0.082 |
| 群間差に反比例 | — / 83% | — / 0.101 |
| 寄与率に反比例 | 80% / 48% | 0.000 / 0.004 |
| 実データ | 36% / 23% | — |

- 「群間差に比例」の帰結ではない(払込資本の群間差 / 中央値 = 約 50)
- class 1 を 2 分割した検証: **成立 54%**(選ばれる設計が分割ごとに変わる)

## 違反の原因と対処(スライド30 の補足)

- 非対称 L1 は、class 2 で現金を総資産比 1e-10 まで使い切る(L1 の端点解。現金は移動コストが最小)
- 実データの再建企業: 2 年で現金を 1/10 未満にした企業 0%、0 にした企業 0 社(57 社・15 社)
- 現金の下限 β_cash = 0.117(α と同じ方法: class 1+2 の 1 年で現金が減った 191 組の 1 パーセンタイル)
  - class 2 の違反: 3〜4 社 → 0〜1 社(残る 1 社は始点の現金 0.7% で半ば循環)
  - 違反 0 の λ̃*_0: 30 → 3、純資産の改善 0.000 → 0.121
  - 端点解は他の科目に移らない(0 件)。等重み L2 のほうが端点解が多い(c2 26 件、c1 47 件)

## 主張 5(class 1 に限定)

> 非対称 L1 は、class 1(n = 128)では 10 点中 7 点の λ で、符号付き順位相関が有意に優れた。class 2(n = 55)では 1 点のみ。class 1 の効果を n = 55 で検出できる確率は 0.20〜0.78 で、class 2 の結果は標本の小ささでも説明でき、効果の有無は判別できない。

- 旧: 「下方硬直性が自動的に学習された」
- 新: **「代表値で結論が変わる」**

| 科目 | 平均(増加 / 減少) | 中央値(増加 / 減少) |
|---|---:|---:|
| 有形固定資産 | 1.31 | 0.92 |
