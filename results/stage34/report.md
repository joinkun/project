# ステージ34: class 1 の活用(検証と試算)

全表は `results.md`、数値は `class_compare.csv`・`summary.json`。スクリプト: `scripts/run_generation_stage34.py`
(生成)、`scripts/evaluate_stage34.py`(評価・集計)。**最終設定は変更していない。** B.3 の可動性と
C.3 の γ は試算で、採用していない。

## 最初に: class 1 は分類器の学習に使われていた

スペックと `HANDOFF.md` の前提は「class 1 は生成にも分類器の学習にも使っていない」だった。
しかし validity の分類器の学習データ(各スクリプトの `load_real`)には、**ラベルのある書類がすべて
入っており、class 1 も「class 2 でない」側に含まれていた。** `train_classifiers` の docstring
(「class0+class2全社」)とも食い違っていた。

本ステージでは、class 1 を含めない分類器(class 0 対 class 2、seed 42)で validity を測った。
この分類器で最終設定(class 2 始点、55 社)の validity を測り直しても 0.998 で、結果は変わらない。
コードは変えず、docstring にこの事実を書き足した。

## 1. A.2 生成結果

- **始点**: class 1 は 137 社(全社が `is_financial` を通過)。ステージ28 の規則(事業の内容と 33 業種)で
  金融 2 社(第一商品、ウェッジ HD)とゴルフ場 3 社(出水ゴルフクラブ、鳴門ゴルフ、大松産業)を除き、
  **132 社を生成**した。
- **外れ値**: ステージ19 の基準(RE・資本金・資本剰余金の総資産比が class 0 の最大を超える)を機械的に
  当てた。この規則は class 2 の外れ値 2 社(オンコセラピー、桃太郎源)をちょうど再現する。class 1 では
  **シンバイオ製薬 1 社**(RE / 総資産 6.58、class 0 の最大 5.57)が該当し、**評価は 131 社**で行った。
- **学習**: class 1 を hold-out に保つため、速度場は class 2 の 57 社 → class 0(等重み最近傍の
  `plan_full`)で学習し、class 1 の始点に当てた。class 1 は学習にも目標にも使っていない
  (目標分布は class 0 のまま)。最終設定は 5-fold だが、class 1 はどの fold にも属さないので、
  seed ごとに class 2 の全社で 1 本学習した。射影は最終設定と同じ。
- 実行不可能は 3 seed とも 0 社。

## 2. A.3 生成と実際の変化の比較

2 つは同じ企業・同じ期間ではない。

- **生成**: 2024 年度の書類で class 1 の 131 社。t = 1(5 年)を年率に直した。
- **実際**: 2022 年度に class 1 だった 148 社のうち、特殊業種を除きパネルにある 127 社。2022 → 2024 の
  2 年を年率に直した。

| 項目(年率、総資産比) | 生成 | 実際(class 1 全体) | 実際のうち class 0 へ回復した社 |
|---|---:|---:|---:|
| 社数 | 131 | 127 | 57 |
| 純資産の改善(中央値) | **+0.037** | +0.020 | +0.044 |
| 純資産が改善した社 | 100% | 65% | 89% |
| 債務超過 → 解消 | 3 / 6 | 1 / 5 | 0 / 0 |
| **利益剰余金が増えた社** | **100%** | 61% | **86%** |
| ΔRE(中央値) | +0.053 | +0.013 | +0.037 |
| Δ払込資本(中央値) | −0.007 | 0.000 | 0.000 |

| 動いた科目の順位 | 生成 | 実際 |
|---:|---|---|
| 1 | 利益剰余金 0.053 | 利益剰余金 0.049 |
| 2 | 現金及び預金 0.014 | 現金及び預金 0.031 |
| 3 | 短期借入金 0.013 | 長期借入金 0.016 |
| 4 | 投資その他の資産 0.009 | 有形固定資産 0.016 |
| 5 | 資本剰余金 0.008 | 短期借入金 0.011 |

- **大きさは実際の回復企業に近い。** 純資産の改善(+0.037 対 +0.044)、ΔRE(+0.053 対 +0.037)、
  動いた科目の上位 2 つ(利益剰余金・現金)が一致した。32 科目の動きの大きさの順位相関は +0.80。
- **違いは向きと割合に出る。**
  - 利益剰余金が増える社: 生成 100%、実際の回復企業 86%
  - 短期借入金: 生成は年 −1.3% 減らすが、実際の中央値は 0
  - 有形固定資産: 生成は増やす(+0.8%)が、実際は減る(−0.4%)
  - 仕入債務・売上債権: 生成は減らすが、実際はわずかに増える
  - 資本金: 生成は減らす(−0.4%)が、実際の中央値は 0
- 生成は全社が「健全企業へ向かう」経路なので、実際の class 1 全体(35% は純資産が改善していない)ではなく、
  回復した 57 社と比べるのが妥当である。

## 3. A.4 制約の過適合の確認

**13 項目の違反は 0 行 / 396 行(132 社 × 3 seed)。** 外れ値のシンバイオ製薬も違反しなかった。
class 2 で設計した第 2 層の制約は、class 1 を始点にしても違反を生まない。過適合の証拠はない。

## 4. B.1 3 群の変化の大きさ

推定用パネルの書類内の 1 年の組を、各書類の年度のラベルで分けた。

| 群 | 組数 | 社数 |
|---|---:|---:|
| class 0 | 10,184 | 3,462 |
| class 1 | 375 | 198 |
| class 2 | 145 | 69 |

- **p90 が class 0 ≤ class 1 ≤ class 2 の順になった科目: 22 / 32。**
  - 例: 資本金 0.0016 < 0.249 < 0.442、現金 0.118 < 0.219 < 0.341、短期借入金 0.070 < 0.122 < 0.253。
- **単調でない科目: 10 個。** 内訳は次のとおり。
  - ゼロが大半の科目・残余: 資産その他、固定資産その他、負債その他、株主資本その他、1 年内社債、社債
  - 健全企業ほど大きく動く科目: **自己株式**(p90 class 0 0.015 > class 1 0.0007 > class 2 0)、
    **その他有価証券評価差額金**、**未払法人税等**、評価・換算差額等その他
  - 後者は、自社株買い・有価証券の保有・利益への課税という「余裕のある企業の動き」で、圧力とは逆向きに
    動く科目として筋が通る。

## 5. B.2 ρ1 の 3 群比較

- **ρ0 ≥ ρ1 ≥ ρ2(単調)の科目: 20 / 32。**
- **class 1 が class 0 より有意に低い科目: 21 / 32**(class 2 でも 21 科目)。
  - 例: 現金 0.946 → 0.875 → 0.709、仕入債務 0.975 → 0.943 → 0.779、無形固定資産 0.919 → 0.824 → 0.649。
- 単調でない科目の多くは、ゼロが大半の科目・残余である。単調でないその他の科目:
  - 資本金・資本剰余金: class 1 のほうが class 2 より低い(資本金 0.809 < 0.858)
  - 未払法人税等: class 1 が最も低い
- **class 1 はおおむね中間の値をとり、「圧力が強いほど持続性が下がる」という解釈は補強された。**
  ただし資本金・資本剰余金では、class 1 のほうが持続性が低い。重要事象の企業が増資や減資で対処した
  (その結果、注記を回避した)ことと整合的だが、推測である。

## 6. B.3 潜在的可動性の試算(生成には使わない)

m = p90(|Δx|/A | class 1 と 2)/ p90(|Δx|/A | class 0)、c = 1/m(現金預金 = 1)。

| 科目 | m | c = 1/m(現金 = 1) |
|---|---:|---:|
| 資本金 | **195.8** | 0.011 |
| 資本剰余金 | 32.8 | 0.065 |
| 利益剰余金 | 5.5 | 0.390 |
| 短期借入金 | 2.2 | 0.98 |
| 現金及び預金 | 2.1 | 1.00 |
| 長期借入金 | 1.9 | 1.12 |
| 有形固定資産 | 1.7 | 1.25 |
| 売上債権・棚卸資産 | 1.2 | 1.78 |
| 未払法人税等 | 0.8 | 2.64 |
| 自己株式 | 0.03 | 88.9 |
| 社債 | 0.01 | 318 |
| 1 年内償還予定社債 | 0 | 定義できない(class 1・2 の p90 が 0) |

**このままでは重みに使えない**と考える。理由は 3 つ。

- **分母の小さい科目で比が極端になる。** 資本金は健全企業ではほぼ動かない(p90 0.0016)ので、
  比が 196 倍に跳ね上がる。逆に自己株式・社債は、苦境企業が持たない・動かさないので 0 に近く、
  コストが数百倍になる。
- **「圧力下で動いた量」は「必要があって動いた量」でもある。** 持続性(ステージ33)と同じ問題を、
  逆側から持ち込んでいる。利益剰余金の m = 5.5 は大半が損失によるもので、動かしやすさではない。
- **重みとして採用するなら、分母に下限を設ける、損失で受動的に動く科目を除く、などの設計を、
  生成の前に決める必要がある。** 本ステージでは試算にとどめた。

**測定の枠組みとしての発見**: 平時(class 0)と圧力下(class 1・2)の変化の比は、平時の持続性とは
別の情報を持つ。特に資本金・資本剰余金は「平時は動かないが、圧力下では最も大きく動く」科目だった。

## 8. C.2・C.3 回復群の財務変化と γ

| 項目(2022 → 2024、年率) | class 2 → 注記なし(15 社) | class 1 → class 0(57 社) |
|---|---:|---:|
| 利益剰余金が増えた社 | 86.7% | **86.0%** |
| うち振替を伴う | 5 | 13 |
| 利益部分 P > 0 の社 | 11(73%) | 47(82%) |
| 利益部分の年率(中央値) | +0.054 | +0.031 |
| 増資のある社 | 9(60%) | 14(25%) |
| Δ純資産の年率(中央値) | +0.068 | +0.044 |
| 債務超過 → 解消 | 4 / 4 | 0 / 0(債務超過の社なし) |

- **利益剰余金が増えた社の割合は、2 つの回復群でほぼ同じ(87% と 86%)。** 「再建では利益剰余金が
  増える」(ステージ30)は、4 倍の標本でも再現した。
- 合わせた 72 社で割合 86.1%、**Wilson 95% 区間は 76.3〜92.3%**(15 社では 62.1〜96.3%)。
  **最終設定の生成(100%)は、区間の上端を 8 ポイント上回る。** 標本を増やすと、ステージ31 で限界として
  書いた差がよりはっきりする。
- class 1 の回復群は、class 2 の回復群より利益の速さも増資の頻度も小さい。より軽い状態からの回復である。

| γ の標本(Tukey の外れ値を除く p90 × 5) | 社数 | 外れ値 | γ |
|---|---:|---:|---:|
| class 2 → 注記なし(ステージ31 の値) | 15 | 2 | 0.757 |
| class 1 → class 0 | 57 | 4 | **0.383** |
| 両者を合わせる | 72 | 7 | **0.439** |

**標本を増やすと γ は 0.757 から 0.44 前後に下がる**(採用しない)。class 1 の回復群は GC 企業より
軽い状態からの回復なので、class 2 の再建経路の上限として合わせてよいかは別途判断が要る。

## 9. 想定と違った点

- **class 1 は分類器の学習に使われていた**(class 2 でない側)。validity への影響はなかった。
- class 1 始点でも 13 項目の違反は 0 で、制約の過適合は見られなかった。
- 生成は、実際の回復企業と大きさ(純資産の改善・ΔRE)が近い。一方、利益剰余金が増える割合(100% 対 86%)
  と、借入金・有形固定資産の向きが違う。
- 3 群の単調性は、変化の大きさで 22 / 32、ρ で 20 / 32 科目だった。自己株式・評価差額金・未払法人税等は、
  健全企業ほど大きく動く。
- 潜在的可動性 m は、資本金で 196 倍、社債・自己株式でほぼ 0 と極端で、そのままでは重みにならない。
- class 1 の回復率(43%)は class 2(19%)の 2 倍以上だった。回復群の「利益剰余金が増えた社」の割合は
  86% で、class 2 の 87% とほぼ同じだった。
- γ は、合わせた標本では 0.44 に下がった。
