## 3. パートC: 実在の再建企業へのバックテスト

- **対象**: class 1 → class 0 の 57 社(fold f のホールドアウト D_f)と、class 2 → 回復の 15 社。
- **始点と実績**:
  - 再建前の始点 x_{k,0} = 2022 年度の構成、実績 x_{k,1} = 2024 年度の構成(どちらも各年度の総資産比、パネル)。
  - 生成の終点 ŷ_k は、総資産で割り直して構成にする: ŷ_k / A(ŷ_k)。
  - 変化は δ_real = x_{k,1} − x_{k,0}、δ̂ = ŷ_k / A(ŷ_k) − x_{k,0}。
- **57 社の生成(out-of-fold)**:
  - fold f のホールドアウトには、57 社から D_f を除いて推定した θ(D1 の cfg f)を使う。
  - 輸送: 始点を D_f の企業、対象を健全企業とする。γ' = 0.1、τ' はステージ79 §7 の式で n0 = |D_f| から計算する。**同一企業(自社の再建後の書類)の組は除く。**
  - QP は KDE0p と同じ(s は cfg f の class 1 の F1 の定義)。
- **λ̃ の選び方**:
  - **主: fold f 以外の 4 fold の λ̃*_{f'} の中央値。**
  - 理由: λ̃*_f は、fold f の 57 社(= ホールドアウトそのもの)の実データの集計値(払込資本↓・RE↑・総資産の変化)を目標に選ばれており、使うと集計値の水準で答えを見ることになる。
  - 参考: 指示どおりの λ̃*_f も並べる。
- **15 社の生成**: 57 社の全体の θ(15 社はコストのプールに入らない)と、単一の生成の λ̃。
  - 15 社は、λ の較正の目標にも入らない。ただし、class 2 の順位相関の参照(Y 群)には使われている。
- **比較の基準**:
  1. KDE0(base)を同じ手順で(λ̃ は KDE0 base の D1 から同じ規則で)
  2. 1-NN の健全企業(同じ輸送のコストで最小の 1 社、QP なし)
  3. 健全企業の構成の中央値への移動
- **指標**(企業ごとに計算し、中央値・IQR・正の割合を出す):
  - DSA_k: |δ_real| ≥ ε の科目での符号の一致率。ε = 10⁻²(主)、5 × 10⁻³・2 × 10⁻²(感度)。該当する科目のない企業は除き、件数を報告する。
  - Cos_k(32 次元のコサイン類似度)、ρ_k(企業ごとのスピアマン順位相関)。
  - ERR^{L1} = 1 − ‖ŷ − x₁‖₁ / ‖x₀ − x₁‖₁。
  - ERR^ψ = 1 − ψ_k(x₁ − ŷ)/ψ_k(x₁ − x₀)。ψ_k は KDE0p の企業 k の単価で、利益剰余金は 0。
  - 苦境の確率: LightGBM(企業単位の 5 分割、ステージ76 と同じ)。企業 k を学習に含まない fold のモデルで予測する。
  - 5 つの財務比率: x₀・x₁・ŷ の中央値、改善幅(実績 x₁ − x₀ と生成 ŷ − x₀)の相関、MAE(ŷ と x₁)。
- **事例(class ごとに 2 社)**:
  - 代表例: DSA_k と ERR^{L1} の順位の平均が、中央値に最も近い企業。
  - 乖離の例: ERR^{L1} が最も小さい企業。
