# ステージ52 報告: ゼロを明示的に扱う密度と、それによる目標設定

A(ゼロパターンの集計)は `report_a.md`。本書は追加指示を受けた B〜E の結果。

- 規則: `criteria_b.md`(推定・目標・生成の前に記録、コミット 2312689)
- 表: `density_b.md`(B)、`matching.md`(C)、`comparison_d.md`(D.2)、`targets_d.md`(D.3)、`bs_d.md`(D.4)、`assets_extreme.md`

## 結論

1. **採用しない。最終設定は変えない。**
   - 主の版 I(32 科目・独立ゼロ + 条件付き正規)は、class 1 では基準を満たす(純資産の改善 +0.038、順位相関 +0.034)。
   - しかし class 2 では、どちらも有意差がない(+0.007、−0.019)。
   - 違反は両 class で 0。
2. **密度は推定でき、健全性も識別した**(B.4.1 を両版とも通過)。
   - 1 社あたりの log q の中央値: class 0(交差検証の hold-out)30.7 > class 1 13.0 > class 2 −13.2
   - class 2 < class 0 の片側 Mann-Whitney p = 3.9e−22
   - **ステージ51 で失敗した密度推定は、ゼロを離散部分に分けることで成り立った。**
3. **しかし、密度を目標の選択に使っても、ゼロパターンの一致は改善しなかった**(C.2、事前の予想どおり)。
   - 自己株式を持たない始点 15 社のうち、対応先が自己株式を持つ社: 現行 9 社 → 版 I 14 社、版 II 13 社(採用した λ)。
   - **−log q(y) + λd の密度の項は始点によらない。** そのため、密度は「始点と同じパターン」ではなく「健全企業でよくあるパターン」(自己株式は 91% が持つ)を選ぶ。
   - 一致を良くするには、条件付き密度 q(y | x)(始点のパターンを条件にする)が要る。
4. **版 II(18 科目のパターン混合)は、事前の標本数の規則で 1 パターンに縮退した。**
   - 「ゼロなし」以外のパターンは、すべて社数が次元の 10 倍未満(3〜9 倍)。
   - 実質的には、18 科目の単一の正規である。
5. ステージ50(尤度コスト)と違い、**対応先の払込資本比率は崩れなかった**(0.833 → 0.794)。純資産の改善も下がらなかった。

  - 1.16 は、ゼロ率が高いことによる比の上限である。

## 10. 想定と違った点

1. **密度は推定でき、class の順序も強く成り立った。** ステージ51 の失敗は、ゼロを離散部分に分けることで解消した。
   - パターンの確率だけでも、class 2 は有意に稀である。
   - **「ゼロの構造」と「非ゼロの値」の両方が、健全性の情報を持つ。**
2. **それでも、目標の選択でパターンの一致は改善しない。** 密度の項 −log q(y) は始点によらず、健全企業でよくあるパターン(自己株式を持つ)を選ぶ。
   - 指示の「パターンを明示的に扱えば改善するはず」は、**条件付き密度 q(y | x) でなければ成り立たない**。
   - 18 科目版で 14 科目を外しても、一致は改善しなかった(指示の予想どおり)。
3. **版 II は 1 パターンに縮退した。** ゼロなし以外の上位パターンは、どれも社数が次元の 10 倍に届かない(148 社 / 17 次元など)。
4. **ステージ50 の失敗(払込資本比率の崩れ)は起きなかった。** 原因は、λ の規則(現行の 1.5 倍以内の距離)で、対応先が現行の近くに留まったことと考えられる。
5. **追加指示の数値が、データと合わなかった**(§0)。決定はユーザーの判断に従ったが、理由の記述は訂正した。

## 次の候補(実装しない)

- **条件付き密度 q(y | x)**: 始点のゼロパターンを条件にした密度(例: 始点で 0 の科目は対応先でも 0 である確率を、class 0 の年次の遷移(推定用パネル)から推定する)。ステージ49 の π の遷移(新規計上・消滅)を密度に組み込む形になる。
- 版 I の密度は class を強く見分けるので、**生成結果の評価指標**(生成の終点の log q)として使える可能性がある。validity(分類器)と違い、学習データの外の点も連続的に評価できる。
