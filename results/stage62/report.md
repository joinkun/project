# ステージ62: 違反の解消と、第 1 項の重みの検討

**結論**
1. **提案手法(非対称 L1)のままでは、class 2 で違反 0 を満たす λ が実用的な範囲にない。**
   - 違反 0 は λ̃ ≥ 30 でだけ成立し、そこでは再建しない(純資産の改善 0.000)。
   - 違反 4 社はすべて独立のチェック(現金 ≈ 0、うち 1 社は主要資産の消滅も)。外れ値 2 社は含まない。
   - 原因は、生成が現金を 0 にすることで、始点の状態から引き継いだものではない。
   - L1 の移動コストは、調整を最も安い科目(現金、c が最小)に集める端点解になる。
2. **第 1 項の重み(払込資本への引きを弱める m)は、払込資本を制御できる新しいレバーだった。**
   - λ̃ = 3 で、払込資本を減らす企業が有意に減る。等重み L2・class 2 で 42% → 24%、非対称 L1・class 2 で 16% → 2%。純資産の改善は悪化しない。
   - 払込資本に m = 10 を掛けて λ を再較正すると、**非対称 L1 が両 class で違反 0 になった。**
     - class 2: λ̃*_0 = 0.1。払込資本を減らす企業 36%(実データ 36%)、純資産の改善 0.329、解消率 1.00。
     - class 1: λ̃*_0 = 1。19%(実データ 23%)、0.163、1.00。
   - **ただしこの組合せは、事前に決めた 6 設計 × 10 λ̃ から結果を見て選んだもので、採用は決めていない(§E.1)。**
3. **m を変えると λ̃* は動く**(非対称 L1・class 2: 1 → 0.1)。第 1 項と第 2 項の比が変わるので、再較正が必要である(B.4 の答え)。
4. **「順位相関で非対称 L1 が一貫して高い」は、class 2 では頑健でない。**
   - 中央値 ≈ 0(|値| < 1e-4)を 0 にそろえると、class 2 で非対称 L1 が有意に高い λ̃ は 1 / 10。class 1 では 5 / 10 で、ここは残る。
   - 改善は、多くの科目の中央値が 0 付近にあり、その微小な符号(ソルバの残差)で順位が付くことに一部よっている。
   - **有形固定資産・棚卸資産の「下方硬直性を捉えた」という証拠はない**(有形固定資産は実データ −0.021 に対し、非対称 L1 の中央値は 0)。
5. **ハード制約は課さない**(D)。社債でも 18% が償還している。

## 0. 指示文の前提との違い

- 「λ̃* = 3 の非対称 L1 で class 2 の 4 社」は不正確。class 2 の非対称 L1 の λ̃* は 1 で、4 社はそこでの数(λ̃ = 3 では 3 社)。
- 「順位相関は全ての λ で非対称 L1 が最も高い」は、class 2 で 7 / 10、class 1 で 8 / 10 の λ̃ でしか成り立たない(§C.1)。
- 第 1 項は、ステージ59・60 の決定どおり σ² で割っている(指示文の式は σ)。m は σ に掛けるので、重みは w / m² になる。

## E.1 違反の診断(A.1、class 2、非対称 L1、λ̃ = 1)

| 企業 | 項目 | 終点の現金 / 総資産(0) | 始点の値 | 違反が消える λ̃ |
|---|---|---:|---:|---|
| クオンタムソリューションズ | 3 現金 ≈ 0 | 4e-11 | 0.119 | 3 以上 |
| 燦キャピタルマネージメント | 3 現金 ≈ 0 | 5e-10 | 0.052 | 10 以上 |
| Birdman | 3 現金 ≈ 0 | 7e-10 | 0.308 | 30 以上 |
| モンスターラボホールディングス | 3 現金 ≈ 0、4 主要資産 | 5e-10 | 0.007 | 1 以外のすべて |

- 外れ値 2 社(オンコセラピー・サイエンス、桃太郎源)は、ステージ60 以降の始点(55 社)に含まない。
- **始点で違反している企業はない。** 生成が現金を厳密に 0 にしている。対応先の現金は 0 ではない(例: Birdman の対応先は 0.279)。
- **項目 3・4 は独立のチェック**(ステージ51 `checks.md`)。指示文の分類では「根拠の弱い項目」に当たるが、現金を総資産比 1e-10 にする生成は会計上不自然である。違反として扱うのが妥当と考える。
- **原因(仮説、一部の企業で確認)**:
  - L1 の移動コストは、動かす科目を少数に集める端点解を作る。現金は c が最も小さい科目(c− = 35.1)で、恒等式の釣り合いを取るための調整が現金に集まり、下限 0 まで使い切る。
  - 燦キャピタルマネージメントでは、払込資本を 0.757 減らす分を現金で埋めて 0 になった。払込資本への引きを弱めた paid10 では、払込資本が動かず、現金が残った(0.052)。
  - Birdman と ANAP は払込資本が増える側で、この説明だけでは足りない。
  - 等重み L2(二乗)は調整を多くの科目に分けるので、端点に張り付かない。

## E.3 クラス間の逆転(A.3)

違反した (企業, 項目) を、λ̃ の 10 点で合計した。

| class | 距離 | 項目 3 現金 ≈ 0 | 項目 4 主要資産 | 項目 5 負債 2 倍超 |
|---|---|---:|---:|---:|
| c2 | 等重み L2 | 0 | 0 | 0 |
| c2 | 非対称 L1 | 24 | 1 | 0 |
| c1 | 等重み L2 | 3 | 0 | **55** |
| c1 | 非対称 L1 | 0 | 0 | 16 |

- **違反の種類が class で違う。**
  - class 2 の非対称 L1 は「現金を使い切る」(L1 の端点解)。
  - class 1 の等重み L2 は「負債が 2 倍超に増える」。
- class 1 の等重み L2 では、第 1 項が対応先の負債の水準へ引き、二乗の移動コストは大きな増加を十分に抑えない。非対称 L1 では、借入金の増加に c+ がかかるので抑えられる。
- class 2 は債務超過・払込資本過大の企業が多く、資産側を削って釣り合いを取る方向の調整が多い。そのため現金の端点解が出やすい(仮説)。

## E.4 第 1 項の重みの効果(B.3、λ̃ = 3 で固定)

m の設計は `criteria.md` §2(実行の前に記録)。差は base に対する企業単位のペアのブートストラップ。

| class・距離 | 設計 | 払込資本↓(差 [95%]) | 純資産の改善 | 順位相関 | 変更科目数 | 違反(社) |
|---|---|---|---:|---:|---:|---:|
| c2 等重み L2 | base | 42% | 0.072 | +0.351 | 9 | 0 |
| | paid3 / paid10 | 29%(−0.13 [−0.22, −0.05])/ 24%(−0.18 [−0.29, −0.09]) | 0.078 | +0.365 | 9 | 0 |
| | gap | 27%(−0.15) | 0.066 | +0.263 | 7 | 0 |
| | invgap / invrho | 76% / 78%(+0.35) | 0.116 / 0.159 | +0.27〜0.29 | 12〜13 | 0〜1 |
| c2 非対称 L1 | base | 16% | 0.121 | +0.203 | 3 | 3 |
| | paid10 | 2%(−0.15 [−0.25, −0.05]) | 0.152 | +0.337 | 3 | 1 |
| | gap | 2% | 0.009 | +0.225 | 3 | 0 |
| c1 等重み L2 | base / paid10 | 16% / 2%(−0.13) | 0.020 / 0.020 | +0.16 | 5 | 2 |

(実データ: 払込資本↓ 36% / 23%、変更科目数 16 / 14)

- **払込資本だけ m を上げる(paid)と、払込資本を減らす企業は有意に減り、主指標は悪化しない。** m = 10 と 30 は同じ結果で、10 で飽和している。
  - 第 2 項(c±)では制御できなかったものが、第 1 項では制御できる。
- **群間差に比例(gap)は、払込資本を減らすが、再建が弱くなる。** 純資産の改善は c2 非対称 L1 で 0.121 → 0.009、RE↑ は 82% → 56%。
  - 群間差の大きい科目(払込資本だけでなく借入金なども)への引きを、まとめて弱めるためである。
- **群間差に反比例(invgap)・寄与率に反比例(invrho)は、払込資本を減らす企業を 66〜84% に増やす**(「群間差の大きい科目こそ合わせる」立場)。
- 変更された科目数は、どの設計でもほぼ変わらない(λ で決まる)。

## E.6 C.1: λ に依存しない差か

| | class 2 | class 1 |
|---|---|---|
| 非対称 L1 が最も高い λ̃(元の定義) | 7 / 10 | 8 / 10 |
| 非対称 L1 − 等重み L2 が有意に正(元の定義) | 1 / 10 | 7 / 10 |
| 中央値 ≈ 0 を 0 にそろえた場合、最も高い | 4 / 10 | 6 / 10 |
| 同、有意に正 | 1 / 10 | 5 / 10 |

- **class 1 では、λ̃ ≤ 10 の広い範囲で非対称 L1 が高く、0 にそろえても半数の λ̃ で有意である。** 提案手法の根拠として使えるのは class 1 の結果である。
- **class 2 では、差は λ に依存し、頑健でない。** ステージ61 の「λ̃* で +0.251(有意)」は、0 にそろえると +0.089 [−0.038, +0.359] になる。
- 0 にそろえると、λ̃ ≥ 10 では多くの距離で全科目の中央値が 0 になり、相関が定義できない(表の nan)。

## E.7 C.2: 科目別の分解(`accounts.md`)

- class 2(等重み L2 λ̃ = 3 対 非対称 L1 λ̃ = 1): 符号の一致は、等重み L2 22 / 32、**非対称 L1 19 / 32 で、非対称 L1 のほうが少ない。**
  - 寄与の改善が大きい科目は、資本剰余金・仕入債務・有形固定資産。どれも非対称 L1 の中央値が ±0.0000(実質 0)で、微小な符号が実データの符号と合ったことによる。
- class 1(両方 λ̃ = 3): 符号の一致は、等重み L2 20 / 32、非対称 L1 22 / 32。
- **有形固定資産**: 実データは減少(class 2 −0.021、class 1 −0.003)。等重み L2 は増加(×)、非対称 L1 は 0(×)。
  - c−/c+ は 0.52(class 2 の重み)・0.12(class 1 の重み)で、「減らしにくい」重みではない。
  - **下方硬直性を捉えたという主張は、このデータでは裏づけられない。**
- **棚卸資産**: 実データは増加(+0.007)。等重み L2 は一致、非対称 L1 は 0(×)。

## E.8 D: ハード制約の記述(スライド30、`hard.md`)

- 方針: **実データの再建企業に存在する行動は禁止しない。**
- 減少がほぼ起きない科目(正規化・名目の 57 社と、名目の 15 社のすべてで減少 ≤ 5%)は、丸め差の残余科目 3 つだけである。値が総資産比 1e-6 程度なので、制約として意味を持たない。
- **社債でも 57 社中 10 社(18%)、15 社中 2 社(13%)が減らしている(償還)。** 資本金も名目で 18%、自己株式も 5〜14% が減らしている。
- **結論: ハード制約は課さない。** 減らしにくさは、移動コストの非対称の重み(ソフトな形)と、第 1 項の重み m で表す。

## E.9 想定と違った点

1. 違反は「根拠の弱い項目」だが、中身は「現金を総資産比 1e-10 まで使い切る」で、会計上不自然だった。L1 の端点解という、手法の構造から来る。
2. 違反 0 を制約にすると、m = 1 の非対称 L1 は class 2 で再建しない(λ̃*_0 = 30)。
3. 第 1 項の重み(払込資本 × 10)で、払込資本と違反が同時に改善した。λ を下げられるようになったためで、第 1 項と第 2 項の比が本質である。ただし事後の選択である。
4. 順位相関の非対称 L1 の優位は、class 2 では「ほぼ 0 の中央値」の微小な符号に一部よっていた。
5. 有形固定資産の重みは c−/c+ < 1 で、下方硬直性の主張とは逆向きの重みだった(ステージ59 から変わらず)。
