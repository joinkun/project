## 0. 指示文の前提の確認(ステージ61 の数値)

1. **「λ̃* = 3 の非対称 L1 で class 2 の 4 社が違反」は不正確。**
   - class 2 の非対称 L1 の λ̃* は 1 で、そこで 4 社が違反する。λ̃ = 3 では 3 社。
   - λ̃* = 3 は、等重み L2(両 class)と class 1 の非対称 L1 の値である。
   - 診断(A.1)は λ̃ = 1 と 3 の両方で行う。
2. class 2 の非対称 L1 の違反企業数は、λ̃ ≤ 0.3 で 3 社、1 で 4 社、3 で 3 社、10 で 2 社、30 以上で 0 社。対称 L1 も同様。等重み L2 は、全 λ̃ で 0 社。
3. **「符号付き順位相関は全ての λ で非対称 L1 が最も高い」は、一部の範囲でしか成り立たない。**
   - class 1 では λ̃ ≤ 10 で成り立つ(0.31〜0.45、等重み L2 は −0.02〜0.21)。λ̃ = 30・100 では等重み L2 のほうが高い。
   - class 2 では λ̃ ≤ 1 で成り立つ。λ̃ = 3・10・30 では等重み L2 のほうが高い(例: λ̃ = 3 で 0.203 対 0.351)。
   - C.1 では全点の表で報告する。
4. 符号付き順位相関の定義は、32 科目の「生成の変化の中央値」と「実データの変化の中央値」の Spearman 相関である(`compare_stage39.corr`)。符号の一致数(`agree`)とは別の量なので、C.2 では両方を科目ごとに分解する。

## 2. 第 1 項の重み m_a(B.2)

σ_a^eff = max(σ_a^pool, 0.001) × m_a、つまり第 1 項の重みは w_a / m_a²(ステージ59・60 と同じく σ² で割る)。

| 設計 | m_a |
|---|---|
| base | すべて 1(ステージ61 と同じ) |
| paid3・paid10・paid30 | 資本金・資本剰余金だけ m = 3・10・30、他は 1 |
| gap | m_a ∝ d_a |
| invgap | m_a ∝ 1 / d_a |
| invrho | m_a ∝ 1 / ρ_a |

- **d_a** = |生成する class の平均 − class 0 の平均|(x̃、除外後の断面)。class 2 は 55 社、class 1 は生成の始点 132 社。下限は 0.001。
- **ρ_a** = 等重み L2² の最近傍での寄与率(ステージ59 A'.2 の定義)。生成する class ごとに計算し、下限は 0.001。
- **gap・invgap・invrho の正規化**:
  - 操作できる 29 科目で、m の幾何平均を 1 にする(全体の引っ張りの強さを変えず、配分だけ変える)。
  - そのうえで m を [0.01, 100] で切る。
  - 非操作 3 科目(利益剰余金・その他有価証券評価差額金・非支配株主持分)は m = 1(利益剰余金の経路を変えない)。
- **比較の λ**: 指示どおり λ̃ = 3 に固定する(B.3)。λ = λ̃ × s_d の s_d は、ステージ61 の値(base の w)をそのまま使う。m を変えても s を計算し直さない。
- **B.4 の再較正**: 各設計で λ̃ のグリッド 10 点も生成する。各設計の λ̃*(と λ̃*_0)が base からずれるかを報告する。
- **距離**: 等重み L2(主)と非対称 L1(提案)の 2 つ。両 class。
- 評価指標は次のとおり。結果を見て m の設計を変えない。
  - 払込資本を減らした割合(名目・正規化)
  - 純資産の改善、符号付き順位相関、変更された科目数
  - 違反企業数(項目別)
  - 較正の乖離 L
