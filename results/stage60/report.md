- **全 15 設定が収束した。** 行の誤差 < 1e-6、質量 0 の行は 0、輸送質量は 1(始点側を厳密に保存するので常に 1)。
  - ステージ13・50 の失敗(質量 0 の行、輸送質量 0.068)は、両側を緩めた版で起きたもので、この版では構造上起こらない。

- **局所性(≤ 20)を満たすのは τ1 が小さい場合だけで、そのとき計画は最近傍とほぼ同じになる。**

  - τ1 → 0 の極限は「始点ごとに独立に exp(−C/ε) で重みを付ける」形で、群から群への輸送ではない(`criteria.md` §0.3)。
  - **A の局所的な設定は、実質的に最近傍の平滑化である。**

## F.3 B: 台を絞る

- **B.3 抽出の安定性**: 実効サポートは seed による差が小さい。例えば n1' = 550・ε = 0.005 で 11.7〜12.1。
  - ただし代表の n1' での生成は、純資産の改善の中央値の範囲が class 2 で 0.039、class 1 で 0.036 あり、事前の閾値 0.02 を超えた。**規則により「抽出に依存する」と判定した。**
  - 払込資本を減らした割合の範囲は、両 class とも 2 ポイントで安定している。
- **B.4 層化の妥当性**:
  - 業種の構成比のずれは最大 0.004(n1' = 110)、0.001(n1' ≥ 220)。
  - 払込資本比率の中央値は 0.124〜0.141(全体 0.133)。
  - 32 科目の中央値のずれは最大 0.064(n1' = 110)、0.005〜0.021(n1' ≥ 550)。
  - 層化による分布の歪みは小さい。
- 代表は class 2 で n1' = 550(実効サポート 12.1)、class 1 で n1' = 1,100(9.6)。
- 対照の近傍の和集合(案 3)は、class 2 で k = 20(14.3)、class 1 で k = 8(6.3)。

## F.4 C.3: 重み付き μ1 の退化

- **どの β でも実効サポートは 20 を超えた。** ε = 0.005 での最小は、class 2 で 66.1(β = 5)、class 1 で 26.0。
- 上位 5 社の受取質量は ≤ 0.5%(class 2)で、退化(1 社への集中)は起きていない。
- 重み w_j ∝ exp(−β min_i C̃_ij) は、C̃ の単位で β ≤ 5 だと偏りが小さく、周辺分布の制約がほとんど緩まない。β をさらに大きくすれば局所化できるかもしれないが、事前に決めた範囲の外である。

## F.8 想定と違った点

1. **「82%」は Flow Matching の性質ではなく、目標への引きの強さで決まっていた。**

   | λ̃ | 0.01 | 1 | 10 | 100 |
   |---|---:|---:|---:|---:|
   | 等重み L2² の最近傍(class 2) | 65% | 11% | 4% | 0% |
   | バランス OT の重心(class 2) | 85% | 51% | 7% | 0% |

   - λ̃ = 0.01(ほぼ目標への射影)で、等重み L2² は 65%(class 1 は 62%)、重心は 83〜87% になり、現行の 82% に近い。
   - **健全企業を目標にすると払込資本比率が下がるのは、目標の性質(class 0 の払込資本比率 0.13)そのものである。** 移動コストを重くすると割合は単調に下がり、0% まで下げられる。
   - 「実データの 23〜36% に合わせる」ことは λ の選び方でできてしまう。ただし λ は事前に「2 項の大きさをそろえる」と決めた値(λ̃ = 1)で評価した。
2. **等重み L2² + QP(λ̃ = 1)は、払込資本を減らす企業が実データより少ない**(11% 対 36%、10% 対 23%)。問題の向きが、Flow Matching のとき(多すぎる)と逆になった。
3. **A(不均衡 OT)は、局所性を得ると最近傍とほぼ同じになる。** 不均衡 OT の失敗(ステージ13・50)は再現しなかったが、それは τ0 = ∞ で始点を保存したからである。代わりに「群の輸送」としての意味が薄れる。
4. **重心は、少数の平均でも識別 AUC が 0.98 以上になる。** 目標点の局所性(実効サポート)を回復しても、合成点の問題は解けない。
5. **ステージ13 の総資産 −66% は、正規化空間の QP では再現しない。** 「素朴な OT ではなぜ駄目か」の材料は、総資産ではなく「重心が実在しない点になる(AUC 0.995)」と「台の下限 n1/n0」になる。
6. 提案コストの最近傍自体が、class 2 で独立のチェック(現金 ≈ 0、主要資産の消滅)に違反した(5 社)。等重み L2² の最近傍は class 2 で違反 0 である。
7. B の抽出の安定性は、払込資本の割合では成立し(範囲 2 ポイント)、純資産の改善では不成立だった(0.036〜0.039)。

## QP の数値的健全性(ステージ59 C.2・C.4)

- **重み比**: 1/σ² の最大 / 最小は 483,315(σ の下限 0.001)、c± は 68.9(class 2)と 204(class 1、15 社の重み)。白色化して解いた。
- **ソルバの状態**: 全 48,246 件が `optimal`(class 2 14,190、class 1 34,056)。
  - OSQP が inaccurate を返した場合は、内点法で解き直している。その件数は数えていない(cvxpy の警告として出る)。
  - 実行不可能は 0。
- **独立ソルバ(CLARABEL)との差**: 最大 1.1e-5(総資産比、代表の設定)。
- **スラック変数**: min(u, v) > 1e-9 は、c > 0 の科目で 4,542 件(class 2)と 2,007 件(class 1)。最大は 1.4e-7 で、1e-6 を超えるものはない。
  - 指示の閾値 1e-9 では 0 にならないが、大きさはソルバの許容誤差(1e-8)の 10 倍程度である。
  - 非操作 3 科目(c = 0)では、u・v の分け方が一意でないので数えていない。
