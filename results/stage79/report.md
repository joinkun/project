規則は `criteria.md`(コミット b8142c1、計算の前に記録。§7 の追記はコミット 4a3e237 で、指標を見る前)。表は `comparison_report.md`、数値は `summary.json`、コストの診断は `costs.md`、Sinkhorn の減衰は `sinkhorn_decay.md`。ステージ75 の `scripts/stage75_*.py`・`results/stage75/` は変更していない。

**結論**:

- **規則(§6)の上では、A1・F1 だけが「R1・F1 の置き換えの候補」になった。ただし差は実質的にない。私は置き換えないことを勧める**(§4)。
  - R1・F1 との純資産の改善の差は fold ごとに +0.001〜+0.006。符号はそろうが、大きさは R1・F1 とステージ69 の差(class 2 で +0.095)の 1/20 以下である。
  - A1 は、事前の予想どおり R1 のほぼ定数倍だった(A1 / R1 の中央値 1.43、log の相関 0.997)。λ̃*_f も全 fold で R1 と同じだった。
- **A2(2 区間の区分線形)は、R1・F1 より劣る。** class 2 の純資産の改善は −0.040(4 fold で有意に下)。
  - 52 方向中 37 方向で、大きい区間の傾きが小さい区間より小さく(凹)、「大きく動かすほど単位あたり安い」コストになった。指示文の想定(大きく動かすほど高い)とは逆である。
- **スパース OT は、カットオフなしで候補を 5 社(中央値)に絞れた。しかし主指標は R1・F1 と変わらない。**
  - 実効サポートが class 1 で 2.97 / 2.99 と、条件 4 の下限 3 をわずかに下回った。
  - R1・SP-F1 は、class 2 の fold f4 で違反が 1 社出た。
  - 少額科目の膨張は、class 2 で 12.7% → 11.3% とわずかに下がる。
- **Sinkhorn の確率の減衰(指示 2-1)**:
  - 全体の 25〜27% の p_ij は厳密に 0(アンダーフロー)。コストの順位で 50 位の候補の p は中央値で 10⁻²⁹〜10⁻³⁴。
  - 一方で、累積 90% に必要な候補数は中央値で 10〜11 社(最大 82〜187 社)。**現行の「累積 0.9・最大 10 社」は、ほとんどの行で上限の 10 社に当たっている**(表の \|S(i)\| = 10 / 10)。

  - 輸送のコストは中央値で割り、λ は s で尺度をそろえるので、共通の倍率は結果に効かない。違いは、倍率のばらつき(分布の形)の分だけである。

  - 「小さく動かす区間は面積が大きいので安く、大きく動かす区間は高い」という指示文の想定は、区間ごとのハザードで測ると、多くの科目で成り立たない。

## 2. スパース OT(`src/fsgen/models/sparse_transport.py`)

- 行で正規化した p について、min Σ pC̃ + (γ'/2)‖p‖² + (τ'/2) Σ_j (r_j − 1)² を解く。制約は行の単体で、同一企業の組は 0 に固定する。
- 解法は、行ごとの単体への厳密な射影をもつ加速射影勾配法と、勾配による再始動。
  - 最初は関数値による再始動にしていたが、最適解の近くで丸め誤差のために再始動を繰り返して収束しなかった。そこで変更した。
  - cvxpy の解との一致(10⁻⁶)、厳密な 0 の存在、未収束での例外をテストした(`tests/models/test_sparse_transport.py`、7 件)。
- **列の罰則の強さ τ' を、計算の途中で変えた**(criteria §7)。
  - 当初の τ'(釣り合いのまわりで KL の曲率に合わせた値)では、1 社の全質量を 1 つの対応先が受けるときの勾配が KL の 16 倍になった。その結果、候補が 43 社に散った。
  - 変更後の τ' は、その負荷で KL と勾配が等しくなる値である。
  - **列の罰則を KL のままにすると、空の列の勾配が −∞ なので行はスパースにならない**(各行が約 n1/n0 社に散る)。指示文の第 1 案の目的関数では、スパースな解は得られない。
- **|S(i)| の中央値は、γ' = 10⁻⁴〜0.02 でほぼ 5 のまま変わらない**(`sparse_gamma_*.csv`)。
  - 候補の数を決めているのは、主に列の罰則(対応先の容量)である。
  - 規則どおり、中央値が 5 に最も近い最小の γ' を選んだ。多くは γ' = 10⁻⁴。
- 実効サポートは 2.9〜3.8(Sinkhorn の F1 は約 5)。|S(i)| の最大は class 2 で 20〜25、class 1 で 12〜15。

## 4. 判断(要決定)

規則上は A1・F1 が「置き換えの候補」だが、**私は R1・F1 のままにすることを勧める**。理由は 3 つある。

1. 差が小さい。純資産の改善で +0.001〜+0.006 で、区間が 0 をわずかに外れる fold が多い。
2. A1 は R1 のほぼ定数倍で、違うのは分布の形による小さな補正だけである。新しい原理の効果とは言いにくい。
3. 4 つの設定を同時に比べており、1 つが偶然「優れる」になる可能性を割り引く必要がある(多重比較の補正は事前に決めていなかった)。

置き換えるかどうかは、ご判断ください。置き換える場合は、案 a と同じ作り方(57 社の全体の A1 のコスト、λ̃ = 0.1)の単一の生成を作り、ステージ77 の検算をやり直します。

## 5. 想定と違った点

1. A2 は凹になる方向が多く、「大きく動かすほど高い」にはならなかった。
2. スパース OT の候補の数は、γ' ではなく列の罰則で決まった。KL の列の罰則では、スパースな解は原理的に得られない。
3. Sinkhorn の現行のカットオフは、ほとんどの行で上限の 10 社に当たっている。累積 0.9 は実際には効いていない。
4. 当初の τ' の決め方は誤りで、計算の途中で変えた(指標を見る前、criteria §7)。
