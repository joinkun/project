## 結論

1. **採用しない。最終設定は変えない。**
   - 実データから機械的に決めた θ = 0.0091 は、ほとんど拘束しない(class 2 で 55 社中 3 社、class 1 で 131 社中 2 社)。
   - 生成の払込資本の動きは、ほぼ変わらない。
   - **基準 2(主)を満たさない**: 生成で払込資本を減らす企業は 82%(class 2)・83%(class 1)。実際に再建した企業は 36% [Wilson 16〜61%]・23% [14〜35%]。
2. **問題は減らし方の深さではなく、減らす企業の多さである。**
   - 生成で減らした企業の比の中央値は 0.81・0.86(浅い減少)。実際に減らした再建企業は 0.57・0.65 で、生成より深い。
   - 実在する最も深い減少まで許す下限(p1)は、浅い減少を多数行う生成を止められない。
   - 減らす企業の割合を実データに合わせるには、大半の企業で減少を禁じる必要がある。しかしそれは「実データを禁止しない」(スペック G)に反する。
3. **α(資本金の下限)は θ では置き換えられない。**
   - α を外した設定 3 では、資本金を 0 にする企業が class 2 で 11 社、class 1 で 20 社に戻る(α ありは 0 社・1 社)。
   - θ は合計にしか効かないので、資本金を資本剰余金に振り替えて 0 にすることを止めない。
4. **主指標・違反は変わらない**(両設定とも違反 0、主指標の差 0)。

## 2. A.4 θ と根拠

- **θ = 0.009149**。
- 事前の規則は「再建群で減少した企業の比の p1、30 社未満なら class 1+2」。再建群で減少した企業は 24 社なので、class 1+2 で減少した 51 社の p1 を使った。
- 再建群だけの減少の最小は 0.174。class 1+2 には払込資本をほぼ全額減らした企業(比 < 0.1 が 1.2%)がいるため、θ は極めて小さくなった。
- 生成の前に「ほとんど拘束しない」と予想し、`criteria.md` §6 に記録した。規則のとおりに決めたので動かしていない。
- **期間の限界**(D.2): 2 年の分布から決めた θ を 5 年の経路に課しているので、保守的な方向である。今回は θ がほとんど拘束しないので、結果への影響はない。

## 8. 想定と違った点

1. **生成の問題は「深く減らすこと」ではなく、「多くの企業が浅く減らすこと」だった。** 再建群は、減らす企業が少なく、減らすときは深い。生成は逆で、多くの企業が少しずつ減らす(主に、欠損填補の振替による)。下限という形の制約は、この問題に効かない。
2. **再建群で減少した企業は 24 社しかなく、θ は class 1+2 から決まった。** class 1+2 の p1 は、ほぼ全額の減少(0.009)を許す。
3. **α は θ の代わりにならない**(資本金を資本剰余金に移して 0 にできるため)。
4. **実データでは、健全企業も非再建群も払込資本をあまり減らさない**(減少 20〜30%)。生成の 82〜83% は、どの集団の実データからも遠い。

## 次に考えられること(実施しない)

- 減らす企業の多さは、ステージ46 で示したとおり、対応先の払込資本比率が始点より低いこと(76% の企業)から来る。速度場がその方向を学び、射影の γ の範囲で振替に変わる。
- **頻度を実データに合わせるには、下限ではなく、「減らすかどうか」を決める離散的な仕組み**が要る。
  - 例: 実データの減少の割合に合わせて、一部の企業にだけ減少を許す。
  - ただしこれは、企業ごとに禁止を割り当てることになり、「実データを禁止しない」との兼ね合いを先に決める必要がある。
