## 1. 輸送(A)

- **コスト**: 非対称 L1(中央値の尺度、ε0 = 0.001)。class 2 は D_rec 57 社、class 1 は 15 社(参考値)の c±。C̃ = C / median(C)。
- **始点**: class 2 55 社、class 1 132 社(評価は 128 社)。**目標の候補**: class 0 の 3,768 社。
- **方式**:
  1. バランス OT: `ot.sinkhorn` の対数領域、ε ∈ {0.001, 0.005, 0.02, 0.1}。参考に厳密解 `ot.emd`。
  2. 不均衡 OT: τ0 = ∞、τ1 ∈ {0.001, 0.01, 0.1, 1, 10}(C̃ の単位)× ε の 4 通り。
  3. 片側制約: 行ごとに exp(−C̃/ε) を正規化(τ1 → 0 の極限)。ε の 4 通り。
  4. 最近傍: argmin_j C̃_ij。
- **健全性**: 収束、反復回数、質量 0 の行、最小行質量、輸送質量、実効サポート(中央値・p90・最小・最大)、計算時間。未収束は例外(表に「失敗」と書く)。
- **採用候補から外す設定**: 未収束、質量 0 の行がある、輸送質量 < 0.5。
- **最近傍との一致**: 最大質量の対応先が最近傍と同じ行の数。一致しない行について、次を報告する。
  - 最近傍の対応先と argmax の対応先
  - C̃ の差
  - 払込資本比率の差
