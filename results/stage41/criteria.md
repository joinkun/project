# ステージ41: 不活性制約の選定規則と判定基準(生成の前に記録)

ここまでに見たのは、実データの割合(`rates.md`)と、現行の最終設定(ステージ31・34 の出力)の割合だけで、
不活性制約を入れた生成はまだ行っていない。

## A. 定義

- **始点 0**: \|x\| / 総資産 < 1e-6(`INACTIVE_ZERO`)。生成では始点の総資産で割った値(tilde 空間)で判定する。
- **終点 非0**: \|x\| / 総資産 > 1.001e-3。残余の下限 −1e-3 は「0 から丸め許容を引いた値」なので、
  下限にちょうど張り付いた値(ソルバ誤差で 1e-3 をわずかに超える)を非0 と数えない。1e-3 のままだと、
  現行の生成で純資産その他の「0 → 非0」は 29 / 51 行と数えられるが、29 行すべてが下限への張り付きだった。
- 実データの割合 r は、推定用パネルの class 1+2(始点の年度のラベル)の 1 年の割合。生成の始点は class 1・2 なので
  この母集団を使う(class 0 は参考)。class 1+2 の組は科目によって少なく(例: 棚卸資産 29 組)、区間が広い。

## A.2 選定規則(`scripts/inactive_select_stage41.py`、結果は `selection.md`)

**規則 S(採用、設定 2)**:

| r | 扱い |
|---|---|
| 5% 未満 | 課す |
| 5〜20% | 規則 M で決める(「数値を見て決める」を機械的な規則に置き換えた) |
| 20% 超 | 課さない |
| 推定不可(始点 0 の組がない: 現金、投資その他の資産、利益剰余金) | 課さない |

**規則 M(機械的な代案、設定 2b として参考に出す)**: 5 年換算 r5 = 1 − (1 − r)^5 と、現行の生成の割合 g
(class 1+2 の行)を比べ、r5 < g / 2 なら課す。「0 に固定したほうが、g のままより実データに近い」科目に課す。
r5 は毎年独立とみなした値で、0 のまま留まる企業が多いほど実際の 5 年の割合は小さい(r5 は上限寄り)。

**閾値 5% の根拠について**: スペックの 5% は 1 年の割合への閾値だが、生成は 5 年(t = 1)で、1 年 5% は
独立とみなすと 5 年で約 23% に当たる。つまり 5% は生成の期間では「稀」とは言い切れず、根拠は弱い。
実際、規則 S では流動資産その他(r = 4.7%、r5 = 21%、現行の g = 18%)に課すが、0 に固定すると
実データの 5 年換算からは現行より遠ざかる可能性がある。規則 M はこの期間の違いを考慮した代案である。

**選定結果**: 規則 S は 17 科目、規則 M は 4 科目(規則 S の部分集合)。

- 規則 S: 資産その他、売上債権、貸倒引当金(流動)、流動資産その他、貸倒引当金(固定)、固定資産その他、仕入債務、
  未払金、1年内償還予定社債、負債その他、社債、非支配株主持分、純資産その他、自己株式、株主資本その他、
  その他有価証券評価差額金、評価・換算差額等その他
- 規則 M: 売上債権、固定資産その他、自己株式、評価・換算差額等その他
- 5〜20% の 10 科目(棚卸資産、その他流動資産、有形固定資産、無形固定資産、短期借入金、その他流動負債、
  流動負債その他、長期借入金、固定負債その他、資本剰余金)は、規則 M ですべて「課さない」。
- スペックの想定との対応: 自己株式は課す(r = 0%、0 / 78)。**社債は課す**(r = 1.5%、想定「課さない」と違う)。
  長期借入金は課さない(5.3%)。非支配株主持分は課す(1.9%)。貸倒引当金は流動・固定とも課す(2.9%・3.0%)。

## B. 実装

- 制約: 企業ごとに、始点 0 の対象科目を射影の等式制約で**始点の値に固定する**(`frozen_accounts` に加える)。
  始点の値は \|x\| < 1e-6 × 総資産で、0 との差は無視できる。非0 → 0 は禁じない(始点で非0 の科目は対象外)。
  毎ステップ射影(最終設定と同じ)。
- チェック 15「不活性科目が動いた」: `INACTIVE_ACCOUNTS`(規則 S)のうち始点 0 の科目が、始点の値から
  総資産比 1e-6 を超えて動いた。制約と同じ定義。設定 2b(規則 M)は規則 S の 13 科目を固定しないので、
  チェック 15 に掛かりうる(参考の設定なので必須条件の対象外)。

## C.2 指標

- **必須**: 15 項目の違反 0。
- **主(妥当性)**: 「0 → 非0」が実データに近づくか。
  - 科目別の割合(生成 g と、実データ r・r5・2 年)を並べる。課していない科目の悪化(相殺の付け替え)も見る。
  - **企業ごとの乖離** dev_i = \|E_i − Ê_i\|。E_i は企業 i で「0 → 非0」になった科目の数(seed の中央値)、
    Ê_i = Σ(始点 0 の科目 a) r5_a(実データの 5 年換算の期待値。推定不可の科目は 0)。
    企業単位のペア比較(設定 − 1)の差の中央値と 95% ブートストラップ区間。
- 主(改善): 純資産の改善、債務超過の解消率。
- 主(実行可能性): \|総資産変化\|、sparsity(総資産比 1% を超えて動いた科目数)。
- 副: validity(LightGBM)、proximity、符号付き順位相関(ステージ39 と同じ実データ)。
- 実行可能性の報告: 企業ごとの不活性科目の数の分布、10 科目以上の企業の数と動けているか、`infeasible` の件数、
  ほとんど動けない企業(seed の中央値で \|\|x1 − x0\|\|₂ < 0.01)、アクティブな制約の集計。

## D.1 採用基準

1. 15 項目の違反 0(両 class)。
2. 「0 → 非0」が実データに近づく: dev の差(設定 2 − 1)が両 class で有意に負。
3. 主指標が大きく悪化しない。**許容の案(数値)**: 純資産の改善の差の中央値 ≥ −0.02(現行の中央値 0.19〜0.23 の
   約 10%)、\|総資産変化\| の差の中央値 ≤ +0.02(ステージ19 で規模制約の採否を保留した悪化幅と同じ)。
   これを超える場合は判断を保留する(スペックの通り)。

1〜3 を満たせば設定 2 を採用する。2b・3 は参考で、採否は判定しない。
