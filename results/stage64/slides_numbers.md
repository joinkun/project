# ステージ64 発表資料の数値(OT の枠組み)

## OT の定式化(スライド: 手法)

- μ0 = (1/n0) Σ δ_{x_i}(苦境企業)、μ1 = (1/n1) Σ δ_{y_j}(健全企業、3,768 社)
- π* = argmin Σ π_ij c(x_i, y_j) − εH(π) + τ1 KL(πᵀ1 ‖ μ1)、始点側は厳密に保存(τ0 = ∞)
- 目標 τ_i = 最大質量の対応先(実在企業)
- 地上コスト: 非対称 L1(方向別の重み)。一般のコストを許す定式化なので c(x, y) ≠ c(y, x) でよい
  - **「既存のリコースでは対称性が強制される」は書かない**(最近傍でも非対称コストは使える)
  - 定理の出典(Villani 2009 など)は、原典の該当箇所を確認してから書く

## なぜ素朴な OT では駄目か

| | class 2 | class 1 |
|---|---:|---:|
| 下限 n1 / n0 | 68.5 | 28.5 |
| バランス OT の厳密解の実効サポート | 68.8 | 28.9 |
| その argmax が最近傍と一致 | 0 / 55 | 1 / 132 |
| バランス OT の argmax を目標にした生成: 純資産の改善 | 0.279 | **0.000**(λ̃ = 30 でしか違反 0 にならない) |

## 不均衡 OT で局所性を回復した結果

| | class 2 | class 1 |
|---|---:|---:|
| 実効サポート(中央値) | 1.3 | 17.2 |
| 最大質量の対応先が最近傍と一致 | **54 / 55(98%)** | **109 / 132(83%)** |
| 異なる対応先の数(最近傍 → 不均衡 OT) | 50 → 51 | 120 → 132 |
| 生成の主指標の差(対 最近傍) | なし | なし |

- 記述: 「OT の枠組みで解き、この設定では最近傍にほぼ帰着した。一致しない対応先は、混雑(複数の始点が同じ企業に集まる)を避けたもの」

## 重心を使わない理由

| 目標 | 識別 AUC(LightGBM) |
|---|---:|
| 実在企業の無作為抽出 | 0.47 |
| 最近傍 | 0.73 / 0.68(class 2 / 1) |
| 不均衡 OT の argmax | 0.71 / 0.64 |
| 無作為な 2 社の平均 | 0.92 |
| バランス OT の重心 | **0.995 / 0.999** |

- 原因はゼロの構造(未払金がゼロの企業: 実データ 40%、2 社の平均 14%)
- 注記: 生成の主指標では、重心は class 2 で劣らず(0.394 対 0.329、有意差なし)、class 1 で劣る(−0.051)
