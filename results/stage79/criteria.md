# ステージ79: 決定と規則(計算の前に記録)

「移動量 ÷ 区間面積」のコスト(A1・A2)と、2 次正則化のスパース最適輸送を、ステージ75 と同じ D1(57 社の 5 分割の交差適合)で比べる。

**本ステージでは置き換えを決めない。** 比較の結果と、下の §6 の「置き換えの候補」に当たるかだけを報告する。

## ここまでに見たもの

- ステージ78 までの全結果。
- 本ステージの設計のために、`RecourseQP` の API を読んだ。c± は定数として組み込まれるので、候補ごとに傾きを変えるには候補ごとに QP を作り直す必要がある。
- **新しいコスト・輸送計画・生成・指標は、どれも計算していない。**

## 1. プールと記号(ステージ75 と同じ)

- コストのプール: 57 社(class 1 → class 0、2022 → 2024)。fold f のコストは、57 社から fold f を除いた約 45 社で推定する。fold の分け方は `data/interim/stage75/weights.json` の `folds`(乱数 0)。
- Δ_ka = 総資産比の構成の差(R1 と同じ `prep_stage59.deltas`)。
- d_ka = |x_{k,0,a}| + σ_a、σ_a = max(σ_a^pool, 10⁻³)。
- 向き ± に動いた企業の規格化した幅 Z = |Δ_ka| / d_ka。n± = 動いた企業数。
- m± = Z の中央値、F± = Z の経験分布関数。

## 2. コスト

**A1(方向の面積 × 区間の面積)**:

- P± = n±/N。n± = 0 のときは c = 10³(下限 1/(N + 1) を使っても W が定義できないため)。
- W± = ∫_0^{m±} (1 − F±(t)) dt。経験分布では、これは mean(min(Z, m±)) に等しい。
- c± = min(1/(P± W±), 10³)。評価差額金は c = 0(凍結)、利益剰余金は輸送と QP の移動コストで 0(従来どおり)。

**事前の予想**: 条件付きの幅 Z が指数分布(尺度 θ)なら、W = θ/2、median = θ ln 2 なので、A1 = (2 ln 2) × R1 ≈ 1.386 × R1(全科目・両方向で共通の倍率)になる。

- 輸送のコストは中央値で割り、λ は s で尺度をそろえるので、共通の倍率は結果に効かない。
- したがって A1 と R1 の違いは、Z の分布の形が指数分布から外れる分(W/m の比が科目・向きでばらつく分)だけになる。

**A2(2 区間の区分線形)**:

- 小さい区間 [0, m±] の傾き c₁± = A1 の c±。
- 大きい区間 (m±, ∞) の傾き c₂± = min(1/(P± W₂±), 10³)、W₂± = ∫_{m±}^∞ (1 − F±(t)) dt = mean((Z − m±)₊)。
- 解釈: 区間ごとに一定のハザード h_k = (区間の質量 1/2)/(区間の生存面積 W_k) を置くと、c_k = 2 h_k / P±。指数分布なら c₁ = c₂(無記憶性)。
  - **裾が重いと c₂ < c₁**(大きく動かすほうが単位あたり安く、凹)になる。ステージ49(Subbotin の b < 1)からは、多くの科目でこうなると予想する。指示文の想定(大きく動かす区間ほど高い)とは逆になりうる。その割合を報告する。
- **指示文の「区間面積密度(質量 ÷ 幅)の逆数を傾きにする」は採らない。** 密度の逆数は幅の次元をもつ。そのままでは、典型的に大きく動く科目ほどコストが高くなり、R1・A1 と向きが逆になるためである。
- 始点 i の科目 a の移動 t = |Δ| の費用は Ψ_a(t) = c₁ min(t, b_ia) + c₂ (t − b_ia)₊。区切り b_ia = m± × d_ia、d_ia = |x_{i,a}| + σ_a。
- **輸送**: C_ij = Σ_a Ψ_a(|x_j,a − x_i,a|)(向きに応じた c± と m±)。凸でなくてよい。
- **QP(F1 の候補ごと)**: 候補 j の目標までの移動 t_ij,a で評価した平均の傾き ĉ_ij,a = Ψ_a(t_ij,a)/t_ij,a(t = 0 なら c₁)を、その候補の QP の c± に使う。QP は候補ごとに凸である。

## 3. 輸送計画

**Sinkhorn(ステージ75 と同じ)**:

- 片側不均衡 OT、ε = 0.001、τ1 = 0.05。C̃ = C / median(C[~mask])、同一企業の組は C̃ = 10 max C̃。
- 候補 S(i) = 行の確率の上位で、累積 0.9 まで(最大 10 社)。

**スパース OT(新規、`src/fsgen/models/sparse_transport.py`)**:

- 行で正規化した p_ij = n0 P_ij で書く。
  - min Σ_ij p_ij C̃_ij + (γ'/2) Σ_ij p_ij² + (τ'/2) Σ_j (r_j − 1)²
  - 制約: p ≥ 0、Σ_j p_ij = 1
  - r_j = (n1/n0) Σ_i p_ij(列の相対的な負荷、1 = 釣り合い)
- 列の罰則は 2 次とする。τ' = τ1 × n0/n1(τ1 = 0.05)。
  - Sinkhorn の τ1 KL(q‖b) の、釣り合い q = b のまわりでの 2 次近似(曲率)に合わせた値。
  - 元の尺度では、γ = γ' n0、2 次の列の罰則の係数 τ = τ' n1²/n0 にあたる。
- 解法: 行ごとの単体への厳密な射影をもつ加速射影勾配法(FISTA、再始動つき)。射影なので、解は厳密に 0 の成分をもつ。
- 収束の判定: 不動点の残差 max |p − Π(p − ∇F/L)| ≤ 10⁻¹¹ と、目的関数の相対変化 ≤ 10⁻¹³。上限 200,000 回で未収束なら例外。
- 同一企業の組は、その行の候補から除く(p = 0 に固定)。
- γ' の選び方: 格子 {0.001, 0.002, 0.005, 0.01, 0.02, 0.05, 0.1, 0.2, 0.5, 1} から、class・fold・コストごとに、行の非ゼロ数 |S(i)| の中央値が 5 に最も近いもの(同点は小さい γ')。ラベルを使わない選び方なので、リークはない。中央値が [3, 8] に入らなければ、その旨を報告する。
- F1 の候補 S(i) = {j : p_ij > 0}、重み p̃_ij = p_ij(行の和は 1)。**事後のカットオフはしない。**

**Sinkhorn の減衰の診断(指示 2-1)**: 57 社の全体の R1 で、両 class について次を出す。

- コストの順位 1・5・10・50・100 位の候補の p_ij の大きさ(log10 の中央値・最小・最大)。
- 確率の上位から累積 90%・99%・99.9% に達する候補数。
- 厳密に 0(アンダーフロー)の割合。

## 6. 置き換えの候補(報告だけ。決定はユーザー)

次をすべて満たす設定を「R1・F1 の置き換えの候補」として報告する。

1. ステージ75 の 4 条件を満たす。条件 4 の「統合 ≥ 3」は、実効サポートの中央値 ≥ 3 とする。
2. R1・F1 と比べて、両 class で主指標のどれも「劣る」でない。
3. R1・F1 と比べて、少なくとも 1 つの class で 1 つ以上「優れる」。

- 候補が複数あれば、L_f の fold 平均が小さい順に並べる。
- 候補がなければ、R1・F1 のままとする。
