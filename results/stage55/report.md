# ステージ55 報告: 実際の遷移から距離を学習する(距離の探索の最終試行)

- 判定基準: `criteria.md`(学習の前に記録、コミット b408675)
- 表: `data_a.md`(A)、`accuracy.md`(B.4・D.2)、`weights.md`(B.5)、`comparison.md`(C.2、項目別の違反)、`power.md`(C.3)、`judgment.md`(D)、`bs.md`

## 結論

1. **採用しない。最終設定は変えない。スペック G に従い、距離の探索を打ち切る。**
   - 基準 0(順位精度が 50% を有意に上回る)は満たした: 0.888 [0.825, 0.943]。
   - しかし、学習した重みで生成すると **class 2 が大きく悪化**した。
     - 純資産の改善 0.238 → −0.000(差 −0.164 [−0.221, −0.135])
     - 順位相関 −0.122(有意に悪化)
     - 違反 11 行
   - class 1 は有意差なし。違反 4 行。
2. **学習した距離は、「再建で動く科目を無視する」距離だった。**
   - 重みが 0 になった科目: 現金、短期・長期借入金、有形固定資産、投資その他の資産、資本金、資本剰余金、1 年内償還予定社債、流動資産その他(29 科目中 9)。
   - これらは、実際の再建で 2 年の間に大きく動く科目である。「自社の 2 年後」を他社から見分けるには、動く科目を無視するのが最善になる。
3. **その距離で対応先を選ぶと、資本構成が合わない対応先になる。**
   - 払込資本を無視するので、対応先の払込資本比率の中央値は 0.833 → **0.149**。
   - 生成は払込資本を取り崩して欠損を消すだけになり、純資産が改善しない。**ステージ50 と同じ失敗**である。
   - 現行の等重み距離は、払込資本・借入金という金額の大きい科目を暗に合わせていた。
4. **順位精度の高さの大部分は、学習の効果ではない。**
   - 無作為の負例では、等重みでも 0.949(学習 0.944、差なし)。「企業は 2 年後も自分に似ている」ことで説明できる(A で事前に指摘)。
   - 学習が等重みに勝つのは、等重みで近い順に選んだ負例(近い企業)に対してだけ(+0.247)。等重みの点数がそこで低いのは、負例を等重みで選んだことによる、構成上の結果である。

**スペック G の「失敗の仕方」で言えば、「距離は(順位の上では)学習できるが、生成は改善しない(悪化する)」に当たる。** ただし学習できたのは「移りやすさ」ではなく、「再建で何が動くか」である。それを対応先の選択に使うと、動く科目が合わない対応先が選ばれる。

## 8. 想定と違った点

1. **学習した距離は、再建で動く科目(現金・借入金・有形固定資産・払込資本)を 0 にした。** 「自社の 2 年後」を見分けるには、動かない科目で照合するのが最善だから。
2. **その距離は、対応先の選択では有害だった。** 払込資本を無視するため、払込資本の小さい対応先を選び、生成が振替だけになる(ステージ50 と同じ機構)。
3. **現行の等重み距離の「良さ」は、金額の大きい科目(払込資本・借入金)を暗に合わせることにある。** ステージ50・55 の 2 つの失敗が、同じことを逆側から示している。
4. **順位精度は、学習しなくても高い**(無作為の負例で 0.949)。正解データ(自社の将来)と、生成での使い道(他社を選ぶ)の食い違いのため、基準 0 は距離の良し悪しを測れていなかった(A で事前に指摘)。
5. **過去の推定とは一致しない**(持続性と無相関、頻度とは逆向き)。どれも「再建で動く科目」の扱いが違う。異なる方法が同じ結論に至ることはなかった。
6. **class 2 の評価から外れる企業は 0 社だった。** 再建群の企業は、生成の始点ではなく、対応先の候補(class 0)の側にいる。

## 距離の探索(ステージ21〜55)のまとめ

| 方法 | ステージ | 結果 |
|---|---|---|
| 文献値・部分調整・定性・頻度・持続性の重み | 24〜26・32・36・39 | 等重みに勝てない |
| 変化率の分布の尤度コスト | 50 | 払込資本比率の低い対応先 → 純資産の改善 0 |
| 健全企業の密度 + 距離(周辺・条件付き) | 52・54 | class 1 だけ改善、class 2 は差なし |
| 実際の遷移から学習した重み | 55 | 払込資本を無視 → 純資産の改善 0 |

**等重み最近傍を最終とする。**

- 重みを工夫すると、金額の大きい科目(払込資本・借入金)の一致が崩れ、生成が「振替だけの再建」に寄る。
- 生成結果は制約(特に利益剰余金の上限 γ)に強く支配されており、対応先の資本構成が、振替と利益の配分を通じて結果を決める。
