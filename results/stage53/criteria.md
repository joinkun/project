# ステージ53: PL(健全企業の密度)を評価指標とするかの判定基準(評価の前に記録)

ここまでに見たもの: ステージ52 の B.4.1(class 0・1・2 の PL の中央値)と、既存の出力ファイルの有無。
生成の出力の PL、過去の判定の再計算は、まだ行っていない。新しい生成はしない。

## 1. 指標の定義

- **PL(x) = log q(x)**。q はステージ52 の版 I(`data/interim/stage52/density/indep.npz`)。
  - 科目ごとに独立なゼロ確率 + null(Cᵀ) の座標の条件付き正規(Ledoit-Wolf)。
  - 学習データは除外後の class 0 **3,768 書類**(スペックの 3,951 は除外前の数で、学習には使っていない)。
- **評価する状態**: 各時点の BS を、**その時点の総資産で割った値**。
  - 生成の parquet の x0・x1 は始点の総資産で割った値なので、x / Assets(x) で割り直す。
  - 実データは各年度の総資産で割る。
- **ゼロの判定**: 総資産比の絶対値が 1e-6 未満を 0 とみなし、ちょうど 0 に置き換えてから評価する(INACTIVE_ZERO と同じ)。
  - 射影の解は、0 に固定した科目でも 1e-12 程度の誤差を持つため。
  - 実データには 0 < \|x\| < 1e-6 の値はほとんどない。
- **併記する 3 つ**(A.2):
  - 生の PL
  - 始点との差 ΔPL = PL(x(1)) − PL(x(0))
  - class 0 の分布での分位点
- **分位点の基準**: class 0 の 5 分割交差検証の hold-out の PL(3,768 社、ステージ52 と同じ分割)。学習データでの値は楽観的になるので使わない。
- **経路(A.3)**:
  - 生成は Euler 法 1 ステップで、途中の時点は始点と終点の線形補間(ステージ48)。t ∈ {0, 0.25, 0.5, 0.75, 1} で評価する。
  - **単調増加**: 隣り合う時点の PL の差がすべて −1e-6 以上。行(企業 × seed)で数え、企業単位(3 seed の 2/3 以上)でも出す。

## 2. 構造上の限界(評価の前に確認した事実)

- **PL は貸借一致の破れを検出できない。**
  - 版 I の連続部分は z = Uᵀx(null(Cᵀ) の座標)だけを見る。恒等式を破る成分(C の方向)は捨てられる。
  - スペック C.2 の「先行研究方式(恒等式残差 0.51)の PL は極端に低いはず」は、定義上成り立たない。
  - 先行研究方式(ステージ5)と第 1 層のみ(ステージ17)の出力は、このマシンにない(`data/interim/stage5`・`stage17` が存在しない)。新しい生成はしない方針なので、測定しない。
- **代わりに C.3 は、既存の parquet にある「射影前の Flow Matching の出力」(`method = FM`)で行う**。恒等式は満たすが、符号・小計・第 2 層の制約は課していない。
  - ステージ17 の「第 1 層のみ」(恒等式と符号の射影)とは違い、符号の射影もない。より制約の弱い参照である。
  - 15 項目の違反数と PL の関係を見る。

## 3. 妥当性の検証(B)と判定(B.5)

- **B.1 順序**: 中央値で、class 0(hold-out)> class 1(137)> class 2(55)。
  - 参考に、再建群の終点(class 2 → 回復 15 社、class 1 → class 0 57 社。2024 年度末)と始点(2022 年度末)も出す。
- **B.2 validity との関係**:
  - 比べる量: 終点の PL の分位点と、validity(LightGBM・RF・LogReg)の企業単位の Spearman 相関。
  - 対象: class 2 で、§4 の既存設定のうち validity を計算できるものをまとめた企業 × 設定(seed の中央値)。最終設定の中だけの値も併記する。
  - **「強く相関」= LightGBM との \|ρ\| ≥ 0.7(まとめた方で判定)**。
  - 純資産の改善・proximity との相関も報告する。
  - 識別 AUC は集合単位の量で、企業単位の値がない。そのため企業単位の相関は計算しない(設定単位で比べられる値も、現行の指標ファイルにはない)。
- **B.3 循環性**:
  - 最終設定の class 2(55 社)で、各社の対応先(全社の計画の最近傍 y_j*、実在の class 0 企業)の PL と、終点の PL を比べる。
  - **「ほぼ一致」= Spearman ρ ≥ 0.8**。差の中央値と、終点が対応先を上回る社数も報告する。
  - class 1 は対応先を持たないので対象外。
- **B.4 振替の検出(主の検定)**: 生成ではなく、会計の操作として作った「振替だけの状態」で測る。
  - 対象: class 2 の始点のうち利益剰余金が負の企業。
  - 欠損 −RE(0) を、資本剰余金、次に資本金(資本金の下限 α = 0.00199 × 始点まで)から填補する。振替額 T = min(−RE(0), 資本剰余金(0) + (1 − α) 資本金(0))。
  - 他の科目は動かさない。純資産は変わらない。
  - ΔPL = PL(振替後) − PL(始点)。
  - **「振替で上がる」= ΔPL の中央値 > 0 かつ片側 Wilcoxon(ΔPL > 0)p < 0.05**。
  - **参考**: スペックの方法(生成の出力のうち \|ΔNA\| / A < 0.01 の企業の ΔPL)と、ステージ29 の R4 γ = 0(`data/interim/stage29/r4`、純資産の改善 0 で validity が上がった設定)の ΔPL も出す。ただし、これらは振替以外の科目も動くので、判定には使わない。
- **B.5 判定**(スペックの表を、この優先順で当てる):
  1. B.3 で循環(ρ ≥ 0.8)なら **採用しない**。
  2. B.4 で振替で上がるなら **採用しない**。
  3. B.1 の順序が成り立たなければ **採用しない**。
  4. B.2 で validity と強く相関するなら **副指標として併記**。指標の数を増やさないため、validity を外して PL に置き換えるかを提案する(置き換えはユーザーの判断)。
  5. どれにも当たらなければ、**主指標に加える**。
- **D(過去の判定の再検証)は、PL が主指標に加わる場合だけ行う。**
  - 4 指標(純資産の改善、解消率、順位相関、終点の PL の分位点)で、「2 つ以上で有意に優れ、劣るものがない」で判定する。
  - 有意は、企業単位のペアの差の中央値の 95% ブートストラップ区間で判定する。

## 5. 訂正(評価の後に追記): ゼロの判定

§1 の「総資産比の絶対値 1e-6 未満を 0 とみなす。実データには 0 < |x| < 1e-6 の値はほとんどない」は**事実と違っていた**。

- 実データの事実:
  - class 0 には 0 < |x| < 1e-6 の値が 6,413 個あり、3,768 社中 2,160 社に含まれる。主に丸め差の残余である。
  - 1e-9 未満の非 0 の値は 1 つもない。
- この規則のまま評価すると、class 0(学習データ)の PL が 31.1 から 22.0 に下がる。実データを丸めない交差検証の基準(30.7)と、評価する点が食い違う。
- 生成の状態の事実:
  - 射影の解なので、始点 x(0) にもちょうどの 0 がない。
  - 1e-12〜1e-7 の解の誤差と、1e-7〜1e-6 の本当の小さな値が重なる。

**訂正した規則**(結果を見て決めたもの。その旨を報告する):

- 実データ(class 0・1・2、パネル、振替の操作で作る状態、対応先)は丸めない。密度の推定・交差検証の基準と同じ扱い。
- 生成の状態 x(t) は、次の 2 つを 0 にする。
  - 始点の実データでちょうど 0 の科目で、\|x\| < 1e-6 の値
  - 全科目で \|x\| < 1e-9 の値(実データの非 0 の最小より小さい)
- 当初の規則での結果も `results/stage53/raw_snap/` に残す(`pl_stage53.py --raw-snap`)。
- **B.5 の判定は、どちらの規則でも同じ(「振替で上がる」で採用しない)**。B.4 の主の検定は、訂正後は実データを丸めずに測り、当初の規則でも結果はほぼ同じ(ΔPL の中央値 +2.62、p = 0.0034)。
