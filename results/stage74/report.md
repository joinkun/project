## 4. 相対移動コストの検証(指示 2)

**(a) 資本金の増減コスト(`costs.md`、57 社のプール)**:

| | 差分(総資産比) | 対数変化率(名目) |
|---|---|---|
| n⁺ / n⁻(増加 / 減少した企業) | 21 / 36 | 13 / 10 |
| c⁺ / c⁻ | 92.1 / 31.2 | 5.82 / 0.36 |
| c⁻ / c⁺ | 0.34 | **0.06** |

- 名目の対数変化率で測ると、「総資産の拡大による見かけの減少」は消える(減少 36 → 10 社。名目が変わらない 34 社は数えない)。
- しかし減資は、起きるときの対数の幅が大きい(半減以上)。そのため、縮小の尺度が大きく、**c⁻ が最も安くなり、減資を促す**。
- BS 表(`bs.md`)でも、B1 はジェイホールディングスの資本金を 200 → 97 に半減させる。
- 「名目で測れば減資の誤認が消え、減資が抑えられる」という予想は、半分だけ成り立ち、コストの比はむしろ逆向きになった。

**(b) 少額科目の膨張**:

- 差分のコストの F1 は、始点で 10⁻⁶〜10⁻³ の科目を 10⁻³ 超に膨らませる(A1 で 4.7% / 17.3%、基準は 2.0% / 2.2%)。
- 相対・ハイブリッドではほぼ 0(0.0〜1.1%)。始点で 1/|x| に比例して高くなるコストが、少額科目を固定する。

**(c) 主指標**: §2。

- ハイブリッド(B2)は純資産の改善が両 class で基準より高く(+0.039 / +0.023)、膨張もない。しかし class 1 の順位相関が有意に劣る。
- 相対(B1)は、λ̃ = 3 で動きが小さく、改善しない。
- 指示文の注意 3(相対コストは金額の大きい科目を軽く扱う)は、B1 の class 1 の順位相関の低下(+0.304)と整合する。

## 5. A-4: `enforce_inactive` の整理

- `projection_qp.project_onto_feasible(enforce_inactive=True)` のゼロの判定を、`x_start == 0.0` から **|x| < `INACTIVE_ZERO` × |総資産(始点)|**(`plausibility.inactive_accounts` と同じ)に変えた。固定する値も、0 から始点の値に変えた。
- `DeprecationWarning` を出し、`frozen_accounts=inactive_accounts(...)` を案内する。
  - 対象の科目は全基礎科目のまま(`INACTIVE_ACCOUNTS` の 4 科目ではない)。このため非推奨とし、科目の範囲は変えていない。
- テストを更新し、しきい値の挙動を確かめるテストを 1 つ追加した(`tests/accounting/test_projection_qp.py`)。
- ステージ60〜74 の生成は `enforce_inactive` を使っていない(既定 False)ので、結果は変わらない。

## 6. 想定と違った点

1. **ステージ72 の採用は、リークに依存していた。** 72 社のプールを提案したのは指示だが、私はステージ60 の分離(`ot_stage60.py` の「D.4 の母集団の分離」)を確認せずに統合を実装した。その時点で重複を指摘すべきだった。
2. **リークの経路は、コストより較正にあった。** class 1 のコストに較正の目標と同じ企業を入れると、λ̃*_0 = 0.3(大きく動かす)が選ばれ、class 2 の改善もそこから来ていた。
3. **10 社のプールは推定の情報が少ない**(34 / 62 方向が代替)。リークをなくすと、class 1 のコストはほぼ一様になる。
4. **対数変化率のコストは、減資を最も安くする**(上記)。
5. 基準(ステージ69)自体も class 1 の参照と 5 社重なる。完全にリークのない基準での比較は、まだしていない。
