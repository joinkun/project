# ステージ56: 払込資本の下限の決め方と採用基準(実データの集計・生成の前に記録)

この時点では、払込資本の比の分布(A)はまだ集計していない。θ の値は、下の規則で A から機械的に決め、生成の前に §6 に追記する。

## 1. 払込資本と比

- 払込資本 = 資本金 + 資本剰余金(**名目額**)。比 = 払込資本(2024 年度末)/ 払込資本(2022 年度末)。
- 2 年の変化。5 年には換算しない。推定用パネルの 2022・2024 年度の書類の当期の値を使う。
- 集団はステージ51 の A.1 と同じ(`results/stage51/asset_change.csv`):
  - 再建群 class 2 → 回復 15 社、class 1 → class 0 57 社
  - 非再建群 class 2 → class 2 30 社
  - 健全企業 500 社
- 始点の払込資本が 0 以下の企業は、比を定義できないので除く(件数を報告する)。
- 「増加」= 比 > 1、「減少」= 比 < 1。ちょうど 1 は「不変」。

## 2. θ の決め方(A.4)

- **案 1: 再建群(72 社)で払込資本が減少した企業の比の 1 パーセンタイル**(numpy の線形補間)。
  - 理由: α(資本金の下限)をステージ46 で決めたのと同じ方法(減少した組の比の p1)。
  - 実在する減少のほぼすべてを許す、最も緩い案(スペック G「実データを禁止しない」)。
- **標本が少ない場合**: 再建群で減少した企業が **30 社未満**なら、class 1+2(2022 年度に class 1 か 2、ステージ28 の除外規則に当たらない企業)の 2022 → 2024 で減少した企業の比の p1 を使う(ステージ46 と同じ母集団)。
  - 30 社未満では、p1 は実質的に最小値になり、1 社の値に依存するため。
- **期間の限界**: 2 年の分布から決めた θ を、5 年の経路(t = 1)に課す。5 年ならもっと減らせるはずなので、保守的(厳しい)方向である(D.2)。

## 3. 制約(B)

- **定義**: (資本金 + 資本剰余金)(x) ≥ θ × (資本金 + 資本剰余金)(x_start)。
  - 始点の払込資本が 0 以下なら、始点の値まで緩める(他の第 2 層の制約と同じ扱い)。
  - 合計に課す。資本金と資本剰余金の間の振替は自由。
  - 毎ステップ射影で課す。
- **チェック項目は追加しない**(B.3)。
  - 射影で保証されるので、チェックにすると循環する(ステージ44・51 の整理)。γ・β・α と同じ扱い。
  - 拘束された社数は、アクティブな制約の集計で報告する。

## 5. 採用基準(D.1)

設定 2・3 をそれぞれ設定 1 と比べる。

| # | 基準 | 定義 |
|---|---|---|
| 1 | 15 項目の違反 = 0 | 項目別に報告 |
| 2(主) | **払込資本の減少が実データの範囲に収まる** | 下の注を参照 |
| 3 | 主指標が悪化しない | 純資産の改善・解消率・符号付き順位相関のどれも、設定 1 より有意に劣らない(ステージ51 の有意の定義) |
| 4 | class 1 と class 2 の両方で成立 | |

**基準 2 の定義**(循環しない量で測る):

- 生成で「払込資本を減らした企業」の割合が、対応する再建群で減らした企業の割合の Wilson 95% 区間に入ること。
- 対応する再建群は、class 2 が「class 2 → 回復 15 社」、class 1 が「class 1 → class 0 57 社」。
- 定義はステージ47 の `final_table.md` と同じ: 年率の変化(生成は 5 年で割る、実データは 2 年の和を 2 で割る)が、総資産比 −0.001 未満。
- 比の下限 θ は制約で保証されるので、比そのものでは判定しない(循環するため)。

**参考(判定に使わない)**: 払込資本を増やした企業の割合、減少の規模の中央値、振替のある企業の割合(年率の振替 > 0.001)を、実データと並べる。

**設定 2・3 の両方が基準を満たす場合**:

- 設定 3 を採るのは、資本金を 0 にする企業(始点で資本金 > 0、終点で総資産比 1e-6 以下)が 0 社のときだけ。ステージ47 で α を採った理由(資本金を 0 にする企業 22% → 0%)を失わないため。
- そうでなければ設定 2 を採る。

## 6. θ の値(A の集計の後、生成の前に追記)

**θ = 0.009149**(`paidin.md`、`theta.json`)。

- 再建群 72 社で払込資本が減少した企業は 24 社(class 2 → 回復 6、class 1 → class 0 18)で、§2 の 30 社に届かない。
- そのため、class 1+2(171 社)で減少した 51 社の比の p1 を使う。
- 再建群の減少の最小は 0.174 で、θ はそれよりはるかに小さい(払込資本の 99% の減少まで許す)。class 1+2 には、払込資本をほぼ全額減らした企業(比 < 0.1 が 1.2%)がいるため。
- **予想**: この θ はほとんどの企業で拘束しない。生成の払込資本の減り方は、ほぼ変わらないと考える。θ は規則のとおりに決めたので動かさない。
