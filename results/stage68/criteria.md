## 1. A: ステージ65 の未訂正の数値

ステージ65 は、手法ごとに λ̃*_0 を較正していた(違反 0 の中で L 最小)。class 2 はリーク、class 1 は正しい。訂正では、**手法ごとに class 1 で較正した λ̃*_0** を使い、その絶対値 λ = λ̃*_0 × s_c1 を class 2 に当てはめる。class 2 のグリッドでは λ̃_c2 = λ̃*_0 × s_c1 / s_c2 = λ̃*_0 × 1.09179(ステージ66 の設定 1 と同じ方法)。

| 手法 | class 1 の λ̃*_0(`stage65/metrics.md`) | class 2 に当てはめる λ̃ | 主張 |
|---|---:|---:|---|
| 2 第 1 層のみ | 1(提案の値を使う。手法 2 は較正しない) | 1.09179 | 主張 1 |
| 5 提案 | 1 | 1.09179(ステージ66 の設定 1 の生成) | 主張 6・7 の比較相手 |
| 6 バランス OT の argmax | 30 | 32.7538 | 主張 7 |
| 7 バランス OT の重心 | 3 | 3.27538 | 主張 6 |

- 指示文は「λ̃ = 1」としているが、class 1 で較正した値は手法ごとに違う(6 は 30、7 は 3)。**主の訂正値は手法ごとの class 1 の λ̃*_0** とする。
- 指示文どおりの λ̃ = 1(λ = s_c1)も、手法 6・7 について生成して並べる。
- 識別 AUC は目標だけで決まり、λ に依存しないので変わらない。

## 2. B: 目標の定義(`scripts/targets_stage68.py`)

- **D_rec**: 再建企業 72 社(class 1 → class 0 57 社、class 2 → 回復 15 社)。2022 年度と 2024 年度の BS(`panel.csv`)。
- **対応づけ**:
  - 始点 x_i に、非対称 L1(ステージ60 の c±、class ごと。非操作科目は 0)で最も近い再建企業 k* を選ぶ。
  - 同じ EDINET コードの企業は候補から除く(自分自身を除く)。
- **T0**: ステージ64 の不均衡 OT(τ1 = 0.01、ε = 0.001)の argmax(現行)。
- **T1**: 再建後の構成 x_{k,2024} / A_{k,2024} の中から最も近いもの。
- **T2**: 再建前の構成 x_{k,2022} / A_{k,2022} の中から最も近い k* の、実際の変化量を始点に足す。τ_i = x_i + (x_{k*,2024} − x_{k*,2022}) / A_{k*,2022}(名目の変化を、k* の始点の総資産で割る。総資産の変化を含む)。
  - 目標の値は、負になっても切り詰めない。QP の符号制約が終点を守る。
- **重複**: class 2 の 55 社と D_rec の重複は 0。class 1 の 132 社では 3 社(E02000、E02628、E02978、いずれも 2 → 回復群)。この 3 社は従来どおり評価から除き(128 社)、目標の候補からも自分を除く。
- **期間**: 生成の終点は従来どおり 5 年後とみなす(年率 = ÷5)。T2 の変化量は実データの 2 年分だが、尺度を変えない(T0・T1 と同じ扱い)。比較の限界として記録する。

## 4. B.5 判定(事前)

設定 3・4・5 のそれぞれについて、**設定 1(現行の最終設定)との企業単位のペア比較**で判定する(2,000 回のブートストラップ、95% 区間)。

1. **払込資本を増やした割合**の差の区間が 0 より上、かつ **ΔRE/ΔNA < 0.99 の割合**の差の区間が 0 より上(両方の設定で ΔNA > 0 の企業で比較)。**両 class で**成立すること。
2. 主指標(純資産の改善、債務超過の解消率、符号付き順位相関)のどれも、設定 1 より有意に劣らない(`Ctx.compare` の記号が「−」でない)。**両 class で**。
3. 15 項目の違反が、両 class で 0。

- 1〜3 をすべて満たす設定を採用候補とし、複数あれば class 1 の L が最小のものを採用する。
- どれも満たさなければ不採用。モデルの改良はステージ65(訂正版)で打ち切り、最終設定をそれで確定する。
- 設定 2(T0、m = 1)との比較は参考として報告し、判定には使わない。
