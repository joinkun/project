# 最終提案手法 F1(事後アンサンブル)の定式化(ステージ73、実装との対応つき)

式は、ステージ72 で採用した実装と一致させてある。記法・旧設定の制約の詳細・命題 1・2 は `results/stage69/formulation_final.md` を参照。旧設定と違う点だけを書く。

## 1. コスト(`scripts/stage70_weights.py`)

- **プール**: 再建企業 D_rec の 72 社(class 1 → class 0 57 社 + class 2 → 回復 15 社)。両 class の生成に同じものを使う。
- **尺度とコスト**:
  - Δ_ka = x_{k,2024,a}/A_{k,2024} − x_{k,2022,a}/A_{k,2022}、s_a^± = median{|Δ_ka| : ±Δ_ka > 0}。
  - **c_a^± = 1 / s_a^±**(ε0 なし)。
  - 残余科目(`__OTHER__*`)だけ c = min(1/s, 10³)。
  - n < 5 の方向は、n ≥ 5 の全方向の c の中央値で代替する。72 社では 62 方向中 2 方向(15 社のプールでは 12 方向)。
- **非操作**: その他有価証券評価差額金だけ(c = 0、凍結)。
  - 非支配株主持分は c = 1/s で動かす。
  - 利益剰余金は、QP の移動コストが 0(上限 γ だけ)。輸送のコストでも 0。
- **自分自身を除く**: 始点と同じ EDINET コードの再建企業(class 1 の 3 社)は、その始点の c± の推定から除く(71 社で推定)。

## 2. 輸送計画と候補集合(`scripts/stage71_ot.py`)

- **地上コスト**: c(x_i, y_j) = Σ_a [c_a⁺ (y_ja − x_ia)_+ + c_a⁻ (x_ia − y_ja)_+]。利益剰余金と評価差額金の c は 0。
- **正規化**: C̃ = C / median(C)。始点と同じ EDINET コードの候補(class 1 の 1 件)は、その組を C̃ の最大の 10 倍にして質量 0。
- **片側不均衡 OT**(τ0 = ∞): min_{P ≥ 0, P1 = a} ⟨P, C̃⟩ + ε KL(P ‖ a ⊗ b) + τ1 KL(Pᵀ1 ‖ b)。
  - a = 1/n0、b = 1/n1、**ε = 0.001、τ1 = 0.05**(`transport.solve_semi_unbalanced_normalized`)。
- **候補集合**:
  - p_ij = P_ij / Σ_j' P_ij'。
  - S(i) = p の大きい順に、**累積が 0.9 に達するまで(最大 10 社)**。
  - p̃_ij = p_ij / Σ_{k ∈ S(i)} p_ik。
  - 実効サポート 1/Σ p̃² の中央値は 6.93(両 class)。

## 3. 生成(`scripts/stage72_qp.py` の `f1`)

各候補 j ∈ S(i) について、凸 QP を解く(`RecourseQP`):

$$y^{(i,j)} = \arg\min_{y \in \mathcal{F}_i^+} \ \tfrac{1}{2} \sum_a w_a (y_a - y_{ja})^2 + \lambda \sum_{a:\, c_a^+ > 0,\, c_a^- > 0} (c_a^+ u_a + c_a^- v_a), \qquad y - x_i = u - v \ (\text{同じ } a),\ u, v \ge 0$$

- w_a = 1 / (max(σ_a^pool, 10⁻³)² m_a²)。m = 10(資本金・資本剰余金)、それ以外は 1。
- 移動コストの変数は、c_a⁺ と c_a⁻ がともに正の科目だけにある。利益剰余金(c = 0)は第 1 項と制約だけで決まる。

**事後アンサンブル**:

$$y_i^* = \sum_{j \in S(i)} \tilde{p}_{ij}\, y^{(i,j)}$$

**λ**:

- λ = λ̃ × s。s = median_i [Σ_j p̃_ij · ½ Σ_a w_a (y_ja − x_ia)² / Σ_j p̃_ij Ψ(y_j − x_i)](class 1 の始点)。Ψ(d) = Σ_a c_a^± |d_a|。
- **λ̃*_0 = 0.3**(class 1 の 128 社で、違反 0 の中で L 最小)。s = 0.1002。class 2 に同じ λ。

**ソルバ**:

- CLARABEL → OSQP(高精度)→ ECOS の順に試す。
- status = optimal かつ制約違反 ≤ 10⁻⁷ max(1, |x|) の解だけを受け入れる。それ以外は例外。

## 4. 𝓕_i⁺

ステージ69 の 𝓕_i(第 1 層、固定、不活性 4 科目、第 2 層の 24 本の線形不等式)から、次の 2 点を変える。

- 凍結は評価差額金だけ(非支配株主持分の凍結を外した)。
- **負債の上限を追加**: L(y) ≤ (1 − 10⁻⁶) max(2 L(x_i), 0.01 A(x_i))(L(x_i) ≤ 0 なら課さない)。
  - 項目 5(負債が 2 倍超)を満たす集合に、QP の許容(10⁻⁷)より大きい余裕を入れたもの。
  - 余裕なしでは、境界の数値誤差が項目 5 の違反と判定された(ステージ71)。

## 5. 性質

1. **実行可能性**: 各 y^(i,j) ∈ 𝓕_i⁺。𝓕_i⁺ は凸多面体なので、凸結合 y_i^* も 𝓕_i⁺ に入る。
   - 貸借一致・符号・凍結・不活性・負債の上限など、𝓕_i⁺ の全制約を満たす。
   - 実測の貸借の残差は 8 × 10⁻¹⁴ / 4 × 10⁻¹⁴(中央値)。
2. **一意性**: 各 QP の目的関数は y について強凸(全 w_a > 0)なので、y^(i,j) は一意。したがって y_i^* も一意(S(i) と p̃ が決まれば)。
3. **ゼロの保存**: 科目 a が全ての候補の解で y_a^(i,j) = 0 なら、y_a^* = 0。
   - 逆に、どれか 1 つの候補で動けば非ゼロになる(和集合)。
   - 実測の終点のゼロ(|y| < 10⁻⁶)は 7.38 / 7.48 で、健全企業の 6.70 以上。1 社の目標(9.4 / 9.3)よりは少ない。
4. **補間**: x_i ∈ 𝓕_i⁺ なら、z(t) = (1 − t) x_i + t y_i^* は全時刻で 𝓕_i⁺ に入る。但し書きはステージ69 の定理 1 と同じ(始点の丸め誤差と、有形固定資産が負の各 1 社)。
5. **15 項目のチェック**は 𝓕_i⁺ と同じではない。
   - 項目 3・4・11 は制約に入っておらず、凸結合でも保証されない。終点で検査し、F1 では両 class で違反 0。

## 6. 事前に混ぜる方法との違い

- QP の解写像 τ ↦ y*(τ) は区分的にアフィンで非線形なので、Σ_j p̃_ij y*(y_j) ≠ y*(Σ_j p̃_ij y_j)。
- 事前に混ぜる(L2 重心・重み付き中央値)と、目標がキメラになる。
  - L2 重心: ゼロの数が 3.3 / 2.5、識別 AUC 0.94 / 0.96。
  - 重み付き中央値: 貸借の残差が 0.04 / 0.05。
- ただし、QP の後の終点は、どちらも貸借一致とゼロを保つ(`results/stage72/contrast.md`)。
