## 1. 生成側の規則

1. **負債の上限(安全マージンつき)**: L(y) ≤ (1 − 10⁻⁶) × max(2 L(x_i), 0.01 A(x_i))。L(x_i) ≤ 0 の始点には課さない。始点 y = x_i で満たす。
   - **他のチェックとの許容の確認**: 項目 2・8・9・12・13・14・15 は許容 10⁻⁶ 以上、項目 6・7 は 10⁻³ で、QP の許容(10⁻⁷)より大きい。
   - 許容なしで制約の境界と一致しうるのは、**項目 1(資産合計が負、制約は資産 ≥ 0)**だけ。マージンは入れない(指示の範囲外)。違反が出たら報告する。
2. **終点のゼロ**: |y_a| < 10⁻⁶ × A(x_i)(`INACTIVE_ZERO` と同じ)を 0 とみなす。
3. **共通**(ステージ70・71 の新設計):
   - 72 社のコスト c = 1/s。評価差額金だけ凍結し、非支配株主持分は動かす。利益剰余金の移動コストは 0。自分自身を除く。
   - 制約は s47_final + 現金の下限 + 負債の上限(マージンつき)。第 1 項は全 32 科目、w = 1/max(σ, 10⁻³)²/m²。
4. **候補集合 S(i)**(ステージ71 と同じ): p_ij の大きい順に累積 0.9 まで、最大 10 社。p̃ = 正規化した重み。
5. **λ**:
   - λ = λ̃ × s。s は設定ごとに class 1 で、ステージ71 と同じ定義(F1 は Σ p̃ D / Σ p̃ Ψ、それ以外は D(x, τ)/Ψ(τ − x))。
   - グリッドは 10 点。**λ̃*_0 は class 1(128 社)だけ**で選ぶ(違反 0 の中で L 最小)。class 2 に同じ λ を当てはめる。

## 3. 指標

- 違反(15 項目)、純資産の改善(設定 4 との差 [95%])、解消率、払込資本↓・↑、変更科目数、順位相関(設定 4 との差)。
- 統合した企業数: p̃ の実効サポート 1/Σp̃² の中央値。1 社の目標は 1。
- **目標の性質**:
  - QP が参照する目標の識別 AUC。F1 は、全始点の候補 y_j(j ∈ S(i))を集めた集合の AUC。1 社の目標は、その集合の AUC。
  - 目標のちょうど 0 の科目数と、貸借の残差 |Cᵀτ|(F1 は候補の平均)。
- **終点の性質**: |y| < 10⁻⁶ を 0 とみなした科目数、貸借の残差。

## 4. 判定(事前)

**F1(設定 1)の採用**: 次をすべて、**両 class で**満たすこと。

1. 15 項目の違反が 0(`plausibility.py` のまま)。
2. 統合した企業数の中央値 ≥ 3。
3. 目標の識別 AUC ≤ 0.762(class 2)/ 0.736(class 1)、かつ終点の 0 とみなす科目数の平均 ≥ 6.70。
4. 主指標(純資産の改善・解消率・順位相関)のどれも設定 4 より有意に劣らず、**その class で少なくとも 1 つが有意に優れる**。

- 満たせば、F1 を新しいメイン手法として採用する。

- 設定 2(m = 1)が同じ条件を満たすかも報告する。両方満たせば、事後選択のない設定 2 を優先する。
- 指示文の「両 class で … 少なくとも 1 つで有意に優れる」は、class ごとに少なくとも 1 つと読む(厳しい方の読み)。
- 他の設定は比較のためで、判定の対象にしない。
