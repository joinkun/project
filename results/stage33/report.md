## 2. A.2 推定できない科目

非対称性(§5)で推定できない科目は 8 個、有意でない科目は 5 個。

## 3. A.3 序列(ρ1 の降順、`tables.md`)

上位: 有形固定資産 0.984 > 利益剰余金 0.979 > 棚卸資産 0.975 > 未払金 0.973 > 仕入債務 0.971 > 資本剰余金 0.963 > 売上債権 0.951 …

想定された序列 現金 < 売上債権 ≈ 棚卸資産 < 有形固定資産 < 無形固定資産 との対応:

| 想定 | 結果 | 合うか |
|---|---|---|
| 現金が最も動く | 現金 0.940 は 5 科目の中で(無形を除き)最も低い | ○ |
| 売上債権 ≈ 棚卸資産 | 売上債権 0.951 < 棚卸資産 0.975 | おおむね(棚卸資産のほうが持続的) |
| 有形固定資産は持続的 | 0.984 で全科目の 1 位 | ○ |
| **無形固定資産が最も持続的** | **0.910 で 5 科目の中で最も低い** | **×** |

**無形固定資産が合わない理由**(推測を含む):

- 無形固定資産には、のれんとソフトウェアが含まれる。のれんは買収で一度に増え、減損で一度に減る。
  class 2 では ρ1 = 0.649 [0.461, 0.803] と大きく下がり、変化の p90 は class 0 の 4 倍(0.084 対
  0.019)だった。
- 総資産に占める割合が小さい(変化の中央値 0.0017)ので、小さな増減でも順位が入れ替わりやすい。

ほかに直感と合わない点:

- 未払金の高さ(0.973)はゼロの同順位によるもの(両年非ゼロでは 0.879)。
- 未払法人税等が低い(0.546)のは、毎年の利益に依存するフローに近い残高だからと考えられる。

## 4. A.4 集約比率との整合

| 集約 | ρ1 | 構成科目の ρ1 |
|---|---:|---|
| ATO = 売上高 / NOA | 0.950 | 売上高 / A 0.952、NOA / A 0.940 |
| NOA / A | 0.940 | 営業資産・負債の主な 9 科目: 0.847〜0.984(中央値 0.951) |
| FLEV = NFO / CSE | 0.943 | NFO / A 0.950、CSE / A 0.949 |
| NFO / A | **0.950** | 借入金・社債・現金の 5 科目: 0.693〜0.940(中央値 0.900) |
| 借入金 + 社債 / A | **0.950** | 短期借入金 0.895、長期借入金 0.920、社債 0.900、1 年内社債 0.693 |

- **NFO と有利子負債の合計では、集約した ρ(0.950)が構成科目のどれよりも高い。** 有利子負債の内訳は、
  借り換え(短期 ⇄ 長期)や、満期が近づいた社債・長期借入金の流動への振替で入れ替わる。その動きは
  合計では相殺される。**科目別の低い ρ の一部は、動かしたのではなく「区分が変わった」ことによる。**
- NOA では、集約した ρ(0.940)は構成科目の中央値(0.951)と同程度で、集約による押し上げは見られない。
- したがって「集約で個別のノイズが相殺され、持続性が高く見える」は、金融側では当てはまり、営業側では
  当てはまらない。ATO の 0.950 は、売上高 / A(0.952)と NOA / A(0.940)の持続性がともに高いことによる。

## 6. C.1 「動かせない」と「動かす必要がない」の切り分け

### (a) 変化の大きさの分布(1 年、|Δx| / 前期総資産)

| 型 | 科目(ρ1、変化ゼロの組の割合、p90) | 読み |
|---|---|---|
| ほぼ毎年動き、一部が大きく動く | 現金(0.940、0%、0.125)、売上債権(0.951、5%、0.066)、棚卸資産(0.975、8%、0.053)、有形固定資産(0.984、2%、0.049)、投資その他(0.945、0%、0.052) | 動かせるが、大きく動かす必要がない |
| 残高があるのに動かない企業が多い | **資本金(0.921、79%、ただし両年ゼロは 0%)**、資本剰余金(0.963、45%) | 動かせない(総会決議などの手続きが要る)可能性 |
| ゼロの企業が多く、ある企業では動く | 短期借入金(0.895、22%、うち両年ゼロ 17%)、長期借入金(0.920、25%、24%) | 借りていない企業が多い。借りている企業では動く |

**ρ が同程度(0.92〜0.95)でも、動き方は科目によってまったく違う。** ρ だけでは 2 つを区別できない
ことが、分布から確かめられた。

### (b) class 2 と class 0 の比較(ラベルは各書類の年度)

class 2 は 145 組(69 社)、class 0 は 10,184 組。class 2 の 95% 区間は企業単位のブートストラップ(1,000 回)。

- **class 2 の ρ1 が class 0 より有意に低い(区間の上端 < class 0 の値): 21 科目。** 有意に高いのは 2 科目
  (社債 1.000、自己株式 0.988)。これは class 2 ではほぼ全組がゼロで、同順位が生んだ値なので意味はない。
- 変化の大きさも class 2 のほうが大きい(中央値で 22 科目、p90 で 25 科目)。
- 例:
  - 現金: ρ1 0.946 → 0.709、p90 0.118 → 0.341
  - 短期借入金: 0.901 → 0.586、p90 0.070 → 0.253
  - **資本金: 0.932 → 0.858、p90 0.0016 → 0.442**
  - 資本剰余金: p90 0.010 → 0.551
- **資本金は、健全企業ではほとんど動かない(class 0 の p90 0.0016)が、苦境企業では大きく動く。**
  これは資本金が「動かせない」のではなく「普段は動かす必要がない」ことを示唆する。
- 注意: class 2 の変化には、自発的な施策だけでなく損失による受動的な変化(現金・利益剰余金の減少)も
  含まれる。「圧力下では動かせる」の証拠としては、資本金・資本剰余金・借入金のように、損失で自動的
  には動かない科目の結果のほうが強い。

**結論(できた範囲で)**: 持続性の高さの大部分は「動かす必要がない」ことによると考えられる。苦境
企業ではほとんどの科目が健全企業より大きく動く。ただし class 2 は 69 社で区間が広く、変化の原因が
施策か損失かは BS だけでは分けられない。

## 7. C.2 生成結果との対応

最終設定(R3 + 上限 0.757、57 社 × 3 seed)の |x1 − x0| / A0(5 年)を ρ1 と比べた。固定科目の 2 つ
(評価差額金・非支配株主持分)は除く。

| 比較(科目間の順位相関) | 値 |
|---|---:|
| ρ1 と生成の動き(30 科目) | **+0.695** |
| ρ1 と科目の大きさ(始点の \|x\| / A0) | +0.735 |
| ρ1 と実データ class 2 の動き | +0.693 |
| **ρ1 と、大きさで割った生成の動き(21 科目)** | **−0.397** |
| ρ1 と、生成の動き / 実データ class 2 の動き × 5(21 科目) | −0.340 |
| 参考: 実データ class 2 の動きと生成の動き | +0.922 |

- 素朴な相関は **正**(ρ が高い科目ほど生成でもよく動く)で、スペックの想定と逆だった。これは規模の
  影響である。ρ の高い科目(利益剰余金、現金、資本剰余金、有形固定資産)は金額が大きく、実データでも
  動く絶対量が大きい。ρ の低い科目は、ゼロの多い残余科目が中心である。
- **大きさで割ると相関は負(−0.40)になる。** 生成でも、持続性の高い科目は大きさの割に動かない。
  等重みでも、対応先(実在の健全企業)と流れ場(実データから学習)を通じて、持続性がある程度反映
  されている。重みを入れても主指標が変わらなかったこと(ステージ32)の説明の一つになりうる。
- ただし、この分析は 21 科目の順位相関で粗い。生成の動きは実データ class 2 の動きと強く連動する
  (+0.92)ので、持続性そのものではなく、科目ごとの典型的な動きの大きさを再現しているだけかもしれない。

## 8. 想定と違った点

- **無形固定資産は最も持続的ではなく、主要 5 科目で最も持続性が低かった**(のれんの買収・減損と推測)。
- **ゼロの同順位が ρ を大きく動かす。** 残余科目の低い ρ1(0.12〜0.47)は、0 と非ゼロの行き来によるもので、
  両年非ゼロでは 0.85〜0.99 と高い。未払金は逆に、ゼロの同順位で押し上げられていた。
- 集約による持続性の押し上げは金融側(有利子負債の内訳の入れ替わり)にだけあり、営業側にはなかった。
- 資本金は健全企業ではほぼ動かない(変化ゼロ 79%)が、苦境企業では大きく動く。
- 生成の動きと ρ1 の素朴な相関は正(+0.70)で、スペックの想定と逆だった。大きさで割ると負(−0.40)。
- class 2 の組は 145(69 社)で、スペックの 68 社 × 3 年より少ない。年度ごとの class 2 のうち、推定用
  パネルに 3 年分そろう社だけが入るため。

## 論文の記述案(スペックの F を数値に合わせて調整)

> 1 年ラグ順位相関(ATO 0.950、FLEV 0.943)は原典(0.947、0.937)とほぼ一致し、パネルの構築が妥当で
> あることを確認した。科目別の推定値を表 X に示す(有形固定資産 0.984 から未払法人税等 0.546 まで。
> ゼロの多い科目と差額で定義した残余科目は解釈に注意を要する)。ただし、高い自己相関は「動かせない」
> ことと「動かす必要がない」ことを区別しない(Ioannidis et al. 2003)。実際、GC 注記企業では 32 科目
> 中 21 科目で持続性が健全企業より有意に低く、資本金のように健全企業ではほとんど動かない科目も大きく
> 動いた。持続性に基づく重みは生成結果の比較でも等重みに対する優位を示さなかったため、本研究では
