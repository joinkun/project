# ステージ44: 判定基準(生成の前に記録)

目的は制約・低次元化を外すことではなく、必要性を数値で確かめること。外して悪化すれば、それが残す根拠になる。
「悪化したが外す」という判断はしない。基準は結果を見た後で変えない。

## 共通

- 比較の基準は最終設定(R3 + 上限 γ = 0.757、第 2 層、α = 0.5、β = 0.3、不活性制約 規則 M、K = 13 の PCA 基底)。
  1 要素だけ変える。seed 0/1/2、class 2(55 社)と class 1(131 社)。
- 主指標: 純資産の改善 ↑、債務超過の解消率 ↑、\|総資産変化\| ↓、sparsity ↓(HANDOFF §4 の主指標)。
- 実データとの乖離: 符号付き順位相関 ↑(class 2 は再建群 15 社の 2 年、class 1 は class 1 → class 0 の 1 年 68 組)。
- 「有意に悪化」: 企業単位のペア(seed の中央値)の差の中央値の 95% ブートストラップ区間が、悪い向きに 0 を含まない。
  順位相関は企業の同時復元抽出(1,000 回)の差の区間。
- 必須: 15 項目の違反 0(両 class、外れ値を除く)。

## A. 低次元化(PCA)

| # | 基底 | 次元 |
|---|---|---|
| 1 | B = U V_13(現行) | 13 |
| 2 | **B = U(PCA なし)** | 31 |
| 3 | B = U V_8 | 8 |
| 4 | B = U V_20 | 20 |

- U は null(Cᵀ) の正規直交基底: C(32 × 1、基礎科目だけの恒等式)の完全 SVD の、rank(= 1)を超える 31 本の左特異ベクトル
  (`orthonormal_basis`)。数値的な性質(\|\|CᵀU\|\|、\|\|UᵀU − I\|\|)を報告する。
- **判定: 設定 2 が両 class で 15 項目の違反 0、主指標で有意に悪化するものがなく、順位相関も有意に下がらなければ、
  「低次元化は不要」と判断し、構成の単純化を提案する**(採否はユーザー)。どれかが悪化すれば、低次元化が必要な根拠とする。
- 過学習(訓練損失と検証損失、検証損失が最小の epoch)と seed 間のばらつき(企業ごとの 3 seed の標準偏差の中央値)は報告する。
  学習は 50 epoch のまま(早期終了は新しい探索になるので行わない)。class 1 は検証用の分割がないので訓練損失だけ。

## B. 制約 (5)(8)(9)

実装上の対象: (5) は**資本金と資本剰余金**の両方に α × 始点の下限(スペックの表は資本金だけ)。(8) の「運転資産」は
**有形固定資産・棚卸資産・売上債権**の 3 科目に β × 始点の下限。(9) は ΔRE ≤ γ × 総資産(始点)。

| # | 設定 |
|---|---|
| 1 | 現行 |
| 2 | (5) を外す |
| 3 | (8) を外す |
| 4 | (9) を外す |
| 5 | (5)(8)(9) をすべて外す |
| 感度 | α ∈ {0, 0.3, 1.0}、β ∈ {0.5, 1.0}(β = 0 は (8) を外すのと同じ実装) |

**外してよい条件(すべて満たすとき)**: (i) 15 項目の違反 0(両 class)、(ii) 主指標で有意に悪化するものがない(両 class)、
(iii) 外した制約に対応する現象の実データとの乖離が、現行より大きくならない(両 class)、(iv) 順位相関が有意に下がらない。
**どれか一つでも満たさなければ、残す根拠とする。**

現象と乖離の定義(生成は 5 年、実データは 2022 → 2024 年度末の 2 年。期間の違いは報告に明記する):

- (5): 資本金(と資本剰余金)が始点の 50% を下回った企業の割合(3 seed の 2/3 以上で下回る企業)と最小の比率。
  実データ: class 1・2(2022 年度)の企業で、2024 年度末の資本金(資本剰余金)が 2022 年度末の 50% 未満の割合。
  乖離 = \|生成の割合 − 実データの割合\|。
- (8): 3 科目のいずれかが始点の 30% を下回った企業の割合(始点で保有する科目のみ)、現金 / 総資産 > 0.9 の企業数。
  実データも同じ定義。乖離 = \|生成の割合 − 実データの割合\|。
- (9): ΔRE / A の年率の分布(p50、p90、p99)。実データは再建群 15 社(年率)。乖離 = \|生成の p90 − 再建群の p90\|。

## C. 自己株式(会社法 461 条の近似)

分配可能額の代理 D = max(利益剰余金 + 資本剰余金 + 自己株式, 0)(準備金を区別できないので真の分配可能額より大きい)。
制約: x_自己株式(t) ≥ x_自己株式(0) − D(0)。

**C.4 近似の妥当性(生成の前に判定)**: 推定用パネル(1 年)で、自己株式が増えた組(\|自己株式\| の増加 > 総資産比 0.001)のうち、
増加額 > 前期末の D となった組の割合が **5% 以下なら妥当**とする。5% を超えれば近似が不正確として**制約を課さない**
(設定 2・3 は参考として生成するが、採用しない)。あわせて、利益剰余金が負の企業で自己株式が増えた件数を報告する。

| # | 自己株式の制約 |
|---|---|
| 1 | 不活性制約のみ(現行) |
| 2 | 不活性制約 + 分配可能額による上限 |
| 3 | 分配可能額による上限のみ |

**採用の条件(近似が妥当な場合)**: 設定 2 が (i) 15 項目の違反 0、(ii) 主指標で有意に悪化するものがない、
(iii) 既に自己株式を持つ企業での自己株式の増加(\|自己株式\| が総資産比 0.001 を超えて増えた企業の割合)が実データ
(class 1・2 の 2 年)に近づく。採用する場合、ステージ7 の方向制約(債務超過企業の自社株買い禁止)を包含するかを
始点で確かめ、包含するなら方向制約を外して統合する(制約の数を増やさない)。
