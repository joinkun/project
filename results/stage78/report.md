**結論: 主提案 R1・F1 の採用は変わらない。** argmax 系を、事前登録どおり F1 の尺度 s で生成し直して D1 を再評価した。

- R1・F1 は、全 fold・両 class で違反 0、4 条件を満たす。L_f の fold 平均は 1.88 のままで、ステージ75 と同じ判定になった(`d1_sF1/report_tables.md`)。
- F1 系の数値は、1 ビットも変わらない。

ただし、検算で新しく分かったことが 3 つあり、論文の記述に影響する。

1. **QP の終点そのものは、実在の健全企業とよく見分けられる。**
   - 終点の識別 AUC(LightGBM)は 0.975〜1.000 で、QP の前の目標(0.60〜0.75)よりずっと高い。

   - LogReg では 0.82〜0.86。
2. **R1 の尺度で測ると、空白地帯の減り方は小さい。** R1・F1 の class 2 の終点の空白地帯率は、Ψ60 では 76% → 36%、Ψ_R1 では 78% → 53%。
3. **回復率の四分位の単調減少は、合算(class 1・2)の 1 年では 3 尺度とも成り立つが、class 2 だけ・2 年では崩れることが多い**(class 2 だけは 1 年 93 件・2 年 45 件で少ない)。

## 3. R3 の定義(項目 3、`r3_compare.md`)

| | (A) 記録した定義(ステージ75 で使用) | (B) 式(7)どおり(規格化なし) |
|---|---|---|
| θ± | (1/N) Σ_k (±Δ^nom_k)₊ / (\|x_{k,0}\| + σ) | (1/N) Σ_k (±Δ^nom_k)₊ |
| c が上限 10³ に当たる方向 | 4 | **14** |
| 資本金の c⁻/c⁺ | 0.33 | 0.24 |

- log(c⁻/c⁺) の (A) と (B) の相関は 0.663、符号の一致は 23 / 31。
- **(A) を維持し、論文の式(7)を (A) に合わせる。** 理由は 2 つある。
  - (A) は、計算の前に記録した定義(`results/stage75/criteria.md` §1)である。
  - (B) は、少額科目で θ が 0 に近づき、上限に張り付く方向が多い。
- 結果を見て定義を選び直すことはしていない。(B) の生成・評価は行っていない。
- 命題 3 の記述は次のとおりにする。
  - (A) は、規格化した変化 z = Δ^nom/(\|x₀\| + σ) にモデル A を当てはめた最尤推定そのものである。
  - R1(z = Δ/(\|x₀\| + σ))と R2(z = Δ/σ)は、平均を中央値に替えた頑健版である。条件付きの幅が指数分布なら、(n±/N)·median は ln 2 · θ± の一致推定量になる。
  - ln 2 は全科目・両方向で共通なので、λ に吸収される。

## 6. 原稿に反映すべき式・数値(項目 5 の代わり)

原稿のファイルがないため、該当箇所の正しい内容を列挙する。

1. **3.2 節の対数カーネル**: 実装(`transport.solve_semi_unbalanced_normalized`)は log K_ij = −C̃_ij / ε + log a_i + log b_j(参照測度 a ⊗ b を含む)、C̃ = C / median(C)、ε = 0.001。
   - 指示文の「log K_ij = −C̃_ij/ε」は、参照測度の項を省いた形である。省くなら「参照測度 a ⊗ b に対する」と書き添える。
2. **3.4 節**: 旧ステージ72 の s = 0.1002・λ̃* = 0.3 を、次に置き換える。
   - s = 0.2824(案 a)、fold では 0.2520〜0.2975。
   - λ̃* = 0.1(fold の λ̃*_f = 0.03・0.1・3・0.1・0.1 の中央値)、λ = 0.02824。
   - s は、目標(F1 / argmax)によらず F1 の重み p̃ の下で計算する。表 3(a) の argmax の行は、ステージ78 の値(`d1_sF1`)に差し替える。
   - SE の補正: fold の L_f で、割合の指標(払込資本↓・RE↑)の復元抽出の SE が 0 のときだけ、√(p̃(1 − p̃)/n)、p̃ = (k + 0.5)/(n + 1) で置き換える(fold f2 の払込資本↓ で SE = 0.060)。これは計算の途中で追記した規則である(`results/stage75/criteria.md` §6)。
3. **式(7)(R3)**: θ±_a = (1/N) Σ_k (±Δ^nom_ka)₊ / (\|x_{k,0,a}\| + σ_a)。命題 3 の記述は §3 のとおり。
