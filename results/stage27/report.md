共通の設定: 等重み最近傍 + W1 + PCFM(毎ステップ射影)+ 第 2 層の制約 + α=0.5 + β=0.3、

## 1. A: 乱数種の修正の前後で主要な結論が保たれるか

乱数種の設定を `seeded_velocity_field`(種を設定してからネットワークを作る)に統一し、
**すべての生成スクリプト**(ステージ10〜26 で使ったもの)に適用した。テスト
`tests/models/test_flow_matching_seed.py` を追加。修正前は同じ設定の 2 回の実行が一致せず
(最大差: ステージ13 の生成 7.94、ステージ16 の生成 4.05)、修正後は完全に一致(差 0)。

再確認は現在の canonical(ステージ21 の統合後)と旧 costs.yaml(ステージ13〜19 と同じ)で、

  「PCFM は非学習ベースより良い」は、**validity と近さを両立する点で良い**と限定して書く必要がある。

### B.3 利益剰余金の変化の現実性(`re_change.md`、最重要)

t=1 を 5 年と解釈し、生成の ΔRE / A0 を 5 で割った年率を、推定用パネル(ステージ23、3 期の差分)の
年率と比べた。

| 系列 | 社数 | p5 | p25 | p50 | p75 | p95 | 年 30% 超 | class 2 の p95 超 | ΔRE>0 かつ 払込資本が減少 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 実データ class 2(GC 注記) | 57 | −0.817 | −0.340 | **−0.130** | −0.001 | +0.210 | 5.3% | 5.3% | 17.5% |
| 実データ class 0(健全) | 3,484 | −0.027 | +0.009 | +0.026 | +0.050 | +0.119 | 0.8% | 1.5% | 9.9% |
| 生成 R3 | 68 | +0.044 | +0.072 | **+0.110** | +0.216 | **+0.703** | **14.7%** | **26.5%** | **79.4%** |
| 生成 R3 + 上限 | 68 | +0.044 | +0.072 | +0.100 | +0.100 | +0.100 | 0% | 0% | 67.6% |

- **R3 の ΔRE は実データを大きく超える。** 実際の GC 注記企業は中央値で年 13% の欠損を積み増して
  いる(ΔRE>0 は 24.6% のみ)。R3 は 68 社すべてで RE が増え、中央値は健全企業の中央値(年 2.6%)の
  約 4 倍、4 社に 1 社は GC 企業の p95(年 21%)を超える。
- ただし実データの class 2 は「GC 注記企業全体」で、大半は再建していない。再建した企業に限った
  分布は手元になく、R3 の比較対象としては厳しすぎる側にずれている。それでも健全企業の p95
  (年 11.9%)を超える社が R3 では 4 分の 1 以上あり、非現実的と判断した。
- **R3 の ΔRE には利益でない振替が混ざる。** 生成の 79.4% の社で「RE が増え、払込資本が減る」
  (実データは 17.5%)。欠損填補の減資(資本金・資本剰余金 → 利益剰余金)と同じ形で、
  純資産は変わらない。モデルは利益による増加と振替を区別できない(B.4、E.2 のアマガサを参照)。

## 3. C: 利益剰余金の増加の上限

- 条件: RE(1) − RE(0) ≤ γ·A0(`PlausibilityConfig.re_growth_cap`、
  `src/fsgen/accounting/plausibility.py`。射影 QP の線形制約として毎ステップ課す)。
- **γ = 0.50 は生成の前に決めた**: 実データ class 2 の ΔRE/A の年率の p90(+0.0999)× 5 年。
  class 0 の p90(+0.084)× 5 = 0.42 も候補だったが、再建の経路は GC 企業の上位の回復に対応する
  ので class 2 を使った。γ を変えた感度分析はしていない。
- 効果: ΔRE の年率は最大 10% に収まる(実データの範囲内)。一方で **p50 = p75 = p95 = 0.100、
  つまり半数以上の社が上限に張り付く。** 分布の形は実データと違う(実データの上位 10% の回復を、
  生成では過半の社がしている)。上限の下での RE の増加は、学習した経路ではなく γ で決まっている、
  と読むべき。
- 改善は上限なしより下がる(純資産の改善 0.342 → 0.279、解消 12 → 9 社)。違反は 0 のまま、
  \|総資産変化\| と validity はほぼ同じ。

## 6. E.1・H: 判定

**採用の判断は、指標の良し悪しではなく、期間の定義から先に決める。**

1. **R1 は、t∈[0,1] を 5 年とする定義の下で非現実的である。** R1 は 5 年間 RE が 1 円も変わらない
   (利益も損失もない)ことを仮定する。実データで RE の変化が年 ±0.5% 未満の社は class 2 で
   10.5%、class 0 で 8.4% にすぎない。さらに R1 では純資産を増やす手段が増資しかなく、改善の
   規模はステージ26 で見たとおり小さい。
2. したがって RE を動かす(R3)。ただし R3 の ΔRE は実データを大きく超える(B.3)ので、実データから
   決めた上限 γ=0.50 を課す(C)。R2 は目標が RE の負の企業になり、再建の目標として意味をなさない
   ので採用しない。
3. 上記を決めた後で指標を見ると、R3 + 上限は必須条件(違反 0)を満たし、R1 より純資産の改善
   (+0.22)・債務超過の解消(2 → 9 社)・\|総資産変化\| が良く、proximity は悪い(始点から大きく動く)。

**推奨: R3 + 上限(γ=0.50)× baseline を主設定とし、R1 を感度分析として併記する。** R3 を採用する
理由は 1 であって、3(指標が良いこと)ではない。

判断が必要な点:

- **上限に過半の社が張り付く。** 主設定の RE の増加は、実質的に γ という仮定で決まる。γ の感度分析
  (例: class 0 の p90 由来の 0.42、class 2 の p75 由来の値)を追加するか。
- **利益と振替を区別できない。** 欠損填補の減資を明示的にモデル化しない限り、R3 の ΔRE は
  「利益 + 振替」の合計である。論文では限界として書く(下の記述案)。
- 旧重み・CAFM・非学習ベースとの比較は、今回 R1 の下で再確認したもの。R3 + 上限を主設定にするなら、
  ステージ13〜17 の比較を R3 + 上限で取り直すかどうか。

## 7. E.3: 論文の記述案

> 生成の時間 t∈[0,1] は 5 年に対応するものとする。利益剰余金の扱いについて二つの設定を比較する。
> 主設定では利益剰余金を固定せず、その増加に上限 RE(1) − RE(0) ≤ 0.5·A(0) を課す。上限は、
> 推定用パネルの GC 注記企業の利益剰余金の変化(総資産比、年率)の 90 パーセンタイル(0.0999)を
> 5 年分に換算して、生成の前に定めた。5 年間利益剰余金が変化しないという仮定は、実データでは約 1 割の
> 企業にしか当てはまらず、期間の定義と整合しないため、主設定では利益剰余金を動かす。
>
> 感度分析として、利益剰余金を固定する設定(R1)を示す。R1 は 5 年間の営業上の改善をゼロとみなす
> 保守的な設定で、純資産の改善は増資だけで表される。主設定は営業上の改善を含むが、上限なしでは
> 生成された利益剰余金の増加が実データの GC 注記企業の分布を大きく超える(年率の中央値 +11%、
> 実データは −13%)。上限の下でも過半の企業が上限に達しており、主設定の改善の規模は上限の仮定に
> 依存する。両設定の差(純資産の改善 0.279 対 0.017、債務超過の解消 9 社対 2 社)は、再建が営業上の
> 改善にどれだけ依存するかを表す。
>
> なお、生成された利益剰余金の増加には、資本金・資本剰余金からの振替(欠損填補の減資に相当)が
> 含まれ、本手法は利益による増加と区別しない。
