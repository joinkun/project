## 0. ユーザーの決定と、その前提の訂正

  - 1.16 は社債 2 科目の比の**上限**(ゼロ率が 86% あると、比は 1/0.86 ≈ 1.16 を超えられない)。独立の証拠ではない。
  - 基準率に左右されない相関 φ は 0.68 で、強く連動している。351 組中 82 組は独立の期待値の 2 倍以上(有形・無形固定資産は 28.7 倍)。
  - **版 I の独立の仮定は「32 科目を扱える唯一の近似」であって、「データで支持される」ものではない。**
- 訂正 2: 自己株式のゼロ率は class 0 で 8.6% なので、**18 科目の側(密度に入る側)にある**。ゼロ率の高い 14 科目は、社債 2 科目・非支配株主持分・丸め差の残余 3 つ・未払金・貸倒引当金 2 科目・評価・換算差額等その他・純資産その他・長期借入金・その他有価証券評価差額金・短期借入金。

## 2. 版 I: 32 科目・独立ゼロ + 条件付き正規

  log q(x) = Σ_a [ z_a log π_a + (1 − z_a) log(1 − π_a) ] + log N(x_S̄ | x_S = 0)

- π_a = class 0 でのゼロ率。[1/N, 1 − 1/N] でクリップする(N = 3,768)。
- **連続部分(前回の案 b)**:
  - z = Uᵀx(U は null(Cᵀ) の正規直交基底、31 次元)に、Ledoit-Wolf の縮小推定で正規 N(μ, Σ) を当てはめる。ゼロも値として含める。
  - パターン S の企業では、U_S z = x_S = 0 で条件付けた正規を、その零空間(次元 \|S̄\| − 1)の座標で評価する。
  - **恒等式の部分空間(次元 \|S̄\| − 1)に自動で入る**(B.2 の指示どおり)。
- 縮小係数を報告する。
- 既知の弱点:
  - ゼロを値として推定に含めるので、ゼロの多い科目の平均・分散が歪む。
  - パターンによって連続部分の次元が違うので、パターン間で log q を比べるとき、単位(密度の次元)が揃わない。ステージ50 の離散・連続の混合と同じ性質。

## 3. 版 II: 18 科目のパターン混合

- 科目: class 0 のゼロ率が 10% 未満の 18 科目。
- **パターン**: 18 科目でのゼロの集合。**M = 累積 80% に達する最小の数**(予備集計では 7)。
- **併合**: 上位 M に入らない class 0 の企業は、ハミング距離が最小の上位パターンへ併合する(同距離なら頻度の高い方)。π_S は併合後の社数 / N。
- **連続部分 q_S**:
  - パターン S にちょうど一致する企業だけで推定する(併合した企業は、ゼロの位置が違うので使わない)。
  - 18 科目の部分集合では恒等式が閉じないので、次元は \|S̄\| そのもの(−1 しない。B.2 の指示は 32 科目の場合)。
  - Ledoit-Wolf の正規。
  - 社数 < 10 × 次元 のパターンは、上位から外し、その企業を残りへ併合し直す(B.3 の基準)。
- **評価**:
  - パターンがちょうど一致すれば、その q_S で評価する。
  - 一致しなければ、併合先のパターン S′ で評価する。S′ で非 0 の科目のうち実際は 0 のものは 0 として評価し、S′ で 0 の科目のうち実際は非 0 のものは無視する(近似)。
- ゼロ率の高い 14 科目は、密度に入らない。

## 4. 検証(B.4)と停止の規則

版ごとに行う:

1. **B.4.1 class 別の尤度**: 1 社あたりの log q の中央値と四分位を、次の集団で出す。
   - class 0(学習に使った全社)
   - class 0 の 5 分割交差検証の hold-out(各社は、その社を含まない 4/5 で推定したモデルで評価)
   - class 0 の検証用 500 社(乱数 seed 0 で抜き、残りで推定)
   - class 1(137)
   - class 2(57、55)
2. **通過の条件**: 次の両方を満たすこと。
   - **中央値の順序**: hold-out の class 0 > class 1 > class 2
   - **class 2 が hold-out の class 0 より有意に低い**: Mann-Whitney の片側検定で p < 0.05
3. **通らない版は、C 以降を実施しない。**「密度は推定できたが健全性を識別しなかった」と報告する。
4. 交差検証の対数尤度、合成サンプルと実データの比較(各科目のゼロ率・非 0 の値の四分位、科目間の相関行列の差)も報告する。判定には使わない。
5. **B.4.2**: class 2 の各社のパターンの、class 0 のモデルでの確率 π_S を出す(中央値・最小)。
   - 版 I は Π_a の積。
   - 版 II は併合後の π(上位に入らないものは、ちょうど一致の割合も併記)。

## 5. 目標の設定(C、通過した版だけ)

- **実在企業から選ぶ(C.2 の案 1)**: j*(i) = argmin_j [ −log q(y_j) + λ d(x_i, y_j) ]。y_j は class 0 の全社(3,768)。
  - d は現行と同じ等重みの二乗距離(非操作 3 科目を除く 29 科目)。
  - 全社の計画と fold の計画を、現行の最近傍と同じ形で作る。
  - 密度は class 0 だけから推定するので、fold によらない。
- **連続最適化(案 2)は実施しない**。
  - 版 I はパターンの選び方が 2^32 通りの組合せになる。
  - 版 II は密度に入らない 14 科目が密度で決まらない。
  - 指示の「通らなければ案 1 のみでよい」に当たる。
- **λ**: λ = c · s、c ∈ {0.1, 0.5, 1, 5, 10}。
  - s = class 0 の −log q の四分位範囲 / 現行の最近傍の d(x_i, y_nn(i)) の中央値。
  - λ → ∞ で現行の最近傍に一致し、λ → 0 で密度最大の企業(全社共通)になる。
  - **選び方: 対応先の d の中央値が、現行の最近傍の 1.5 倍以内に収まる最小の c**(距離をあまり悪くせず、密度の重みを最大にする)。5 つすべてで C.2 の一致数と d・log q を報告する(トレードオフ曲線)。
- **C.2 のゼロパターンの一致**(全社の計画、57 社):
  - 始点と対応先のパターンが完全一致した社数(32 科目、丸め差の残余を除く 28 科目)
  - 対応先が、始点で 0 の科目を非 0 で持つ社数
  - 自己株式を持たない始点(16 社)のうち、対応先が自己株式を持つ社数
- **事前の予想**:
  - コスト −log q(y_j) + λd の密度の項は始点によらない。そのため、密度は「始点と同じパターン」ではなく「class 0 でよくあるパターン」を選ぶ。
  - 自己株式は class 0 の 91% が持つので、**密度の項は、自己株式を持つ対応先をむしろ有利にする**。
  - **C.2 の一致は、現行より改善しないと予想する**(版 I・II とも)。
