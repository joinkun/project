# ステージ61: λ の較正と、主張の再構成

**結論**
1. **λ は較正指標(払込資本・利益剰余金)には合わせられるが、較正に使わなかった指標には一般化しない。**
   - 事前の検証規則を満たしたのは、6 組(2 class × 3 距離)のうち 1 組だけだった。
   - 払込資本を減らす企業を実データ並みに少なくする λ(大)と、実データ並みに多くの科目を変える λ(小)が両立しない。
   - 単一の λ では、「多くの科目を動かすが、払込資本はめったに動かさない」という実際の再建を表せない。
2. **主の距離(等重み L2)では、較正した λ̃* = 3 で再建そのものが弱くなる。**
   - 純資産の改善は、class 2 で 0.072(λ̃ ≤ 0.1 では 0.26〜0.28)、class 1 で 0.020。
   - 債務超過の解消率は 0.50 と 0.17。
3. **距離の設計は λ に吸収されない。** 各距離の λ̃* で比べると、提案の非対称 L1 は等重み L2 より、両 class で純資産の改善と符号付き順位相関が有意に優れる。
   - 払込資本の割合の差は有意でない。
   - ただし class 2 では、非対称 L1 に違反が 4 社ある(等重み L2 は 0 社)。
4. **2 社の平均が区別できる主因は、ゼロの構造の崩れである。** ゼロかどうかだけで AUC 0.86〜0.89 になる。分散の縮みを戻しても、AUC は下がらない。
5. **OT の最大質量の対応先の AUC 0.49 は、「健全企業の典型」であることを示すだけで、良さの根拠にはならない。**
   - class 0 の無作為抽出の AUC は 0.47 で、定義上 0.5 付近になる。
   - 主指標では、最近傍を上回らない(ステージ60)。

## D.3 検証(A.4、較正に使わなかった指標)

事前の規則: λ̃* での検証指標が、(a) グリッドの上位半分に入り、かつ (b) λ̃ = 1 以上に実データに近いこと。

| class | 距離 | 順位相関 (a) / (b) | 変更された科目数(λ̃* での値 / 実データ)(a) / (b) | 成立 |
|---|---|---|---|---|
| c2 | 1 等重み L2 | ○ / ○(+0.351) | 9 / 16: × / × | × |
| c2 | 2 対称 L1 | ○ / ○ | 10 / 16: ○ / ○ | **○** |
| c2 | 3 非対称 L1 | ○ / —(λ̃* = 1) | 6 / 16: × / — | × |
| c1 | 1 等重み L2 | ○ / × | 5 / 14: × / × | × |
| c1 | 2 対称 L1 | ○ / —(λ̃* = 1) | 5 / 14: × / — | × |
| c1 | 3 非対称 L1 | ○ / × | 3 / 14: × / × | × |

- **順位相関は、6 組すべてで上位半分に入った。** 較正は順位相関を悪くしない。
- **変更された科目数は、6 組中 5 組で外れた。**
  - 実データの再建企業は、年率 0.2% を超えて 14〜16 科目を動かしている。
  - 較正した生成は 3〜10 科目しか動かさない。小さい λ(≤ 0.1)なら科目数は実データに近いが、そのとき払込資本の割合は 56〜84% になる。
- **規則による判定: 較正は「特定の指標を合わせただけ」に近い**(成立は 1 / 6)。
  - 原因は QP の形にある。移動コストが科目ごとに一様な強さで「動かすこと」を罰するので、「払込資本は動かさないが他は動かす」という実データの組合せを作れない。
  - ステージ59 A'.1 の「凸なコストは頻度を表せない」と同じ構造である。

## D.4 距離の設計による差(A.5)

各距離の λ̃* で、企業単位のペアの比較を行った。

| class | 比較(λ̃*) | 払込資本↓ の差 | 純資産の改善 | 順位相関 | 記号 |
|---|---|---|---|---|---|
| c2 | 非対称 L1(1)− 等重み L2(3) | −0.05 [−0.22, +0.11] | **+0.136 [+0.088, +0.187]** | **+0.251 [+0.003, +0.441]** | + 0 + |
| c2 | 対称 L1(0.3)− 等重み L2(3) | +0.04 [−0.11, +0.20] | **+0.183 [+0.075, +0.284]** | +0.048 [−0.112, +0.371] | + 0 0 |
| c2 | 非対称 L1 − 対称 L1 | −0.09 [−0.22, +0.04] | −0.024 [−0.051, +0.000] | +0.203 [−0.161, +0.343] | 0 0 0 |
| c1 | 非対称 L1(3)− 等重み L2(3) | −0.04 [−0.11, +0.03] | **+0.093 [+0.054, +0.135]** | **+0.262 [+0.077, +0.414]** | + + + |
| c1 | 対称 L1(1)− 等重み L2(3) | **+0.12 [+0.02, +0.21]** | **+0.099 [+0.057, +0.133]** | +0.038 [−0.131, +0.222] | + 0 0 |
| c1 | 非対称 L1 − 対称 L1 | **−0.16 [−0.23, −0.09]** | −0.000 [−0.029, +0.000] | **+0.224 [+0.084, +0.341]** | 0 0 + |

- **規則による判定: 距離の設計は λ に吸収されない(両 class)。**
- 払込資本の割合は、等重み L2 と非対称 L1 で有意差がない。これは λ に吸収される。
- 純資産の改善と順位相関は、非対称 L1 が等重み L2 より、両 class で有意に優れる。
  - 理由は 2 つある。L1 の移動コストは少数の科目に変化を集める(変更科目数 3〜6)。そして等重み L2 は、λ̃* では動かす量全体を抑えてしまう。
- ただし class 2 の非対称 L1(λ̃* = 1)は違反が 4 社ある(項目 3・4、独立のチェック)。等重み L2 は 0 社で、必須条件(違反 0)を満たすのは等重み L2 だけである。
  - class 1 の非対称 L1(λ̃* = 3)は 0 社。
- ステージ59・60 の「提案コストは L2 に劣る」は λ̃ = 1 での比較だった。λ を距離ごとに較正すると、主指標の向きが逆になる。**距離の比較は、λ をそろえるか較正するかで結論が変わる。**

## D.5 B.2: 2 社の平均が区別できる理由(`b2.md`)

class 0 から無作為に 500 組の 2 社を作り、その平均を実在企業と比べた(5-fold CV、3 回)。

| 特徴量 | AUC LightGBM | AUC LogReg |
|---|---:|---:|
| (iii) 元の値 | 0.918 | 0.472 |
| (i) ゼロかどうか(0/1)だけ | **0.863** | **0.892** |
| (ii) 分散の縮みを戻した値 | 1.000 | 0.845 |
| 参考: 実在企業の無作為抽出(55 社) | 0.471 | 0.538 |

- **主因はゼロの構造の崩れである。** 2 社の平均がゼロになるのは、両方がゼロのときだけである。そのため、ゼロの割合は大きく下がる。
  - 未払金は 40.3% → 14.2%、資産その他は 48.7% → 23.8%。
  - 32 科目のゼロの割合の差は、中央値 7.7 ポイント、最大 26.1 ポイント。
  - KS 統計量の大きい上位 6 科目(0.24〜0.26)のうち 5 科目は、実データでゼロが 31〜57% ある科目である。
  - ロジスティック回帰は、元の値では区別できない(0.47)が、ゼロかどうかだけなら 0.89 で区別できる。
- **分散の縮みは主因ではない**(分散の比の中央値は 0.48 で、理論どおり 0.5)。
  - 平均からのずれを √2 倍して分散を戻すと、AUC は下がらず 1.000 になった。
  - ただしこの変換は、ゼロの値も 0 でなくする(両方ゼロの組も μ − √2 μ になる)ので、分散の効果とゼロの効果を完全には分けられていない。
- **会計データの構造的な性質として報告できる。** 科目の「ある・なし」(ゼロのパターン)は企業の性質で、平均を取ると消える。重心はどれだけ局所的でも、この構造を失う。ステージ52 のゼロパターンの分析(上位 10 パターンで 7.6%)とも整合する。

## D.6 B.3: OT の再確認(ステージ60 の値)

| 対応先 | AUC LightGBM | 違反(社) c2 / c1 | 純資産の改善 c2 / c1 | 払込資本↓ c2 / c1(対 最近傍) |
|---|---:|---|---|---|
| 最近傍(非対称 L1) | 0.725 | 5 / 0 | 0.220 / 0.148 | 36% / 45% |
| 台を絞った OT の最大質量 | 0.490 | 6 / 4 | 0.143 / 0.105(差は有意でない) | 49% / 45%(+0.13 有意 / +0.01) |

- **AUC 0.49 は「OT のほうが良い」ことを意味しない。** 識別 AUC は、目標と class 0 の無作為抽出を比べる。class 0 の無作為抽出なら定義上 0.5 付近になる(実測 0.471)。
  - バランス OT の最大質量は、全 class 0 に質量を配るので、選ばれる企業は class 0 の典型に近くなる。
  - 最近傍の 0.73 は、苦境企業に近い(健全企業の中では典型でない)企業を選んでいることを示し、合成点であることを示すものではない。
- 主指標では、台を絞った OT の最大質量は最近傍を上回らない。払込資本は class 2 で有意に増え、違反も多い。**OT を採る余地は、このデータでは見つからない。**

## D.8 想定と違った点

1. **λ の較正は、較正に使わない指標(変更された科目数)を実データから遠ざけた。** 単一の λ は「動かす量全体」を決めるだけで、どの科目を動かすかを決めない。
2. **λ̃* では再建が弱い。** 実データの払込資本の割合に合わせると、純資産の改善・解消率が大きく下がる(等重み L2)。
3. **距離の設計は λ に吸収されず、較正後は提案の非対称 L1 のほうが主指標で優れた。** ステージ59・60(λ̃ = 1 での比較)とは逆の結論である。ただし class 2 では違反 4 社で、必須条件を満たさない。
4. 実データの総資産の増加は、正規化空間の QP では合わせられない。較正指標の 1 つが、構造的に動かない。
5. 指示文の実データの値(87%、+0.030・+0.148)は、このデータでは再現しなかった。
6. OT の最大質量の AUC 0.49 は、良さではなく「典型的な健全企業」であることの表れだった。
