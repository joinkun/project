D1 = ステージ75 と同じ 5 fold の交差適合(値は fold の平均、V は最大、ESS は中央値)。記号 = 純資産の改善・解消率・順位相関(+ 優れる、− 劣る、0 差なし)。対 基準の記号は「その行 − 基準の行」。

## 要約

**ゲート(criteria §5)をすべて満たしたので、主モデルを KDE0 + indiv_scale = False + stage1_penalty + 提案の輸送(γ' = 0.1)+ F1、λ̃ = 0.1 に確定する**(採用はユーザーの決定。KDE0 + stage1_penalty は本ステージで初めて計算した)。

1. **パートA(D1)**:
   - 違反 0 / 0、QP の実行不可能 0、始点ゼロ科目の発生率 0.3% / 0.1%(base は 31%)。
   - ステージ69 との差は、純資産の改善で +0.115 / +0.028(4 fold で有意)。両 class で条件 1〜4 を満たす。
   - R1 + stage1_penalty より、純資産の改善が +0.004 / +0.003 高い(3 / 5 fold で有意)。符号はそろうが差はごく小さく、KDE0 と R1 は実質的に同等である(θ の順位相関 0.996)。
   - KDE0 base との差は +0.018 / +0.009。
2. **KDE0 の代替**: fold あたり 1〜3 方向で、n < 5 のため R1 に戻した。fold f2 では、1 方向が「動いた企業なし」で θ_max になった(`kde0_fallback.csv`)。
3. **パートB**:
   - 輸送の方式は、主指標にほぼ影響しない(どの方式も、提案の方式との比較で差がない)。ただし topk_hard_5・topk_hard_8・quad_col_only は、class 2 で違反が 1 社出た。
   - 制約は tier3 まで必要(tier1 だけで違反 20 / 47 社)。
   - Tier A / B / C は、class 2 で 69.1% / 21.8% / 9.1%。Tier C の 5 社は、中間点の違反 0。
4. **パートC(バックテスト、リークなしの λ̃)**:
   - **方向は合う**: DSA の中央値 0.647 / 0.667、Cos 0.533 / 0.466(正の割合 86.7% / 89.5%)。
   - **しかし動きすぎる**: ERR^{L1} の中央値は −0.450 / −0.334(正の割合 46.7% / 19.3%)。多くの企業で、生成は「動かさない」より実績から遠い。
     - 例: class 1 の自己資本比率は、実績 0.416 に対して生成 0.641。
   - 生成は 5 年後とみなしている一方、実績は 2 年である。**事後の感度**(事前に決めていない)として、生成の変化を 2/5 に縮めると、ERR^{L1} の中央値は +0.095 / +0.017(正の割合 66.7% / 56.1%)になる。
   - 比較の基準:
     - 健全企業の中央値への移動のほうが、方向の一致は高い(Cos 0.662 / 0.506)。
     - 主モデルは、1-NN・健全企業の中央値より ERR がずっと良い(class 1 で −0.334 対 −1.019・−1.564)。
     - KDE0 base は ERR がわずかに良い(−0.255)。
   - 事例(`backtest_cases.md`): class 2 の代表例 E05633 は、純資産を −29.5% → 48.0% にするが、LightGBM の苦境の確率は 70.0% → 82.5% と上がる。分類器の判断と純資産の改善が食い違う例である。
5. **パートD(図)**:
   - Ψ_KDE0 の古典的 MDS の 2 次元の寄与は 55%(ステージ76 の Ψ60 では 27%)。
   - 図 1 の Tier C の 5 社は始点が極端な外れ値(ロジット 20〜58)で、★ を表示するために軸を広げたので、class 2 の主な点は左に詰まって見える。
   - 図 2 では、生成の矢印は実績と同じ向き(左下 = 健全側)へ伸びるが、多くは実績より長い。

**論文に書くべき注意**:

- バックテストで言えるのは「方向は合う」まで。「実績の再建後の BS に近づく」は、事後の期間の補正(2/5)をしないと成り立たない。
- KDE0 と R1 の差は実質的にない。KDE0 を選んだ理由は、密度の直接推定という定式化の解釈である。
