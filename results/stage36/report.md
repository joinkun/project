# ステージ36: class 1 での重みの再比較

全表は `comparison.md`、指標は `metrics_class1/`・`metrics_class2/`。
スクリプト: `scripts/run_generation_stage34.py`(class 1 の生成)、`scripts/run_generation_stage16.py`
(class 2 の生成)、`scripts/run_stage25.py --outliers`(指標)、`scripts/evaluate_stage36.py`(比較)。
新しい重みは作っていない(既存の `costs_*.yaml` の 5 版)。

**結論: どの版も、class 1・class 2 のどちらでも等重みに勝たなかった(ステージ32 の定義)。
class 1 では 4 版とも純資産の改善で等重みを有意に上回ったが、class 2 では再現せず、推定ベースは
逆向きに有意だった。等重みの結論は確定とする。**

## 1. A.1 構成

- 速度場は **class 2 の 57 社だけ**で学習した(各版の重みで作った輸送計画 `plan_full`)。
  seed ごとに全社で 1 本学習し、class 1 の 132 社に当てた(ステージ34 と同じ)。
- 重みは輸送(対応先の選択)にだけ効く。class 1 の経路には、「その重みで作った class 2 の対応で
  学習した速度場」を通じて効く。これは 5-fold でテスト fold の社に重みが効く仕組みと同じである。
- 評価は外れ値(シンバイオ製薬)を除く **131 社**。目標分布は class 0 のまま。
- 推定ベース・定性ベースは、これまで R1 の設定でしか比べていなかった。検定力を比べるため、
  最終設定の上で class 2(55 社)でも生成した。頻度・持続性・等重みの class 2 はステージ31・32 の生成を使った。
- validity は、class 1 を学習に含めない分類器(class 0 対 class 2)で測った。

## 2. B.2 債務超過の社数

**class 1 で始点が債務超過の企業は 6 社**(class 2 は 12 社)。解消率はこの 6 社でしか比べられず、
**指標として使えない**(差の中央値はどの版でも 0 で、区間は [0, 0.33])。そのため主指標は、
事実上、純資産の改善と |総資産変化| の 2 つになる。

## 5. C.2 判定

| 版 | class 1: 主指標で優 / 劣 | class 2: 優 / 劣 | 勝つ(両方) |
|---|---|---|---|
| 推定ベース | 1 / 1 | 0 / 1(純資産の改善で有意に劣る) | × |
| 定性ベース | 1 / 0 | 0 / 0 | × |
| 頻度ベース | 1 / 0 | 0 / 0 | × |
| 持続性ベース | 1 / 1 | 0 / 0 | × |

スペックの 3 つの場合に当てはめると、次のとおりである。

- **「別の版が最良」にはならない。** class 1 で純資産の改善だけを見れば 4 版とも等重みより良いが、
  主指標 2 つ以上で優れる版はない。推定ベースと持続性ベースは |総資産変化| で劣る。
- スペックに従い class 2 に戻って確認した。**class 1 の純資産の改善の優位は class 2 で再現しない。**
  頻度ベースは逆向き(−0.008、p = 0.045)、推定ベースは逆向きに有意(−0.012)だった。
- 向きが両 class で一致するのは定性ベース(+0.0019 と +0.0011)と持続性ベース(+0.0039 と +0.0022)だが、
  class 2 では有意でない。大きさも 5 年で総資産の 0.1〜0.4%(等重みの水準 0.19〜0.23 の 0.5〜2%)にすぎない。
  持続性ベースは class 1 で |総資産変化| が劣る。
- **結論: 版によって指標が割れ(トレードオフ)、両 class で一貫して等重みを上回る版はない。
  class 2 での結論(等重み)は、大きい標本でも覆らなかった。確定とする。**

## 6. D.1・D.2 実データとの一致

**D.1 向き**(年率、実際は 2022 年度に class 1 だった 127 社の 2 年間、生成は 131 社):

| 系列 | 短期借入金 中央値 | 減った / 増えた社 | 有形固定資産 中央値 | 減った / 増えた社 |
|---|---:|---|---:|---|
| 実際(全体) | 0.000 | 42% / 38% | −0.004 | 63% / 30% |
| 実際(class 0 へ回復) | 0.000 | 46% / 40% | −0.003 | 60% / 40% |
| 生成(5 版とも) | −0.013〜−0.015 | **76% / 0%** | +0.008〜+0.009 | **1% / 97〜98%** |

**どの重みでも向きは変わらない。** 生成は 5 版とも短期借入金を減らし、有形固定資産を増やす。
重みは対応先の選択にしか効かず、この向きは流れ場と対応先の集団(class 0)の性質から来ている
と考えられる。

**D.2 科目別の動き**(32 科目の中央値の順位相関):

| 版 | \|Δx\| と実際(全体) | \|Δx\| と実際(回復) | 符号付き Δx と実際(全体) |
|---|---:|---:|---:|
| 1 等重み | +0.800 | +0.779 | −0.113 |
| 2 推定ベース | +0.793 | +0.767 | −0.074 |
| 3 定性ベース | +0.803 | +0.785 | −0.091 |
| 4 頻度ベース | +0.713 | +0.700 | −0.137 |
| 5 持続性ベース | **+0.811** | **+0.791** | −0.049 |

- 動きの大きさの一致は、持続性ベース(+0.811)と定性ベース(+0.803)がわずかに等重み(+0.800)を
  上回る。差は 0.01 程度で、判断を変える大きさではない。頻度ベースは下がる(+0.713)。
- **符号付きの順位相関はどの版も −0.05〜−0.14 で、向きは実データと一致しない。** ステージ34 の
  +0.80 は動きの「大きさ」の一致で、主に科目の規模を反映している(ステージ33 の C.2 と同じ)。
  向きまで含めた一致は、どの重みでも得られない。

## 7. 想定と違った点

- **class 1 では 4 版とも純資産の改善で等重みを有意に上回ったが、class 2 では再現しなかった。**
  推定ベースと頻度ベースは向きが逆だった。重みの効果は始点の集団に依存し、汎化しない。
- CI の狭まり(2.58 倍)は、標本の大きさから予想される 1.54 倍を超えた。
- 債務超過の class 1 企業は 6 社で、解消率は使えなかった。
- 重みを変えても、短期借入金を減らし有形固定資産を増やす向きは変わらなかった。
- 実データとの科目別の一致は大きさだけで、符号付きではどの版も負の相関(約 −0.1)だった。これは
  等重みを含む現行の生成の限界として、論文に書くべき点である。

## 論文の記述案(重みの結論の確定)

> 重みの 5 版(等重み、部分調整モデルによる推定、制度的根拠、施策の頻度、持続性)を、GC 注記企業
> (55 社)に加え、学習に用いていない重要事象の企業(class 1、131 社)でも比較した。class 1 では
> 信頼区間が約 2.6 倍狭まり、4 版とも純資産の改善で等重みをわずかに上回った(5 年で総資産の
> 0.2〜1.3%)。しかしこの差は GC 注記企業では再現せず、2 版では向きが逆であった。いずれの版も、
> 両集団で一貫して等重みを上回らなかったため、等重みを採用する。
