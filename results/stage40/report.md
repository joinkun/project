### D.3 記述案(事実に合わせて修正した)

スペックの案のうち、「持続性は集約値（0.984）と内訳（0.834〜0.987）で大きく変わらず」は、内訳の上限が機械の 0.988 であり、
建設仮勘定(0.834、両年非ゼロでは 0.670)は集約値と明確に異なるので、そのままでは使えない。また、細分化した空間では
持続性の重みが等重みに勝った(ステージ39 の 5 − 3 は両 class)ので、「重みの推定が妨げられていない」とも言い切れない。

> 勘定科目の粒度が結果を制約しているという仮説を検証した。有形固定資産を土地・建物・機械・建設仮勘定に、
> 投資その他の資産を投資有価証券・繰延税金資産に細分化した(D = 38)。内訳の持続性は 0.834(建設仮勘定)から
> 0.988(機械)に分かれ、集約値(0.984)に近い科目と明確に低い科目があった。細分化した空間では持続性に基づく重みが
> 等重みを上回ったが、細分化した生成は、残余に下限を課して 14 項目の制約を満たしたうえでも、class 2 で
> 集約した表現(D = 32)に対して総資産の変化を有意に増やし、両方の母集団での優位を示せなかった。細分化した BS は
> 土地・建物・機械を同じ向きに動かし、実データに見られる「土地を保持し設備を減らす」パターンを再現しなかった。

## 9. 想定と違った点

1. **下限は主指標をほぼ変えなかった**。ステージ39 の問題は指標ではなく BS の水準(残余の負)にあり、下限はそれを直したが、
   判定は変わらなかった(class 2 の \|総資産変化\| の悪化はステージ39 と同じ +0.014)。
2. **下限を課しても土地の出現は減らない**(47 → 46 / 99)。残余の相殺が他の科目に置き換わっただけ。
3. **出現は core でも大きい**(自己株式 0 → 負が 79〜95%、class 1 の有形固定資産 0 → 正が 81%)。細分化で見えるようになった、
   生成全体の性質である。
4. チェック 10 は投資その他の資産の残余を既に見ていた。抜けていたのは、事前の設計で自由にした有形固定資産の残余である。
5. 細分化の中での持続性 対 等重み(3 − 2)は、ステージ40 の主指標(解消率を含まない)では class 2 で \|総資産変化\| が
   わずかに有意に悪化し(+0.0057 [+0.0004, +0.011])、両 class では勝たない(ステージ39 の 5 − 3 は下限なし・主指標の定義が違う)。
6. 生成は土地・建物・機械を同じ向きに動かす。実データの再建企業は土地を保持して設備を減らす。
