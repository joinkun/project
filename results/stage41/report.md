選定規則と判定基準は `criteria.md`(生成の前に記録し、コミット c9b5b77 で push)。基準は変えていない。

## 結論

- **事前の基準では、設定 2(規則 S、17 科目)は採用基準を満たさない**。15 項目の違反 0(基準 1)と主指標の許容(基準 3)は
  満たすが、基準 2 に使うと決めた「企業ごとの乖離 dev」が下がらず、むしろ上がった(class 2 の中央値 0.69 → 0.83、
  class 1 0.45 → 0.73。差の区間は 0 を含む)。
- ただし、**科目別の割合では、実データにはっきり近づいた**。自己株式 80〜95% → 0%(実データ 0%)、評価・換算差額等その他
  85〜98% → 0%(実データ 1 年 0.6%)、固定資産その他 34〜43% → 0%(実データ 0%)。課していない科目の割合は
  設定 1 と全く同じで、相殺の付け替えは起きていない。
- 食い違いは dev の設計の欠陥による、と考える。dev は「0 → 非0 になった科目の数」を実データの期待値と比べるだけで、
  どの科目が出現したかを見ない。現行の生成は、実データでは起きない科目(自己株式など)に出現を作り、その数が期待値
  (企業あたり 1.2〜1.3 個)に偶然近かった。
- **判断は保留し、ユーザーに委ねる**。スペックの基準 2 の文言(「0 → 非0 の割合が実データに近づく」、C.3 は科目別)を
  科目別の割合で読むなら、設定 2 は 1〜3 をすべて満たす。事前に決めた dev で読むなら満たさない。

## 2. A.2 選定規則と対象科目(`selection.md`)

- 規則 S(採用): 実データ class 1+2 の 1 年の割合 r が 5% 未満 → 課す、20% 超 → 課さない、5〜20% → 規則 M。
- 規則 M(機械的な代案): 5 年換算 r5 = 1 − (1 − r)^5 が、現行の生成の割合 g の半分未満なら課す
  (0 に固定したほうが現行より実データに近い)。5〜20% の 10 科目はすべて「課さない」になった。
- **閾値 5% の根拠は弱い**: 5% は 1 年の割合への閾値だが、生成は 5 年で、1 年 5% は 5 年で約 23% に当たる。
  そのため、機械的な代案として規則 M を示した。
- 対象(規則 S、17 科目): 資産その他、売上債権、貸倒引当金(流動・固定)、流動資産その他、固定資産その他、仕入債務、未払金、
  1年内償還予定社債、負債その他、社債、非支配株主持分、純資産その他、自己株式、株主資本その他、その他有価証券評価差額金、
  評価・換算差額等その他。規則 M は 4 科目(売上債権、固定資産その他、自己株式、評価・換算差額等その他)。
- スペックの想定と違う点: **社債は課す**(r = 1.5%。新規発行は苦境企業では稀)。長期借入金は課さない(5.3%)。
  非支配株主持分・貸倒引当金は課す。

## 8. D.1 判定

| 基準 | class 2 | class 1 | 満たす |

| 1. 15 項目の違反 0 | 0 | 0 | はい |

- 主指標の許容の案: 純資産の改善の差 ≥ −0.02、\|総資産変化\| の差 ≤ +0.02。設定 2 はどちらも十分内側(悪化なし)。

## 9. 想定と違った点

1. **事前に決めた dev が、改善を捉えなかった**。科目別には明確に近づいたが、出現の「数」は実データの期待値から遠ざかった。
   現行の生成は、誤った科目(自己株式・評価換算差額の残余・固定資産その他)で、正しい数の出現を作っていた。
2. **相殺の付け替えは起きなかった**。課していない科目の出現は行数まで同じ。止めた分は、既に非0 の科目が吸収した(例: 燦キャピタルでは資本剰余金が 41 百万円減った)。
3. 不活性科目が多い企業(10 科目以上: class 2 20 社、class 1 51 社)も普段どおり動く。実行可能性は問題にならなかった
   (全科目に課した設定 3 でも実行不可能は各 class 1 社)。
4. **sparsity はほとんど下がらない**(平均 −0.3 科目以下)。出現を止めた科目の分だけで、密な基底の性質は変わらない。
5. 自己株式の膨張は「0 から」だけでなく「少額から」も起きており、不活性制約では止まらない(class 1 で 90%)。
   流れ場が目標(class 0)の典型的な自己株式の水準へ引き寄せる性質で、苦境企業の実データ(新規計上 0%)と合わない。
6. 社債は、スペックの想定と違い、実データでは苦境企業の新規発行が稀(1.5%)で、規則により課した。
7. 評価・換算差額等その他は、符号を自由にしている残余で、現行の生成では 85〜98% で 0 から負になっていた。
   **ステージ40 の出現の集計(`emergence_stage40.py`)は、符号が自由な科目の負への出現を数えておらず、これを 2〜4% と
   報告していた**。スクリプトを直してステージ40 の表を作り直し、ステージ40 の報告に訂正を追記した(土地の行と判定は変わらない)。
