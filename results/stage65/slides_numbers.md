# ステージ65 発表資料の数値(最終版)

最終設定:
- 対応先は、不均衡 OT(τ0 = ∞、τ1 = 0.01、ε = 0.001)の最大質量の対応先。
- 第 1 項の重みは払込資本 m = 10、移動コストは非対称 L1。
- 制約は第 2 層 + 現金の下限 0.117。
- λ̃*_0 は class 2 で 0.1、class 1 で 1。

評価対象は class 2 55 社、class 1 128 社(生成の始点は 132 社)。

## 主張 1: 会計恒等式だけでは成立しない

- 第 1 層(恒等式・符号)のみで、**67 / 68 社(98.5%)** が 15 項目のどれかに違反(ステージ27、Flow Matching の生成)
- 本ステージの QP でも、第 1 層のみ(提案の目標・λ)で違反は **class 2 で 11 社、class 1 で 16 社**
  - 例: 純資産の悪化(項目 6)、不活性科目が動いた(項目 15)、小計が負(項目 2)
  - λ̃ = 3 では、総資産が負(−0.15)の企業が出る(項目 1)
- 提案(第 2 層 + 現金の下限)の違反: **0 / 0**

## 主張 2: 既存の L2 距離は払込資本に支配される(スライド21・22)

- 払込資本(資本金 + 資本剰余金)の寄与率: **54.5%**(1 科目あたり、他の 27 科目の平均の **16.1 倍**)
- 払込資本 / 総資産の中央値: class 2 **1.144**、class 1 0.489、class 0 **0.133**
- 等重み L2 の最近傍の対応先: 0.820(class 0 の中央値の 6 倍)

## 主張 3: 生成結果は λ に支配される(図 1: `results/stage61/figures/tradeoff_c2.png`)

| 等重み L2、class 2 | λ̃ = 0.01 | 3 | 100 | 実データ |
|---|---:|---:|---:|---:|
| 払込資本を減らした企業 | 67% | 42% | 2% | 36% |
| 変更された科目数 | 17 | 9 | 1 | 16 |
| 純資産の改善 | 0.277 | 0.072 | 0.003 | — |

## 主張 4: 第 1 項の重みが払込資本を制御する(図 2: `figures/fig2_m_saturation.png`)

λ̃ = 3 で、払込資本の m を 1 → 3 → 10 → 30 にしたときの、払込資本を減らした企業の割合:

| | m = 1 | 3 | 10 | 30 |
|---|---:|---:|---:|---:|
| class 2 等重み L2 | 42% | 29% | 24% | 24% |
| class 2 非対称 L1 | 16% | 5% | 2% | 2% |
| class 1 非対称 L1 | 12% | 4% | 3% | 3% |

- m ≥ 10 で飽和する。純資産の改善は悪化しない(class 2 非対称 L1: 0.121 → 0.152)
- 第 2 項(移動コストの重み)では制御できなかった:
  - 再建群の変化量の重み(ステージ57): 82% → 91〜100%
  - 群内分散の重み(ステージ58): 98〜100%
  - 方向別の重み(ステージ59): 資本金の c−/c+ = 0.36(減らすほうが安い)
- **事後選択**: 6 設計から結果を見て選んだ。class 1 の 2 分割の検証の成立 54%

## 主張 5: 距離の設計の効果は λ に吸収されない(class 1 に限定)

- 非対称 L1 − 等重み L2 の符号付き順位相関が有意に正: **class 1 で 10 点中 7 点**(中央値 ≈ 0 を 0 にそろえても 5 点)、class 2 で 1 点
- class 1 の効果を 55 社で検出できる確率: **0.20〜0.78**(class 2 で有意でないのは、標本の小ささでも説明できる)
- 最終設定でも、提案は等重み L2 より、class 1 で純資産の改善 +0.154、順位相関 +0.310(有意)

## 主張 6: 重心は実データと区別できる(図 4: `figures/fig4_auc.png`)

| 目標 | 識別 AUC(class 2 / class 1) |
|---|---|
| 実在企業の無作為抽出 | 0.47 |
| **提案(不均衡 OT の argmax、実在企業)** | **0.71 / 0.69** |
| 等重み L2 の最近傍 | 0.85 / 0.75 |
| 無作為な 2 社の平均 | 0.92 |
| **バランス OT の重心** | **0.995 / 0.999** |

- 原因はゼロの構造: 未払金がゼロの企業は、実データで 40%、2 社の平均で 14%(ゼロかどうかだけで AUC 0.86〜0.89)
- 生成の主指標では、重心は class 2 で劣らず(0.394 対 0.327)、class 1 で劣る(−0.051)。根拠は「到達点が実在しない」こと

## 主張 7: バランス輸送は局所性を失う(図 5: `figures/fig5_support_tau1.png`)

| | class 2 | class 1 |
|---|---:|---:|
| 下限 n1 / n0 | 68.5 | 28.5 |
| 厳密解の実効サポート | **68.8** | **28.9** |
| その argmax が最近傍と一致 | 0 / 55 | 1 / 132 |
| バランス OT の argmax を目標にした生成: 純資産の改善 | 0.279 | **0.000**(λ̃ = 30 でしか違反 0 にならない) |
| 不均衡 OT(τ1 = 0.01)の実効サポート | **1.35** | **1.40** |
| その argmax が最近傍と一致 | 54 / 55(98%) | 127 / 132(96%) |

- 記述: 「OT の枠組みで解き、この設定では最近傍にほぼ帰着した。一致しない対応先は、主に混雑(同じ企業への集中)を避けたもの(6 社中 5 社)」

## 主張 8: 下方硬直性の向きは代表値に依存する(スライド15・42)

| 科目 | 平均(増加の大きさ / 減少の大きさ) | 中央値 |
|---|---:|---:|
| 有形固定資産 | 1.31 | **0.92** |
| 無形固定資産 | 1.59 | 1.19 |

- Anderson, Banker & Janakiraman (2003): 0.55 / 0.35 は、プールした OLS の回帰係数(β̂1 = 0.5459、β̂1 + β̂2 = 0.3545)で、平均の側の値
- 本研究の重み(中央値)では、有形固定資産の c−/c+ = 0.52(減らしやすい)。下方硬直性とは逆向き
- スライド15: 「方向別の可変性をデータから推定する(硬直性を仮定しない)」
- スライド42: 「代表値で結論が変わる」
