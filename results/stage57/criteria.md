## 0. スペックの前提の訂正: 現行の刻み

- **現行の生成は Euler 法 1 ステップ(n = 1、`_TS = (0.0, 1.0)`)**。スペックの「5 点(t = 0, 0.25, 0.5, 0.75, 1)」は、全件出力のための始点と終点の線形補間で、モデルの刻みではない(ステージ48 で判明)。
- **射影の扱い**: 現行の「毎ステップ射影」は、Euler 法で積分した射影前の経路の各点を、それぞれ独立に射影する。射影した点を次のステップに戻さない。スペック B.2 の「PCFM 方式を維持」に従い、この扱いを変えない。
  - そのため、刻みを細かくして変わるのは ODE の積分の精度(射影前の終点)である。終点の射影は、途中の点の射影に依存しない。
- **刻みの系列**: n ∈ {1(現行), 4, 20, 100}。スペックの n ∈ {4, 20, 100} に、実際の現行 n = 1 を加える。

## 1. 変化量(A)

- **対象**: ステージ55 の再建群 72 社(class 2 → 回復 15、class 1 → class 0 57)。2022 → 2024 年度末の 2 年。
- **変化量**: Δx_a / A = (x_a(2024) − x_a(2022)) / 総資産(2022)。名目額で、生成と同じく始点の総資産で割る。
- **非再建群**(A.3): class 2 → class 2 の 30 社(ステージ51 と同じ)。
- **期間の限界**: 2 年の変化から作った重みを、5 年の生成に使う。重みは相対値なので、全科目が同じ比率で変われば順位は変わらない。しかし、科目によって年次の挙動が違う可能性がある。

## 2. 重みの構成(A.4〜A.6)

- **代表値: 平均**(m_a = 72 社の \|Δx_a / A\| の平均。変化が 0 の企業も 0 として含める)。
  - 理由: ステージ56 で、生成と実データの差は「減らす深さ」でなく「減らす企業の多さ(頻度)」だった。平均は「動く企業の割合 × 動くときの大きさ」で、頻度と大きさの両方を反映する。
    - 中央値は、変化なしが半数を超える科目(資本金など)で 0 になる。
    - 非ゼロだけの中央値(A.4 の案 2)は、頻度の情報を捨てる。
  - 中央値・p75・非ゼロの中央値の版も、参考として計算する(生成には使わない)。
  - **ゼロの扱い**: A.4 の案 1(平均)。平均が 0 になるのは 72 社すべてで変化がちょうど 0 の科目だけで、その科目の重みは上限(下記)にする。
- **重み**: w_a = m_現金 / m_a(現金預金 = 1)。
  - **上限 100**(現金の 100 倍)。ほとんど動かない科目で重みが発散するのを防ぐ。
  - 非操作 3 科目(利益剰余金・その他有価証券評価差額金・非支配株主持分)は、現行の `nearest_na0` と同じく 0。
- **方向別(A.6)**: m_a^+ = 72 社の max(Δx_a / A, 0) の平均、m_a^− = max(−Δx_a / A, 0) の平均(変化しない・逆向きの企業は 0 として含む)。w_a^+ = m_現金^+ / m_a^+、w_a^− = m_現金^− / m_a^−。上限 100。
  - スペックの式(Δ > 0 の企業だけでの代表値)は頻度を捨てるので、上の無条件の平均を使う。条件付きの値も報告する。
  - 距離 d = Σ_a w_a^+ max(y_a − x_a, 0)² + w_a^− max(x_a − y_a, 0)²(`weighted_asymmetric_cost_matrix`)。「目標が始点より大きい」= 増加の重み。
- **群**: 72 社をまとめた値を使う(主)。15 社・57 社別の値と、両者の重みの順位相関も報告する。相関が低くても、まとめた値を使う。
- **信頼区間**: 企業の復元抽出 2,000 回(seed 0)で、m_a と w_a の 95% 区間を出す。
