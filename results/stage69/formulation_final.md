- **符号**: 基礎科目ごとに nonneg(棚卸資産・売上債権・現金・借入金・資本金など 17 科目)、nonpos(貸倒引当金 2・自己株式の 3 科目)、free(残余 9・利益剰余金・評価差額金・非支配株主持分の 12 科目)。

## 1. 地上コストと輸送

### 1.1 非対称 L1 コスト(`prep_stage59.l1_cost`、重みは `ot_stage60.weights` → `scales_stage59.scale_table`)

$$c(x_i, y_j) = \sum_{a \in \mathcal{A}} \left[ c_a^{+} (y_{ja} - x_{ia})_+ + c_a^{-} (x_{ia} - y_{ja})_+ \right]$$

- **尺度**:
  - 再建群の企業 k について、構成の差 Δ_ka = x_{k,2024,a} / A_{k,2024} − x_{k,2022,a} / A_{k,2022}(`prep_stage59.deltas`)を取る。
  - s_a⁺ = median{Δ_ka : Δ_ka > 0}、s_a⁻ = median{−Δ_ka : Δ_ka < 0}(変化した企業の大きさの中央値)。
- **コスト**: c_a^± = 1 / (s_a^± + ε0)、**ε0 = 0.001**。
- **n < 5 の代替**: その方向の企業数が 5 未満なら、c_a^± を「n ≥ 5 で操作可能な全方向の c の中央値」に置き換える(方向ごとに独立)。
- **非操作 3 科目**は c_a^± = 0。
- 丸め残余(資産その他など)は s ≈ 0 なので c ≈ 1/ε0 ≈ 1,000(最も高い)。
- **推定に使う群**(母集団を分ける):
  - class 2 の生成には、class 1 → class 0 の 57 社。
  - class 1 の生成には、class 2 → 回復の 15 社。
- 例(class 2 用): 資本金 c⁺ = 84.3、c⁻ = 30.3。資本剰余金 33.5 / 44.9。

### 1.2 正規化と不均衡 OT(`transport.solve_semi_unbalanced_normalized`、`ot_stage64.py`)

- **正規化**: C̃_ij = c(x_i, y_j) / median_{i,j} c(x_i, y_j)(全要素の中央値)。周辺分布は一様、a_i = 1/n0、b_j = 1/n1。
- **片側不均衡 OT**(始点側を厳密に保存、τ0 = ∞):

$$\min_{P \ge 0,\ P\mathbf{1} = a} \ \langle P, \tilde{C} \rangle + \varepsilon\, \mathrm{KL}(P \,\|\, a \otimes b) + \tau_1\, \mathrm{KL}(P^{\top}\mathbf{1} \,\|\, b), \qquad \varepsilon = 0.001,\ \tau_1 = 0.01$$

- 参照測度は μ0 ⊗ μ1 = a ⊗ b。
- **解法**(対数領域の反復):
  - log u = log a − LSE_j(log K + log v)、log v = φ(log b − LSE_i(log K + log u))。
  - φ = τ1 / (τ1 + ε)、log K = −C̃/ε + log a + log b。
- **収束**:
  - v の更新量の幅 max Δlog v − min Δlog v < 10⁻⁹(定数のずれは計画を変えないので除く)。最大 2,000,000 反復。
  - 未収束・非有限・行の周辺の誤差・質量 0 の行は例外。
- **対応先**: j*(i) = argmax_j P_ij(実在企業)。目標 τ_i = y_{j*(i)}。
  - 最近傍 argmin_j C̃_ij との一致は、class 2 で 54 / 55、class 1 で 127 / 132。
- **バランス OT**(比較):
  - 同じ C̃ と a, b で、P1 = a、Pᵀ1 = b。
  - ε = 0.001 の対数領域 Sinkhorn(`ot.sinkhorn`、`sinkhorn_log`)と、厳密解(`ot.emd`)。

## 2. 命題 1: バランス輸送のサポートの下界(検算: `verify.md`)

**命題 1.** a = 1/n0、b = 1/n1、n0 < n1 のバランス輸送の任意の実行可能な計画 P(P1 = a、Pᵀ1 = b、P ≥ 0)について、次が成り立つ。

1. 各行 i の非ゼロ要素数 #{j : P_ij > 0} ≥ ⌈n1/n0⌉。
2. 行で正規化した p_ij = n0 P_ij の実効サポート 1/Σ_j p_ij² ≥ n1/n0。
3. P が輸送多面体の頂点(LP の基底解、`ot.emd` の解)なら、非ゼロ要素の総数は n0 + n1 − 1 以下である。したがって行あたりの非ゼロ数の平均は [⌈n1/n0⌉, (n0 + n1 − 1)/n0] に入り、実効サポートの行平均は [n1/n0, (n0 + n1 − 1)/n0] に入る。

**証明.**

- 列の制約から、各要素は P_ij ≤ b_j = 1/n1。
- 1: 行 i の和は 1/n0 = Σ_j P_ij ≤ #{j : P_ij > 0} / n1。
- 2: p_ij ≤ n0/n1 なので、Σ_j p_ij² ≤ max_j p_ij · Σ_j p_ij ≤ n0/n1。
- 3: 輸送多面体の制約行列の階数は n0 + n1 − 1 で、基底解の非ゼロはその数以下。
  - 実効サポートは非ゼロ数以下なので、上界も従う。∎

| class | n1/n0 | ⌈n1/n0⌉ | 頂点の上界 | 厳密解: 行の非ゼロ数 最小 / 平均 | 非ゼロの総数(n0 + n1 − 1) | 実効サポート 最小 / 中央値 / 平均 |
|---|---:|---:|---:|---|---|---|
| class 2 | 68.509 | 69 | 69.491 | 69 / 69.491 | 3,822(3,822) | 68.760 / 68.778 / 68.853 |
| class 1 | 28.545 | 29 | 29.538 | 29 / 29.515 | 3,896(3,899) | 28.796 / 28.880 / 28.922 |

- 厳密解は限界を満たす。class 2 は非退化の頂点(非ゼロの総数がちょうど n0 + n1 − 1)。max_ij P_ij × n1 = 1 で、受け手の列容量を使い切る。
- **指示文との差**: 「行平均非ゼロ数は [n1/n0, (n0+n1−1)/n0] = [68.51, 69.49]」は、非ゼロ数については下限が ⌈n1/n0⌉ = 69 になる。区間 [68.51, 69.49] が成り立つのは**実効サポート(1/Σp²)の行平均**である。
  - 実測の「実効サポート 68.8」(中央値 68.78)はこちらの量で、下界 68.51 と上界 69.49 の間にある。
- 意味: 1 社の始点の質量は、必ず約 n1/n0 社以上に分散する。argmax は局所性を失い(最近傍との一致 0 / 55、1 / 132)、重心は約 69 社の凸結合になる。

## 3. 命題 2: 凸結合によるゼロの構造の消失(検算: `verify.md`)

**命題 2.** y_1, …, y_K を BS とし、重心 ȳ = Σ_k w_k y_k(w_k > 0、Σ w_k = 1)を作る。

- 科目 a で、全員が y_ka = 0 なら ȳ_a = 0。
- 符号が一定の科目(nonneg・nonpos)では逆も成り立つ。ȳ_a = 0 ⇔ すべての k で y_ka = 0。
- したがって、符号一定の科目について、ȳ のゼロの集合は各 y_k のゼロの集合の**共通部分**になる。

**証明.** 符号一定なら、各項 w_k y_ka は同符号。和が 0 になるのは、全項が 0 のときに限る。∎

| 対象 | ちょうど 0 の科目数(32 科目中、平均) | 未払金が 0 の割合 |
|---|---:|---:|
| 健全企業(class 0、3,768 社) | **6.70** | 40% |
| 2 社の平均(無作為 10,000 組) | 3.24 | 16% |

| 提案の対応先(argmax、class 2 / class 1) | 9.78 / 8.08 | 25% / 46% |

- 重心は命題 1 により約 69 / 29 社の凸結合。ゼロの集合の共通部分は実質的に空になり、ちょうど 0 の科目が 1 つも残らない。

  | 目標 | LightGBM | ロジスティック回帰 |
  |---|---|---|
  | 重心 | 0.995(class 2)/ 0.999(class 1) | 0.589 / 0.599 |
  | 無作為な 2 社の平均 | 0.92(ステージ61) | — |

  - 木のモデルだけが重心を見分けるのは、「ちょうど 0」という離散的な構造で分けるからである(ゼロかどうかだけで AUC 0.86〜0.89、ステージ65)。
  - **AUC の値は命題の帰結ではなく、実測**である(命題が言うのは、ゼロの構造が消えることまで)。

## 4. 第 2 段階: 凸 QP(`projection_qp.project_onto_feasible(l1_move=…)`、`qp_stage61.py`)

### 4.1 目的関数

$$\min_{y,\,u,\,v}\ \sum_{a \in \mathcal{A}} w_a (y_a - \tau_{ia})^2 + \lambda \sum_{a \in \mathcal{A}} \left( c_a^{+} u_a + c_a^{-} v_a \right) \quad \text{s.t.}\ y - x_i = u - v,\ u, v \ge 0,\ y \in \mathcal{F}_i$$

- **第 1 項の重み**:

  $$w_a = \frac{1}{\max(\sigma_a^{\mathrm{pool}}, 10^{-3})^{2}\, m_a^{2}}$$

  **σ と m はどちらも 2 乗。**
  - σ_a^pool = √(Σ_k n_k Var_k(x_a) / Σ_k n_k)(class 0・1・2 の群内分散を社数で重み付け、ddof = 0。`results/stage59/pooled_sd.csv` の `sigma_1`)。
  - m_a = 10(資本金・資本剰余金)、それ以外は 1(`data/interim/stage62/m/*_paid10.json`)。
  - 全 32 科目で w_a > 0。
- **第 2 項の係数**: §1.1 の c_a^±(輸送と同じもの)。非操作 3 科目は 0。
- 係数 ½ はない。内部でスケーリングと白色化(u ← √w ⊙ y)をするが、元の単位では上の式と同じ。
- **λ = λ̃ × s**:
  - s = median_i [Σ_a w_a⁰ (τ_ia − x_ia)² / Σ_a c_a^± |τ_ia − x_ia|]。w⁰ は m を掛ける前の重み。τ は非対称 L1 の最近傍(ステージ61)。class 1 の始点で計算。
  - s_c1 = 0.3866(`data/interim/stage61/scale_c1.json` の `l1a`)。
  - **λ̃*_0 = 1**(class 1 の 128 社で、違反 0 の中で較正の乖離 L が最小)。両 class に **λ = 0.3866** を当てはめる。
  - L = Σ_{m} |g_m − r_m| / SE_m。m ∈ {払込資本を減らした割合、利益剰余金が増えた割合、総資産変化の中央値}。いずれも年率で、生成は ÷5、実データは ÷2。SE は実データの企業の復元抽出(2,000 回)の標準偏差。

### 4.3 定理 1(実行可能性・一意性・補間)

**定理 1.** x_i ∈ 𝓕_i とする。

1. **(実行可能性)** 𝓕_i は空でない閉じた凸多面体である(y = x_i ∈ 𝓕_i)。
2. **(存在と一意性)** 目的関数は y について強凸(全ての w_a > 0)で、下に有界。したがって最適解 y* は存在し、一意である(λ ≥ 0 で成立)。
   - さらに λ > 0 なら、c_a⁺ + c_a⁻ > 0 の科目 a について (u_a*, v_a*) = ((y_a* − x_ia)_+, (x_ia − y_a*)_+) と一意に決まる。
   - c_a⁺ = c_a⁻ = 0 の科目(利益剰余金)では、u_a, v_a は一意でない(y_a* は一意)。
3. **(補間)** 𝓕_i は凸で x_i, y* ∈ 𝓕_i なので、z(t) = (1 − t) x_i + t y* はすべての t ∈ [0, 1] で 𝓕_i に入る。

**証明.**

1. 各制約は始点で成り立つように作ってある(上の表の「緩和」)。
2. y を固定すると、(u, v) の最小化は科目ごとに独立。
   - c_a⁺, c_a⁻ ≥ 0 で、u_a − v_a = d_a のもとで c_a⁺ u_a + c_a⁻ v_a を最小にする解は、c_a⁺ + c_a⁻ > 0 なら u_a = (d_a)_+、v_a = (−d_a)_+(両方が正なら共通部分を減らすと真に下がる)。
   - y の目的関数は Σ w_a (y_a − τ_a)² + λ Σ_a [c_a⁺ (y_a − x_a)_+ + c_a⁻ (x_a − y_a)_+]。強凸の二次関数に凸関数を足したものなので、閉凸集合上の最小点は一意。
3. 凸性から明らか。∎

**但し書き(実データ。`results/stage67/start_feasibility.md`)**:

- **貸借一致の丸め**:
  - 始点の Cᵀx_i は、class 2 で 13 / 55 社、class 1 で 18 / 132 社が |·| > 10⁻⁶(最大 4.9 × 10⁻⁴)。これらの始点は (L1) を厳密には満たさない。
  - 終点は Cᵀy* = 0 なので、補間では Cᵀz(t) = (1 − t) Cᵀx_i。残差は始点の値から線形に 0 へ減る。
- **有形固定資産が負の企業**:
  - 各 class に 1 社。(7) の y ≥ 0.3 max(x, 0) = 0 を始点が破る(x_i,PPE < 0)。
  - g(z) = z_PPE は線形なので、違反するのは t < t* = −g(x_i) / (g(y*) − g(x_i)) の区間だけ。
- 符号 (L2) の違反は始点で 0。
- **15 項目のチェック**は 𝓕_i と同じではない。補間の途中や終点でチェックを満たすことは、定理 1 からは従わない。
  - 終点のチェックは生成ごとに検査し、最終設定では両 class で違反 0。
  - 実データの再建企業の変化も、class 2 → 回復の 15 社中 5 社、class 1 → class 0 の 57 社中 16 社がチェックに違反する(`paper_tables.md` 表 5)。

## 6. 指示文・過去の記述との差(正誤)

1. **第 2 層の制約の本数**: 指示文の「16 本のドメイン制約」は、実装では **24 本の線形不等式**(9 種類、§4.2)。
   - これに加えて、固定 (F1)・不活性 (F2) の等式と、第 1 層 (L1)・(L2) がある。

2. **小計・控除後の純額の緩和**は min(0, S(x_i)) で、指示文どおり。
   - **事業継続 β は max(x, 0) で、緩和ではない**(有形固定資産が負の 1 社が始点で破る理由)。
   - **残余科目の下限は緩和しない**(始点が破れば例外)。

5. **n < 5 の代替**: 最終設定の c±(ステージ60)は「操作可能な全方向の c の中央値」で置き換える。
