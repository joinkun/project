## 停止規則

> **本ステージが重みの根拠の最後の試行である。** 頻度ベース(版 2)または頻度 + 非対称性(版 4)が
> 等重みに勝てなければ、重みの探索を終了し、等重みを採用して限界として記述する。

これまでの試行: 文献値(旧 `costs.yaml`、ステージ8〜9)、部分調整モデルの推定(ステージ21〜24)、
制度的根拠(定性ベース、ステージ24)。本ステージで実施頻度と持続性を加え、5 通りになる。

## 「勝つ」の定義

版 2 または版 4 が、等重み(版 1、ステージ31 の最終設定そのもの)に対して、次のすべてを満たすとき
「勝つ」とする。

1. 13 項目の違反が 0(外れ値 2 社を除く 55 社)
2. 主指標 3 つ(純資産の改善 ↑、債務超過の解消率 ↑、\|総資産変化\| ↓)のうち **2 つ以上で有意に
   優れる**。有意 = 企業単位のペア比較で、差の中央値の 95% ブートストラップ区間(2,000 回、
   `paired_test`)が 0 を含まず、良い向きにある
3. 主指標 3 つのうち、有意に劣るものがない

- 債務超過の解消率は、始点で債務超過の 12 社について、3 seed のうち解消した割合で比べる。12 社では
  差の中央値の区間が [0, 0] になりやすく、実質的には純資産の改善と \|総資産変化\| の 2 つで決まる
  可能性が高い(あらかじめ記録)。
- 版 2 と版 4 がともに勝つ場合は、純資産の改善が大きい方を採用する。
- 多重比較の補正はしない(候補 2 版 × 主指標 3 つ)。補正しないぶん勝ちやすい側に甘い。
- **版 3(持続性)は採用の候補にしない**(補助的な根拠。スペック B.3)。比較には載せる。
- コスト重み付き proximity は使わない(自己参照的)。

## 生成の前に決めたこと

| 項目 | 決定 | 理由 |
|---|---|---|
| 頻度の出典 | **AGS (1994) の NBER WP 3942(1991)で確認できた値だけ** | Ofek (1993) は本文を入手できず(Elsevier、オープンアクセスの版なし)、スペックの規則により使わない。QJE 掲載版は入手できず、WP と QJE の違いは確かめていない |
| 頻度の分母 | 困窮企業 102 社全体 | AGS Table 3 は再建策をとった 76 社が分母。本研究の GC 企業は再建策をとったかで選ばれていない |
| 変換 | **c = 1/f**(−log f は参考として計算のみ) | 対応づけのない科目を 1.0 とすることが「f = 1(制約なく動かせる)」に対応し、現金預金 = 1.0 の正規化と整合する。−log f は f = 1 で 0 になり、正規化の基準点がない |
| 対応づけ | 与信枠の縮小 22 社 → 短期・長期借入金の減少、公募債の交換の成功 34 社 → 社債(流動・固定)の減少、総資産の 20% 超の資産売却 21 社 → 有形固定資産・投資その他の資産の減少。**6 科目、減少の向きのみ。残り 26 科目は 1.0** | 定義を本文で確認できた施策だけ。銀行債務のリストラ 78% は大半が条項の免除・期限延長で残高を変えないので使わない。設備投資の削減 83% はフローなので使わない |
| ABJ の 1.6 | **一律には適用しない** | SG&A(費用のフロー)の売上に対する粘着性で、BS の残高を動かすコストではない。代わりに同じ形の回帰を科目別に自前で推定し(`persistence.md`)、β1 と β1 + β2 がともに 5% 水準で正の科目だけ比 r を使う(版 4) |
| 版 4 の合成 | w+ = c / √r、w− = c × √r(w−/w+ = r、幾何平均は版 2 の c) | 現金預金の幾何平均 1.0 を保つ |
| 版 3 の変換 | c = (1 − ρ現金) / (1 − ρ)、増減は対称 | 1 − ρ を平均回帰の速さとみなす |
