# ステージ55 A: 正例(実際の遷移)と負例の構築

## A.1 正例(`pairs.csv`)

- 状態: 各年度末の総資産で割った 32 科目。始点 = 2022 年度の書類の当期、終点 = 2024 年度の書類の当期(推定用パネル)。
- 社数: class 2 → 回復 15、class 1 → class 0 57、合計 72。

**再現の確認**(ステージ30・34・47 の規則でやり直した集合との一致):

- class 2 → 回復: 使用 15 社、規則でやり直し 15 社、完全一致
- class 1 → class 0: 使用 57 社、規則でやり直し 57 社、完全一致

## A.2 期間

- 案 1(2 年の遷移をそのまま使う)。生成の経路は 5 年なので、**正解の期間は生成の 2/5**(限界として明記する)。

## A.3 負例(`negatives.csv`)

- 候補: 生成の目標の候補と同じ class 0(除外後 3,768 書類)。その企業自身の書類は除く(候補にその企業の書類がある始点: 69 / 72)。
- 無作為: 乱数 seed 0 で各始点 10 社(計 720)。
- 近い企業(hard negative): 現行の等重み距離で近い順に 10 社(計 720)。

## 注意: この正例と負例で学習すると、何を学ぶか

- 正例の終点は**同じ企業の 2 年後**、負例は**別の企業**である。
- 現行の等重み距離でも、実際の終点は無作為の負例 10 社すべてより近い(61 / 72 社)。近い企業 10 社すべてより近い始点も 40 / 72 社ある。
- 正例と負例の違いの多くは、「企業は 2 年後も自分に似ている」(持続性)で説明できる。
- **この対で学習した距離は、「同じ企業らしさ」(持続性の高い科目に大きな重み)を学ぶ可能性が高い。** これはステージ32 の持続性の重み(不採用)と同じ方向である。
- 一方、生成で距離が使われるのは、**別の健全企業**を対応先に選ぶときである。
- 学習の課題(自社の将来を他社から見分ける)と、使い道(別の企業の中から選ぶ)が違う。
- **候補にその企業自身の書類がある始点が 69 / 72 社ある**(負例からは除いた)。再建群の企業は、自社の後の年度の書類が class 0 の候補に入っている。
