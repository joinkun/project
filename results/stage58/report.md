# ステージ58: 群内分散による標準化(Gnanadesikan et al. 1995)

**結論: 不採用。最終設定は `s47_final`(等重み最近傍、K = 13、n = 1)のまま。**
- 群内分散で科目を標準化すると、払込資本(資本金・資本剰余金)の重みは軽くなる(現金 = 1 で 0.12〜0.56)。
- その結果、払込資本の小さい対応先を選び、払込資本を減らす企業が 98〜100% に増える(実データ 23〜36%)。
- 案 1(class 内の分散)は全体の分散とほぼ同じで(対応先の 98% が一致)、B.4 の「全体 < 群内」の検証はこのデータでは成り立たない。

規則(群の定義・重み・採用基準)は `criteria.md` に、集計の前に記録した(コミット c80cb82)。集計・生成の後に変えた規則はない。

## E.6 C(対数正規の Bregman ダイバージェンス)の判断

**実施しない。** 理由:
1. 対数正規の尤度コストによる最近傍は、ステージ50 で実施済みで、不採用だった(class 2 の純資産の改善 −0.095、違反 7)。
2. 対数正規の負の対数尤度は x̃ について凸でない(ステージ49 D.2)。Bregman ダイバージェンスにするには凸な生成関数が要るが、それは別の分布の仮定になる。
3. 凸性が要るのは射影(二次計画)で、対応先の選択(最近傍)には要らない。対応先の選択に使う限り、ステージ50 と同じ問題(金額の大きい科目の一致が崩れる)が起きる。
4. B で、科目の尺度をそろえる方向(1/σ²)が払込資本の頻度を悪化させた。尺度をそろえる別の形(対数比)も、ステージ50 で同じ向きの結果だった。

## E.8 想定と違った点

1. スペックは「払込資本の重みはステージ57 より大きくなる」と見込んでいたが、小さくなった(0.32・0.15 対 1.59・1.00)。事前の予想(`criteria.md` §0.1)どおり。
2. 案 1 の群内分散は全体の分散とほぼ同じだった(比 0.906〜1.000)。class 0 が 95% を占める断面では、プールしたクラス内分散は群構造を反映しない。この結果、B.4(理論の再現)は検証できなかった。
3. class 1 では標準化した 3 設定(2・4・5)が主指標で優れた。ただし違反(項目 5)が増えた。K = 31 の等重み(設定 1)自体にも class 1 で違反があり、「K = 31 で統一」した比較では、基準 1 は class 1 でどの設定も満たさない。
4. MAD 版は資本金の重みを大きく(27.7)したが、払込資本を減らす企業は減らなかった(98〜99%)。ロバスト化の効果(3 対 2)は class 2 の順位相関で +、class 1 の純資産の改善で − と、向きがそろわない。
5. 対応先の総資産 / 始点が 1.54 → 2.85〜3.70 に大きくなった。払込資本と借入金(金額の大きい科目)の一致が崩れると、規模の違う企業が対応先になる。ステージ50・55 の所見と同じ。
