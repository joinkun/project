## 最終設定

等重み最近傍 + W1 + PCFM + R3 + 上限 γ = 0.757 + 第 2 層の制約 + α = 0.5 + β = 0.3
+ **不活性制約(規則 M、4 科目: 売上債権、固定資産その他、自己株式、評価・換算差額等その他)** + 目標 baseline。
Flow Matching(K = 13、5-fold、50 epoch)、seed 0/1/2。class 2 は 57 社を生成し外れ値 2 社を除く 55 社で、class 1 は
132 社を生成し外れ値 1 社を除く 131 社で評価(class 1 は class 2 → class 0 で学習した速度場を当てる)。

再現性: 最終設定の出力はステージ41 の設定 2b と、従来(不活性制約なし)の出力はステージ31・34 と、それぞれ完全に一致した(差 0)。

## 論文に書く事実

- **不活性制約なしの従来の最終設定は、自己株式を持たない企業の 80〜95% に自己株式を生じさせていた**
  (class 2 36 / 45 行、class 1 63 / 66 行)。実データでは、苦境企業(class 1+2)で自己株式が 0 から計上されたのは
  78 組中 0 件(健全企業では 7.5%)。**符号制約では検出できない**(自己株式は負の科目で、0 から負になるのは符号として正しい)。
- チェック 15(規則 M の 4 科目)で数えると、従来の最終設定は class 2 で 128 / 165 行、class 1 で 315 / 393 行が違反する。
  **ステージ41 で報告した「162 / 165 行」は、チェック 15 が規則 S の 17 科目を見ていたときの数**で、確定した定義では 128 / 165 行。
- ステージ40 の出現の集計の誤り(符号が自由な科目の「0 から負」を数えていなかった)は、静かな失敗の 9 件目として
  `results/stage27/silent_failures.md` に記録した。

## 残る限界(今は対処しない)

- **少額からの膨張**: 不活性制約は始点が 0 の企業にしか効かない。自己株式などは少額の保有からも膨らむ(始点が総資産比
  1e-6〜1e-3 の行の 67〜90% が 1e-3 超へ。実データの 1 年は 12%)。BS 表のソフトフロント(自己株式 −0 → −8 百万円)。
  対処には倍率制限が要るが、制約を増やし続けないため保留(`HANDOFF.md` §8)。
- R1(利益剰余金の固定)の感度分析は、ステージ31 の不活性制約なしの数値のまま(再計算していない)。
