# ステージ64: 輸送問題として解く

**結論**
1. **輸送計画はすべて健全に解けた**(2 class × 30 設定)。全設定で収束し、質量 0 の行は 0、輸送質量は 1(始点側を厳密に保存)。
   - 不均衡 OT は自前の対数領域の実装(τ0 = ∞)で解いた。ステージ13・50 の破綻(質量 0 の行、輸送質量 0.068)は起きない。
2. **最近傍との一致(本命 = 不均衡 OT の代表)**
   - class 2 は 54 / 55(98%)で、ほぼ最近傍に帰着した。
   - class 1 は 109 / 132(83%)で、17% の企業で別の対応先を選んだ。class 1 では 132 社すべてが異なる対応先になる(最近傍は 120 社)。
   - バランス OT の argmax は最近傍とほとんど一致しない(class 2 で 4 / 55、class 1 で 6 / 132。厳密解では 0 / 55)。
3. **生成の主指標は、不均衡 OT の argmax と最近傍で差がない**(両 class、すべて有意差なし)。
   - バランス OT の argmax は、class 1 で大きく劣る。違反 0 の λ̃*_0 が 30 になり、再建しない(純資産の改善 −0.162、有意)。
   - **輸送計画を解く効果は「OT ≈ NN」(不均衡)・「OT < NN」(バランス、class 1)。**
4. **重心(対照)は、識別 AUC 0.995 / 0.999 で実データと区別できる。** 生成の主指標では、class 2 で劣らず(純資産の改善 0.394、有意差なし)、class 1 で劣る(−0.051、有意)。「重心は使えない」は、AUC では支持され、生成結果では class 1 でだけ支持される。

## F.2 A.4: 最近傍との一致

最大質量の対応先が最近傍と同じ行の数:

| 方式 | class 2(/ 55) | class 1(/ 132) |
|---|---:|---:|
| バランス 厳密解 | 0 | 1 |
| バランス ε = 0.001 / 0.005 / 0.02 / 0.1 | 4 / 7 / 10 / 20 | 6 / 24 / 29 / 32 |
| 不均衡 ε = 0.001、τ1 = 0.001 / 0.01 / 0.1 / 1 / 10 | 55 / **54** / 53 / 36 / 33 | 131 / 127 / **109** / 93 / 91 |
| 片側制約(すべての ε) | 55 | 132 |

(太字は事前の規則による代表: ε = 収束した中で最小の 0.001、τ1 = 実効サポートの中央値 ≤ 20 の最大。class 2 は 0.01、class 1 は 0.1)

- **代表の不均衡 OT の一致率**: class 2 は 98% で「ほぼ最近傍」、class 1 は 83% で「最近傍と異なる対応先を選ぶ」(`criteria.md` §3 の区分)。
- **一致しない行の性質**:
  - class 2 は 1 行(S100TSUR)。C̃ の差は 0.013 で、払込資本比率は最近傍 0.613、argmax 0.276。
  - class 1 は 23 行。C̃ の差の中央値は 0.021(コストはほぼ同じ)で、払込資本比率の中央値は最近傍 0.162、argmax 0.092。
- **一致しない理由(混雑)**:
  - 最近傍では、複数の始点が同じ対応先を選ぶ(class 1 で最大 4 社、異なる対応先は 120 / 132)。
  - 不均衡 OT は、目標側の質量が μ1 から離れることに罰を課すので、混雑した対応先を避ける。class 1 の argmax は 132 社すべてが異なる対応先になった。
  - ただし、不一致の 23 行のうち、最近傍が共有されていたのは 12 行で、残り 11 行は近くの始点との競合による。
- バランス OT は、各始点の質量が 1/n1 以下の対応先に均等に広がるので、argmax は 1/n1 ちょうどの多数の対応先からの選択になり、最近傍とほとんど一致しない。

## F.5 C: 発表での記述案

**C.1 OT の枠組み(修正版)**

> 苦境企業の経験分布 μ0 と健全企業の経験分布 μ1 の間の、エントロピー正則化つきの不均衡輸送を解く(始点側は厳密に保存し、目標側は KL で緩める)。
>
> π* = argmin Σ π_ij c(x_i, y_j) − εH(π) + τ1 KL(πᵀ1 ‖ μ1)
>
> 地上コスト c には、方向別の重みを持つ非対称 L1 を用いる。Monge–Kantorovich の定式化は、下半連続で下に有界なコストを許すので、c(x, y) ≠ c(y, x) でよい(Villani 2009 などの一般論。本研究では原典の該当箇所を未確認)。

- **削除する記述**: 「距離を用いる既存のリコースでは対称性が強制される」。最近傍 argmin_j c(x_i, y_j) も非対称のコストをそのまま使えるので、非対称性は OT に固有の利点ではない。
- **Villani (2009) / Peyré & Cuturi (2019) の該当箇所は、まだ原典で確認していない**(ステージ59 B.1 は未実施)。スライドに定理番号を書く前に確認が要る。

**C.2 最近傍との一致**

> 輸送計画を解き、最大質量の対応先(実在企業)を目標とした。本データでは n1/n0 ≈ 68(class 2)・29(class 1)で、バランス輸送では各始点が 68.8 社・28.9 社(厳密解)に質量を広げ、最近傍と一致する対応先はほとんどない(0〜6 社)。不均衡輸送(目標側を KL で緩める)で局所性を回復した。その結果、最大質量の対応先は、class 2 で 98%、class 1 で 83% の企業で最近傍と一致した。一致しない対応先は、複数の始点が同じ企業に集まる「混雑」を避けたもので(class 1 で全 132 社が異なる対応先)、生成の主指標は最近傍と区別できなかった。OT の枠組みで解き、この設定では最近傍にほぼ帰着した。

**C.3 重心を使わない理由**

> バリセントリック射影は OT の標準的な構成だが、本データでは目標点が実データとほぼ完全に区別できる(識別 AUC 0.995・0.999)。無作為な 2 社の平均でも 0.92 に達する。原因はゼロの構造で、平均を取るとゼロが埋まる(未払金がゼロの企業は、実データで 40%、2 社の平均で 14%)。本研究は最大質量の対応先(実在企業)を目標とする。

- 注記: 生成の主指標では、重心は class 2 で劣らず(純資産の改善 0.394 対 0.329、有意差なし)、class 1 で劣った(−0.051)。「重心を使わない」根拠は、主に目標点の非現実性(AUC)である。

## F.6 想定と違った点

1. class 1 では、不均衡 OT の対応先が 17% の企業で最近傍と違った。それでも生成の主指標は同じだった。QP の第 1 項・第 2 項が、対応先の小さな違いを吸収する。
2. バランス OT の argmax は実在企業で AUC も良い(0.44〜0.59)が、生成では最も悪かった(class 1 で再建しない)。「実在企業を目標にする」だけでは十分でなく、「始点に近い実在企業」であることが要る。
3. 重心は class 2 では生成の主指標で劣らなかった。AUC の悪さが、そのまま生成結果の悪さにはならない。
4. 計算時間は、ε = 0.001 の大きい τ1 で 1 設定 11〜14 分(class 1)。不均衡 OT の反復は、τ1 が大きいほど遅い(φ1 = τ1 / (τ1 + ε) が 1 に近く、収束が遅い)。
