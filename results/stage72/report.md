**結論: F1(τ1 = 0.05、m = 10)は、事前に記録した 4 条件をすべて両 class で満たし、新しいメイン手法として採用する**(`criteria.md`、コミット 0e3f92d)。

- **安全マージン (1 − 10⁻⁶)**: 項目 5 の違反は、全 9 設定 × 10 λ̃ × 2 class で **0 件**(ステージ71 は class 1 で 38 件)。
  - class 1 の較正の格子は、全設定・全 λ̃ で違反 0 になった(class 2 の設定 2 に 1 件、下記)。λ̃*_0 は 0.3〜3 で、L の形から自然に決まった。
- **F1**: 純資産の改善は class 2 で 0.377(設定 4 との差 +0.103 [+0.081, +0.145])、class 1 で 0.199(+0.024 [+0.005, +0.052])。解消率は 1.00 / 1.00。

  - **ただし順位相関の点推定は、両 class とも設定 4(+0.429 / +0.447)より低い。**
- **事前 対 事後の対比**:
  - 指示文の「先に混ぜると、ゼロ構造や貸借整合が壊れる」は、**目標(QP の前)についてだけ成り立つ。** QP の後の終点では、事前に混ぜても貸借は一致し(10⁻¹⁶)、ゼロはむしろ F1 より多く残る。
  - F1 が事前の混合より優れていたのは **class 1 の順位相関**だった(F1 +0.371、事前 L2 重心 +0.238、事前 M1 +0.111。事前の 2 つは有意に劣る)。

**目標(QP の前)**: 指示文のとおり、事前に混ぜた目標はキメラになる。

- L2 重心はゼロが消え(3.31 / 2.52)、AUC 0.94〜0.96。
- M1 は貸借が崩れる(残差 0.04〜0.05)。
- F1 の目標は実在企業そのもの(残差は元データの丸め、AUC 0.732 / 0.545)。

**終点(QP の後)**: 指示文の予想と違い、事前に混ぜても終点は壊れない。

- QP は 𝓕 の上で解くので、どの目標でも終点は貸借一致を満たす(10⁻¹⁶)。
- 非対称 L1 の移動コストは始点の 0 を動かしにくいので、ゼロも残る(8.7〜9.6)。
- **F1 の終点のゼロ(7.38 / 7.48)は、事前の混合や argmax より少ない。** 候補ごとに動かす科目が違い、平均すると「どれかの候補で動いた科目」の和集合が非ゼロになるため。それでも健全企業(6.70)以上は保つ。

**性能**:

- class 2 では、4 つとも純資産の改善が設定 4 より有意に高い(0.349〜0.394)。差は小さい。
- **F1 が違うのは class 1 の順位相関**。argmax(+0.065)、事前 L2(+0.238)、事前 M1(+0.111)は設定 4 より有意に劣るが、F1(+0.371)は劣らない。
  - 解釈: 1 社の目標への射影は、その企業に固有の科目の動きを再建の方向として持ち込む。複数の実在企業への最適解を平均すると、それが打ち消され、再建群に共通する科目の動き(順位相関が測るもの)が残る。
  - 先に目標を混ぜると、QP は 1 つの合成点への疎な解になり、この平均化が起きない。

**数式の上の違い**:

- QP の解写像 τ ↦ y*(τ) は区分的にアフィンで、非線形である(制約と L1 の移動コストによる)。したがって Σ p̃ y*(y_j) ≠ y*(Σ p̃ y_j)。
- F1 は「各候補への最適な再建の期待値」、事前の混合は「期待された目標への最適な再建」。
- 𝓕 が凸なので、F1 の終点はつねに 𝓕 に入る(定理 1 の凸結合)。

**バランス OT**:

- 事前 L2 重心(計画の全体、実効 70.8 / 29.6 社)は、目標の AUC が 0.996 / 0.999。それでも終点の純資産の改善は class 2 で +0.102(有意)、class 1 で −0.006(有意でない)だった。
- バランス OT の F1(S(i) の上位 10 社、p̃ はほぼ一様。S(i) は計画の質量の 15〜35% しか覆わない)は、class 1 の順位相関が最も高い(+0.520)。ただし、純資産の改善は設定 4 と同じ。
- いずれも判定の対象ではない(事前に記録した候補は F1 τ1 = 0.05 だけ)。

## 5. 想定と違った点

1. **事前に混ぜても、QP の後の終点は壊れなかった**(上記)。F1 の利点は、ゼロや貸借ではなく class 1 の順位相関に出た。
2. **F1 の終点のゼロは、1 社の目標より少ない**(和集合の効果)。条件 3(≥ 6.70)は満たす。
3. **F1 は払込資本を減らす企業を増やす**(class 2 で 58%、実データ 36%)。
4. **F1 の順位相関の点推定は、設定 4 より低い**(有意ではない)。
5. **バランス OT の上位 10 社の質量はほぼ一様で、計画の一部しか覆わない**。それでも class 1 の順位相関は最も高かった(判定の対象外)。
6. 事後選択のない m = 1 では、F1 は採用基準を満たさない。**m = 10(事後選択)は F1 でも必要**だった。
