規則は `criteria.md`(コミット 4caa78d、計算の前に記録)。表は `report_tables.md`、数値は `summary.json`、コストの診断は `costs.md`、BS 表は `bs.md`。

**結論: 事前の規則(D1、5 fold の交差適合)を満たしたのは R1・F1 と R2・F1 の 2 つ。L_f の fold 平均で R1・F1(1.88)が R2・F1(1.98)より小さく、規則上は R1・F1 がステージ69 の設定を置き換える。** ただし次の 4 点は、規則の外で重い。

1. **class 1 の「優れる」は実質的に小さい。** 純資産の改善の差の fold 平均は +0.001 である。fold f2(λ̃*_f = 3)だけが −0.081 で、ほかの 4 fold は +0.017〜+0.026 で区間が 0 より上だった。
2. **少額科目の膨張が大きく増える。** 膨張は 12.7% / 24.2% で、基準は 2.0% / 2.2%。BS 表では、始点で 0 の非支配株主持分・無形固定資産が終点で正になる。
3. **採用した設定の最終的な λ̃ を、事前の規則は決めていない。** λ̃*_f は fold ごとに 0.03・0.1・3・0.1・0.1 とばらつく(下の §5)。
4. **計算の途中で規則を 1 つ追記した**(`criteria.md` §6)。fold f2 では払込資本↓ の SE が 0 になり、L_f が計算できなかった。

## 5. 決めていないこと(要判断)

事前の規則は「R1・F1 が置き換える」までで、**論文の最終設定として 1 つの生成を作る方法**を決めていなかった。候補は次の 3 つ。

| 案 | コスト | λ̃ | 評価の数値 | 注意 |
|---|---|---|---|---|
| (a) | 57 社の全体 | fold の λ̃*_f の中央値 = 0.1 | D1 の交差適合の値 | 生成は `gen_full/*/R1_f1__l0.1` が計算済み |
| (b) | 57 社の全体 | 57 社の全体の目標で較正し直す | D1 の交差適合の値 | 較正の目標とコストのプールが同じ 57 社になる(ステージ74 で問題にした形) |
| (c) | fold ごとのまま | fold ごと | D1 | 1 社に 5 つの生成ができ、論文の BS 表が 1 つに決まらない |

私の推奨は (a)。λ̃ を選ぶのに 57 社の目標を直接使わず、評価の数値は交差適合のままで済む。

## 6. BS 表(`bs.md`、class 2 の 5 社、D2 の生成)

目で読んで気づいた点:

- **膨張**: ラピーヌでは、始点で 0 の非支配株主持分が 8、無形固定資産が 16 になる。ANAP では、有形固定資産が 0 → 21、無形固定資産が 0 → 11。F1 で複数の候補を平均するため、候補の誰かが持つ科目が少額で現れる。
- **極楽湯 HD**: R1・F1 は資本金を 5,203 → 555 に減らし、利益剰余金を −7,373 → −854 にする(減資による欠損の填補の形で、実際の再建でも見られる)。一方、短期借入金は 552 → 1,218 に倍増し、棚卸資産は 112 → 349 になる。
- **ジェイ HD**: 貸倒引当金(流動)が −123 → −1、流動資産その他が 240 → 75 で、債権の償却の形である。資本剰余金は 478 → 501 に増える(増資)。
- ステージ69 の設定は、どの企業でも動く科目が少ない(変更科目数 5)。

## 7. 想定と違った点

1. 比率コストでも減資は安いまま(§1)。
2. 比率コストは λ̃* を小さくし、移動を大きくする方向に較正された。純資産の改善は上がるが、膨張も増える。
3. fold f2 の目標(払込資本↓ 0 / 11 社)は、11〜12 社の fold では較正の目標が不安定になることを示している。
4. class 1 の参照を fold に分けると 17〜19 社になり、基準の順位相関も fold で +0.03〜+0.46 とばらつく。順位相関の比較は検出力が低い。
