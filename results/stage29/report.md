  出力に `re_branch`・`re_transfer`・`re_profit` の列を追加した(状態ベクトルは 32 次元のまま)。
- テスト 4 件を追加(分岐の制約、γ = 0 で利益を許さない、分解、和集合への射影で近い分岐を採る)。

**スペックの式からの変更(判断をお願いしたい)**: ΔRE = −(Δ資本金 + Δ資本剰余金) + ΔRE_利益 を
そのまま課すと、増資(Δ払込資本 > 0)で RE が同額減る。これでは増資で純資産が増えなくなる。
そこで払込資本の増減で 2 つに分けた。

- 分岐 A(増資・振替なし): Δ払込資本 ≥ 0、0 ≤ ΔRE ≤ γA0
- 分岐 B(欠損填補の振替): Δ払込資本 ≤ 0、振替 = −Δ払込資本、0 ≤ ΔRE + Δ払込資本 ≤ γA0

2 つの和集合は凸でないので、補助変数を 1 つの QP に入れる代わりに、分岐ごとに射影して近い方を
採った。同じ期間に増資と減資を両方行う経路は、差し引きで扱われる。
既存の α = 0.5(資本金・資本剰余金はそれぞれ始点の 50% 以上)も課したので、振替は払込資本の
半分までに限られる。

**会計的根拠(原典で確認)**:

- 無償減資による欠損填補は、資本金 → 資本剰余金 → 繰越利益剰余金の振替で、純資産(株主資本)の
  総額は変わらない。布袋 (2024) はこれを「損失処理減資」と呼び、資本金 → 資本剰余金の振替だけの
  「項目変更減資」と区別している(p.37)。項目変更減資は払込資本の中の振替なので、本研究の
  分解(払込資本 = 資本金 + 資本剰余金)では振替として現れない。
- 布袋正樹 (2024)「中小企業向け優遇税制と上場企業等の減資行動」『会計検査研究』70 号、33–57 頁
  (doi:10.51016/kaikeikensa.70.0_33)。梗概(p.33)に「上場企業等の減資は2016 年度から緩やかに
  増加し，2020年度以降に急増した。減資タイプをみると，有償減資は非常に少なく，無償減資が
  ほとんどを占めている」とある。対象は資本金 1 億円超から 1 億円以下への減資で、減資全般ではない。
  また「負の利益剰余金が大きな企業ほど損失処理減資を選択する傾向が強い」とある。
- 会社法 309 条 2 項 9 号(e-Gov の現行条文で確認): 資本金の額の減少(447 条 1 項)の株主総会決議は
  原則として特別決議である。ただし、定時株主総会で定め、かつ減少額が欠損の額(法務省令で
  算定)を超えない場合を除く。

### 基準 2 についての所見(基準は変えない)

実データの GC 企業 50 社は、大半が再建していない企業である(RE の中央値 −14%/年)。一方、
生成は構成上「健全企業へ向かう経路」なので、RE を減らす経路は出てこない。基準 2 は
「再建の経路」を「GC 企業全体」と比べているので、どの設計でも満たしにくい。再建した GC 企業
(GC 注記が外れた企業)だけの分布があれば、より適切な比較になる。今回は基準を変えずに判定した。

### D.2 論文の記述案

> t ∈ [0,1] を 5 年と定義した場合、利益剰余金を固定する設定(R1)は、5 年間の営業上の改善を
> ゼロと仮定する保守的な設定である。本研究では、利益剰余金を固定しない設定(R3、上限付きを含む)
> と、欠損填補の減資(資本金・資本剰余金から繰越利益剰余金への振替、純資産は不変)を明示的に
> 表し利益部分を制限する設定(R4)も試した。採否の基準は、推定用パネルの GC 注記企業 50 社から
> 生成の前に定めた。いずれの設定でも、利益剰余金が増える企業の割合が実データ(20%)と整合
> しなかった(R3 は 100%、R4 は 81%)。実データでは振替を差し引いた利益部分の 90 パーセンタイルが
> 負であり、利益による増加の上限は 0 となった。上限を 0 とした R4 は欠損填補の振替のみを生成し、
> 純資産を改善しなかった。以上から R1 を主設定とする。再建経路は財務的手段(増資、返済、
> 資産売却)のみで表現される。欠損填補の振替は純資産を変えないので、R1 の再建経路の評価は
> 振替の有無に影響されない。

## 8. 想定と違った点

- **実データに「純粋な利益による RE の増加」は 1 社もなかった。** 利益部分の p90 が負で、
  γ は機械的に 0 になった。スペックが想定した「γ の根拠となる利益の社」は存在しなかった。
- スペックの R4 の式は、増資で RE が減る形になっていた。払込資本の増減で分岐させて実装した。
- 利益を許すと(γ = 0.40)、利益部分 = 0 の社は 0 社で、全社が RE を増やした。下限 0 は効かなかった。
- γ = 0 でも 81% の社が振替を選んだ。純資産は変わらないのに validity は上がった(+0.011)。
  validity が勘定の振替に反応することが分かった。
- R1 も基準 2 を満たさない。基準 2 は、再建の経路と、大半が再建しない GC 企業全体を比べている。
- 布袋 (2024) は原典で確認できた。ただし対象は資本金 1 億円以下への減資で、GC 企業の欠損填補に
  限った分析ではない。会社法 309 条 2 項 9 号は、布袋 (2024) ではなく条文で確認した。
