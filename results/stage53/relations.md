## B.4 振替の検出

### 主の検定: 会計の操作で作った「振替だけの状態」(class 2 で利益剰余金が負の 50 社)

- 欠損を資本剰余金、次に資本金(下限 α まで)から填補。純資産は不変。利益剰余金がちょうど 0 になった社 36 / 50。
- **ΔPL の中央値 +2.62 [-4.23, +61.36]、上がった社 26 / 50、片側 Wilcoxon p = 0.0034**
- **判定(criteria.md §3): 振替で上がる → 該当**
- 参考(判定に使わない): 欠損の 99% だけ填補(利益剰余金を 0 にしない)と ΔPL の中央値 +7.54、上がった社 35 / 50(利益剰余金のゼロ率は class 0 でほぼ 0% なので、ちょうど 0 になると離散部分で大きく下がる)
