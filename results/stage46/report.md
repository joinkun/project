# ステージ46 報告: 資本金の下限の再設定

下限と判定基準は `criteria.md`(生成の前に記録、コミット 88197e3)。基準は変えていない。
詳細: `capital_depth.md`(A.1)、`results.md`(B・C)、`summary.json`。

## 結論

- **事前の基準では、設定 2(α = 0.00199)は採用しない。最終設定は α = 0(ステージ45)のまま**。
  - 基準 1(違反 0)と基準 3(主指標が悪化しない)は満たした。
  - 基準 2(減資の深さが実データに近づく)を満たさない。半減させた企業(27% / 25%)も、1% 未満まで減らした企業
    (22% / 16%)も、α = 0 と全く同じだった。下限 0.00199 は 0.01 より小さいので、企業は 0 ではなく 0.2% で止まるが、
    それも「1% 未満」に入る(事前に記録した見込みのとおり)。
- ただし、**資本金を 0 にした企業は 22% / 16% → 0% / 0.8% に減り、実データ(0 / 171)に一致した**。この指標は事前の基準に
  入れていない。例: ソフトフロントは 22.2 → 0.044 百万円(約 4.4 万円)で、厳密には 0 でないが、BS の読み手には 0 と
  ほとんど区別できない。
- **払込資本の方向は α によって変わらない**(増えた企業 14〜16%、減った企業 82〜84%。α = 0.5 でも同じ)。(5) を外したことで
  減資の方向が強まった、という可能性は支持されない。

## 2. A.2 下限の決定(`criteria.md`)

- α = 0.0019850022055580064 = class 1+2 の 1 年で資本金が減った 46 組の比の 1 パーセンタイル(案 1)。対象は資本金だけ。

## 4. B.3 判定

| 基準 | class 2 | class 1 | 満たす |
|---|---|---|---|
| 1. 15 項目の違反 0 | 0 | 0 | はい |
| 2. 減資の深さが実データに近づく(実データとの差 設定 1 → 2) | 半減 0.091 → 0.091、1% 未満 0.195 → 0.195 | 半減 0.065 → 0.065、1% 未満 0.138 → 0.138 | **いいえ** |
| 3. 主指標が悪化しない | 悪化なし | 悪化なし | はい |

**設定 2 は採用しない**(最終設定は α = 0 のまま)。

判断を委ねたい点: 事前の基準 2 は「半減」と「1% 未満」で深さを測り、「0 にする」は入れていなかった。設定 2 は「0 にする」問題
(ソフトフロント 22 → 0)を、主指標を変えずに実データの水準(0%)まで解消する。ただし 0.2% で止まるので、BS の読み手には
0 に近い値が残る。実データの深さ(1% 未満 2.3%)に近づけるには、下限は 0.01 程度が必要になるが、それは A.2 の案 3
(恣意的な固定値)に当たる。

## 6. C.3 原因の検討(払込資本 / 総資産)

| 項目 | 中央値 |
|---|---:|
| 始点(class 2、55 社) | **1.144** |
| 目標(各始点の最近傍の class 0 企業) | **0.820** |
| class 0 全体(4,074 書類) | 0.129 |
| 始点(class 1、131 社) | 0.481 |

- **目標の比率が始点より高いのは 55 社中 13 社(24%)**。76% の企業で、目標は払込資本の比率が始点より低い。
- 苦境企業(class 2)は払込資本が総資産を上回り(中央値 1.14、欠損を払込資本で支えている)、目標へ向かうと払込資本の比率が
  下がる方向になる。仮説と整合する。ただし、最近傍の目標(0.82)は class 0 全体(0.13)よりはるかに高い。等重み最近傍は、
  払込資本の比率が高い class 0 企業を選んでいる。
- これは記述のための材料で、対処はしない。

## 7. 経緯(F の指示による)

- **ステージ44**: (5) を「残す」と判定したが、判定が循環していた(チェック 8 は制約 (5) とほぼ同じ条件で、課したものを
  チェックで検出していた)。
- **ステージ45**: (5) とチェック 8 を完全に外した。半減する企業の割合は実データに近づいたが、資本金を 0 にする企業が
  16〜22% 出た(実データ 0%)。**行き過ぎた**。
- **ステージ46**: 実データの分布から下限を決めた(α = 0.00199)。「0 にする」は解消したが、事前に定めた深さの基準
  (半減、1% 未満)は変わらず、採用の基準を満たさなかった。
- 教訓: 制約の設計は「あり / なし」の二択ではなく、値の選択が重要である。値を実データから機械的に決めても、何で評価するか
  (今回は深さを「1% 未満」で測った)によって結論が変わる。

## 8. 想定と違った点

1. **下限 0.00199 は、半減と 1% 未満の割合を全く変えなかった**。企業は 0 の代わりに 0.2% で止まるだけだった。
2. 「0 にする」企業は実データ並みに減ったが、事前の基準に入れていなかった。
3. 実データの「完全に 0」は 1 件あり(メタプラネット)、案 2(最小値)は使えず、案 1 の値もこの 1 件に引きずられた
   (除けば約 0.0044)。
4. α を 0.5 に戻しても、払込資本を減らす企業の割合は 84% のまま(資本金と資本剰余金を半分までは減らせるため)。
5. 最近傍の目標は class 0 全体より払込資本の比率がずっと高い(0.82 対 0.13)。
