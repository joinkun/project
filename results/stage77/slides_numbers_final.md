## 3. 確率モデルとコストの対応(`results/stage76/report.md` §1)

移動コスト Ψ(Δ) = Σ_a c_a⁺ u_a + c_a⁻ v_a(u = 増加分、v = 減少分)は、遷移の負の対数尤度(作用)として書ける。

- 輸送は、遷移の期待対数尤度の最大化にあたる。
- QP は、𝓕⁺ の上での事後最頻値(MAP)にあたる。λ は遷移の事前分布の温度。

| モデル | 単位あたりの傾き c± | 生起頻度の入り方 | 対応するコスト |
|---|---|---|---|
| A: u, v を独立な指数分布 | 1/θ±、θ± = (1/N) Σ (±Δ)₊ = (n±/N) × 条件付きの平均の幅 | 傾きに入る | **R3**(平均)、R2(中央値版)、**R1**(企業ごとに規格化した中央値版) |
| B: 非対称ラプラス | 1/s±、s± = m± + √(m⁺m⁻) | 傾きに入るが、比は c⁻/c⁺ = √(m⁺/m⁻)(R3 の比の平方根) | R3 の非対称を縮めたもの |
| C: ハードル(不動の質量 + 向き + 幅) | 1/s±(条件付きの幅) | 固定費 log(s±/p±)(凸でない) | **abs**(ステージ69)は、固定費を除いた凸緩和 |

- **R1〜R3 が厳密に一致するのはモデル A の最尤推定**である。非対称ラプラス(B)ではない。B の式は停留条件から導き、数値の最適化で確かめた。
- 資本金の c⁻/c⁺ は、abs 0.34、R1 0.31、R2 0.20、R3 0.33、B 0.57。**どのモデルでも減資は増資より安い。**
- ステージ49: 変化率の分布は Laplace より裾が重い(Subbotin の b < 1 が 31 / 32 科目)。その負の対数尤度は凸でない。
  - 範囲を限った凸包は、左右で傾きの違う線形になる。
  - ただし傾きは範囲の端で決まる。また、変数(対数の変化率と総資産比の差)が違うので、対応は定性的である。

## 4. 苦境の確率・実データのコストと回復・実行可能性

### 4.1 苦境の確率の低下(`final_feasibility.md`)

分類器は企業単位の 5 分割の交差適合(乱数 42)。out-of-fold の AUC は、苦境 vs 健全で LogReg 0.890 / LightGBM 0.899。確率は学習データの有病率に戻したもので、**実際の倒産確率ではない**。

| class | 分類器(苦境 vs 健全) | ステージ69 の設定: 中央値(終点 ≤ 健全の中央値) | R1・F1(案 a): 中央値(同) |
|---|---|---|---|
| 2 | LogReg | 72.9% → 49.3%(2%) | 72.9% → **25.1%**(4%) |
| 2 | LightGBM | 37.6% → 13.6%(2%) | 37.6% → **0.51%**(4%) |
| 1 | LogReg | 16.5% → 4.7%(18%) | 16.5% → 3.0%(16%) |
| 1 | LightGBM | 0.99% → 0.04%(18%) | 0.99% → 0.01%(25%) |

- R1・F1 は、class 2 の苦境の確率の中央値を大きく下げる。
- **しかし終点が健全企業の中央値以下になるのは 4% に留まる。** 確率の平均は 44.0% → 19.2%(LightGBM)で、一部の企業は高いまま残る。

### 4.2 実データの移動コストと回復の割合(`results/stage76/report.md` §3)

始点で class 1・2 の企業の実際の推移を Ψ の四分位に分け、終点で class 0 になった割合を見た(ラベルはステージ38 の遷移、1 年 348 件・2 年 172 件)。

| Ψ の尺度 | 期間 | 第 1 四分位 → 第 4 四分位 |
|---|---|---|
| class 2 の Ψ | 1 年 | **37% → 25% → 15% → 11%**(単調) |
| class 2 の Ψ | 2 年 | 49% → 53% → 37% → 21%(単調でない) |
| class 1 の Ψ | 1 年 | 38% → 22% → 18% → 10%(単調) |
| class 1 の Ψ | 2 年 | 60% → 44% → 33% → 23%(単調) |

- **移動コストが小さい推移ほど、回復の割合が高い。** 4 系列中 3 系列で単調、全系列で第 1 四分位 > 第 4 四分位。
- 「コストが小さい = 起きやすく、回復につながりやすい」という対応を支持する。
- **ただし相関であり、因果ではない。** 境界に近い企業は小さな変化で class が変わり、大きな変化は事業の縮小・売却などの混乱を含む可能性がある。
