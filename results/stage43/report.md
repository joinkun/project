## 4. B.3 原因の検討

| 符号付きの中央値(32 科目)の順位相関 | |
|---|---:|
| 生成 class 1 対 生成 class 2 | **+0.937** |
| 実際 class 1(全体)対 実際 class 2(再建) | +0.490 |
| 生成 class 1 対 実際 class 2(再建) | +0.314 |
| 生成 class 2 対 実際 class 2(再建) | +0.325 |
| 生成 class 1 対 実際 class 1(全体 / 回復) | −0.113 / −0.159 |

- **生成の class 1 は、生成の class 2 とほぼ同じ向きに動く(+0.937)**。実データでは class 1 と class 2 の向きは半分程度しか
  似ていない(+0.49)。生成 class 1 は、実際の class 1 より実際の class 2 の再建群に近い(+0.314 対 −0.113)。
- 実データで class 2 と class 1 の向きが逆の科目は、投資その他の資産(class 2 −、class 1 +)と流動負債その他(同)。
  短期借入金・未払金は、class 2 の再建群では減る(−)が、class 1 では変わらない(0)。**生成は class 1 にも class 2 の再建の
  向き(有利子負債・その他の負債の圧縮)を当てている**。
- 目標(class 0)は同じなので、違いは始点にある。class 1 は始点の自己資本比率が高く(中央値 0.430、class 2 0.190)、
  生成でも動きが小さい(proximity 0.311 対 0.548、年率 Σ\|Δx\|/A 0.147 対 0.238)。実際の class 1 の動きも小さい
  (0.370 対 0.604)。
- **解釈**: 「class 1 は既に(債務の圧縮などに)対処済みで、さらに class 2 の再建の方向に動かすと実データと合わない」は、
  次の点で支持される。(i) class 1 の実際は、回復した 57 社でも短期借入金が変わらない(債務を圧縮せずに回復している)、
  (ii) 生成は class 1 に class 2 とほぼ同じ向きを当てる(+0.937)。ただし、(ii) は速度場を class 2 → class 0 だけで学習した
  (class 1 を学習に含めない、ステージ34)ことの直接の帰結でもあり、「対処済み」かどうか自体(class 1 が過去に債務を圧縮したか)は、
  このデータ(2 年)では確かめていない。**限界の記述案**: 「速度場は class 2 の再建の方向を学習しており、状態の異なる
  class 1 にも同じ方向を当てる。class 1 の実際の回復は債務を圧縮せず利益剰余金の積み上げによるもので、科目の向きは
  32 科目中 15(動いた科目では 22 中 5)しか一致しない」。

## 6. 想定と違った点

1. **class 2 では、R1 のほうが実データとの符号付き順位相関が高い**(+0.499 対 +0.325、差 −0.174 [−0.213, −0.014])。
   R3 は資本金・資本剰余金を減らして利益剰余金を増やす(振替)が、再建群は資本剰余金を増やす(増資)。R1 は払込資本を
   増やす経路しかないので、向きは再建群に近い。ただし純資産は改善しない(0.000)。class 1 では逆に R3 が高い(+0.179)。
2. 不活性制約は、R1 と R3 の比較に影響しなかった(混ざる心配は数値上なかった)。validity だけが R1 で上がる(0.669 → 0.751)。
3. C.2 の「class 1 → class 0(63 社)」は、パネルにある 57 社で計算した(6 社は変化を計算できない)。
4. **ステージ42 の集計の誤り**: 「両方が動いて向きが一致した科目」を class 2 で 11 と報告したが、正しくは 10。表示用に丸めた値
   (+0.0001)で数えたため、閾値付近の 1 科目(貸倒引当金(流動)、実際は +0.00006)を誤って数えた。ステージ42 の報告を訂正した。
5. ジェイホールディングスのように、最終設定でも振替だけで純資産が改善しない企業がある(解消しない 4 社)。
