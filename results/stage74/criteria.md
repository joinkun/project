## 3. 相対移動コスト(F1-rel)とハイブリッド(F1-hyb)

- **対数変化率**: プールの企業 k について、両期とも非ゼロで同じ符号の科目で、名目額の g_ka = log(|X_{k,2024,a}| / |X_{k,2022,a}|)。
  - s_grow = median{g : g > 0}、s_shrink = median{−g : g < 0}、c_rel = 1/s(n < 5 は §2 と同じ代替)。
- **下限 x̲_a**: パネルの 2024 年度(t = 2024)の全企業で、総資産比 |x_a| が非ゼロのものの 10 パーセンタイル。ただし 10⁻⁴ 以上。
- **始点 i ごとの係数**(x_ia ≥ 0 なら、y が増える向きが絶対値の拡大):
  - x_ia ≥ 0: c̃⁺ = c_grow / max(|x_ia|, x̲_a)、c̃⁻ = c_shrink / max(|x_ia|, x̲_a)。
  - x_ia < 0: c̃⁺ = c_shrink / max(|x_ia|, x̲_a)、c̃⁻ = c_grow / max(|x_ia|, x̲_a)。
- **ハイブリッド**: c̃_hyb^± = √(c_abs^± × c̃_rel^±)(総資産比の差分のコストと相対コストの幾何平均。√|x| の尺度になる)。
- 利益剰余金(輸送と QP の移動コストで 0)、評価差額金(凍結)、非支配株主持分(動かす)の扱いは、ステージ70〜72 と同じ。
- 輸送の地上コスト C_ij = Σ_a c̃_ia^± (y_ja − x_ia)_± と、QP の第 2 項 λ Σ_a (c̃⁺u + c̃⁻v) に、同じ係数を使う。

## 6. 判定(事前)

- **R1(リークなしの F1 の確認)**: A1 がステージ72 の 4 条件を両 class で満たすか。基準はステージ69 の設定。
  1. 違反 0。
  2. 統合した企業数 ≥ 3。
  3. 候補の集合の識別 AUC ≤ 0.762 / 0.736、かつ終点のゼロ ≥ 6.70。
  4. 主指標が有意に劣らず、各 class で少なくとも 1 つが有意に優れる。
  - 満たせば、A1 の数値を F1 の正式な数値とする(ステージ72 の数値はリークありとして置き換える)。
  - 満たさなければ、F1 の採用を取り消し、最終設定はステージ69 に戻す。
  - なお、基準のステージ69 の設定も、class 1 の順位相関の参照と 5 社重なっている(§1)。基準は作り直さない。
- **R2(相対コスト)**: B1・B2 のどちらかが、次をすべて満たせば A1 と置き換える。両方満たせば、class 1 の L が小さい方。
  1. R1 の 4 条件を満たす。
  2. A1 との企業単位の比較で、主指標のどれも両 class で有意に劣らない。
  3. (b) の膨張の割合が、両 class で A1 より低い。

  満たさなければ A1 のまま。

## 7. A-4(コードの整理)

- `projection_qp.project_onto_feasible(enforce_inactive=True)` は、始点で厳密に 0(`x_start == 0.0`)の全基礎科目を 0 に固定する。
- `plausibility.inactive_accounts` は、`INACTIVE_ACCOUNTS` の 4 科目のうち |x| < 10⁻⁶ × 総資産のものを、始点の値に固定する。両者は定義が違う。
- 変更:
  - `enforce_inactive` のゼロの判定を、`INACTIVE_ZERO × |総資産(始点)|` 未満に統一する。
  - `DeprecationWarning` を出し、`frozen_accounts=inactive_accounts(...)` を使うよう案内する。
  - 現在の生成(ステージ60〜72)は `enforce_inactive` を使っていない(既定 False)ので、結果は変わらない。
