# ステージ83 パートC: 再建企業の事例(主モデル、out-of-fold)

構成は各年度の総資産比(%)。生成 ŷ は ŷ / A(ŷ)。総資産は百万円(生成は始点の総資産 × A(ŷ))。
代表例 = DSA(ε = 10⁻²)と ERR^{L1} の順位の平均が中央値に最も近い企業、乖離の例 = ERR^{L1} が最も小さい企業(criteria §3)。
