## 結論(要点)

1. **科目別の変化率 g = log R は、Laplace よりさらに裾が重い**。
   - Subbotin の形状 b は全件で中央値 0.55、範囲 0.33〜1.21。32 科目中 31 科目で b < 1。
   - 唯一の例外(固定資産その他、b = 1.21)は、表示単位の丸め差がほとんどを占める残余科目である(下の注意 1)。
   - AIC で最良の分布族は t 分布(23 科目)。
2. **b は外れ値の扱いに強く依存する**。
   - Tukey の外れ値(各科目 0.1〜8.7%)を除くと、b の中央値は 0.90 になる。
   - Stanley et al. (1996) の b ≈ 1 に近いのは、裾を除いた本体の形だけ。
3. **増減の向きの偏り**:
   - 有形・無形固定資産、長期借入金、資本剰余金、自己株式は「減る頻度が高く、増えるときは大きく増える」。
   - 運転資本(売上債権・仕入債務・未払金)は、変化の大きさがほぼ対称。
   - 資本金は減る頻度が高いが、増えるときの変化は小さい。ただし、総資産で割った値の変化率なので、名目額が動かない科目は総資産の成長で g < 0 側に偏る(§4 の注意)。
4. **困窮企業(class 2)の変化は大きい**。
   - \|g\| の中央値は、32 科目中 28 科目で class 0 の 1.1 倍以上(最大 5.5 倍、利益剰余金)。
   - 分布の差の尤度比検定は、30 科目中 28 科目で有意。
5. **業種差は有意だが、科目差より小さい**。
   - 業種による b の幅は、科目内で中央値 0.16。
   - 科目間の b の範囲は 0.33〜1.21。
6. **当てはめた分布をコストにすると、Δ について凸にならない**(Subbotin で 31 / 32 科目)。
   - b ≥ 1 や対数正規でも、log の凹性のため、増加側の大きな変化で凸性が崩れる。
   - 凸性を保つ近似(区分線形の凸包)は、左右で傾きの違う線形の重みに退化する。
   - **生成への組み込みは見送る**(G の判定)。
7. 生成に使えなくても、**科目別の分布族・形状 b・増減の偏り・不動の質量は、記述統計として報告できる**。

注意 1(残余科目): 資産その他・固定資産その他・負債その他・株主資本その他の 4 つの残余科目は、主に表示単位の丸め差と考えられる。

- 両期非 0 の組の絶対値の中央値は、それぞれ 100 万円・6,000 円・1,000 円・2,000 円。総資産比の中央値は 0〜2e-6。
- 名目額がまったく同じ組が 28〜99% ある。
- これらの分布は、勘定科目の変化として解釈しない。
- 4 科目を除く 28 科目では、次のとおり:
  - b: 全件で中央値 0.55、範囲 0.33〜0.81、**28 / 28 で b < 1**
  - 外れ値を除くと中央値 0.90、範囲 0.48〜1.11、22 / 28 で b < 1

## 8. D.2 凸性の判定(`convexity.md`)

方法: c(Δ) = −log p(log(1 + Δ/x)) を、u = Δ/x の等間隔の格子(R = 0.01〜10、刻み 1e-4)で 2 階差分を取って調べた。

| 分布 | 判定 |
|---|---|
| 当てはめた Subbotin(全件) | **32 科目中 31 科目で非凸**。b < 1 では最頻値で尖り、両側が凹になる。固定資産その他(b = 1.21、丸め差)だけ R ≤ 1.17 で凸(観測の 69%) |
| Laplace(b = 1) | log が凹なので、増加側(R > 1)で凸にならない。凸なのは R ≤ e^μ だけ |
| 対数正規(b = 2、案 A) | R ≤ e^(μ+1) で凸。科目により R の上限は 2.34〜3.62 で、観測の 86〜99.8% がこの範囲に入る |
| 補足: 総資産比の差分 d に Subbotin | b = 0.05〜0.76(32 科目すべてで b < 1)。差分で定義しても凸にならない |

- スペックの「b ≥ 1 なら凸」は、g の関数としては正しい。
- しかし **Δ の関数としては、b ≥ 1 でも増加側の大きな変化で凸性が崩れる**(b = 1 では R > e^μ、b = 2 では R > e^(μ+1))。
- **凸性の判定の実装を一度誤った**:
  - 誤り: log R について等間隔の格子で差分を取っており、Δ についての凸性になっていなかった。
  - 確認: 修正後、理論値(b = 2 で R ≤ e、b = 1 で R ≤ 1、いずれも μ = 0)と一致することを確かめてから判定した。

## 9. D.3 対処案の評価と提案

| 案 | 評価 |
|---|---|
| A 対数正規に限定 | 凸になるのは R ≤ e^(μ+1) の範囲だけ(観測の 86〜99.8%)。範囲の外は、R の上限の線形制約で禁じれば凸にできる。ただしコスト (log(1+u) − μ)² は二次式ではなく、cvxpy の DCP 規則にも合わない(凹関数の 2 乗)ので、区分線形などの近似が要る。当てはまりも悪い(正規の QQ は全科目で S 字) |
| B 区分線形近似 | 凸な区分線形(凸包)なら、線形計画・二次計画に落ちる。ただし、最頻値の両側で凹なコスト(b < 1)の凸包は、最頻値から定義域の両端への直線になる。つまり、**増加側と減少側で傾きの違う L1 コスト(線形の重み)に退化する**。裾の重さの情報は失われ、傾きは推定した分布よりも、定義域の端(R の上限・下限)の決め方で決まる |
| C 非凸最適化 | 大域最適の保証がない。毎ステップの射影(現行)を非凸にすると、収束の検査(CLAUDE.md の規則)が難しくなる |

**提案: 生成への組み込みは見送る**(G の「実装可能性が確認できなければ見送る」に該当)。

- 凸性を保てるのは案 B だけである。
- 案 B では、分布が科目ごとの線形の重み(左右で傾きが違う)に退化し、点推定の重みと本質的に変わらない。
- 分布推定の成果は、**記述統計**として報告する:
  - 科目別の分布族(裾の重い t・Subbotin、b ≈ 0.5、裾を除けば b ≈ 1)
  - 増減の偏り
  - 純資産の科目の「動かない」質量
  - 困窮企業での変化の大きさ
- **生成に使うとすれば、凸性と両立する形は次の 2 つ**(実装はしない):
  - 「動かない」点質量: 科目ごとに Δ = 0 を優先する、L1 の項
  - 左右の傾きの違い: 非対称の L1

## 10. 想定と違った点

1. **b は Laplace(≈ 1)より小さい**(全件の中央値 0.55)。b ≈ 1 になるのは外れ値を除いた後だけで、外れ値の扱いで結論が変わる。
2. **Laplace や対数正規でも、Δ について凸にならない**。log の凹性のため、増加側で崩れる。b の値だけでは凸性は決まらない。
3. **凸化すると、分布は線形の重みに退化する**(案 B)。分布推定の利点を生成に持ち込む経路が見つからなかった。
4. **唯一 b > 1 だった科目(固定資産その他)は、丸め差の残余だった**。4 つの残余科目は丸め差が主で、変化率の分布は解釈できない。
5. **総資産での正規化は、名目額が動かない科目の g を負に偏らせる**(資本金など)。非対称性の頻度の一部はこの効果である。
6. **運転資本に「動かない」質量はほぼない**。動かないのは、純資産の科目と社債。
7. **外れ値は多くの組に含まれる**。
   - いずれかの科目で外れ値になる組は 56%(6,107 / 10,971、`outliers.md`)。
   - 外れ値を含む組の特徴:
     - 規模が小さい(前期総資産の中央値: log10 で 10.31 対 10.61)。
     - 困窮企業の割合が約 2 倍(class 1・2 の合計: 4.4% 対 1.9%)。
     - 総資産の変化が大きい(\|log 比\| の中央値: 0.074 対 0.054)。
   - 総資産が 2 倍以上・半分以下に変わった組は、ほぼすべて外れ値を含む組に入る(1.5% 対 0.0%)。
8. **凸性の判定を一度誤った**(格子が log R について等間隔だった)。理論値で確かめて直した。
