## 0. 停止規則

> 残余に下限を課した細分化が、class 1・class 2 の両方で core (32) に対して主指標で勝てなければ、
> **細分化を不採用として確定し、canonical の探索を終了する。**

- 「勝つ」= 主指標の 2 つ以上で有意に優れ、有意に劣るものがない(ステージ32 と同じ)。
- 主指標: 純資産の改善 ↑、\|総資産変化\| ↓、実データとの符号付き順位相関 ↑。
  **債務超過の解消率は主指標に含めない**(ステージ39 と違う。スペックの定義に従う)。参考として出す。
- 有意: 企業単位のペア(seed の中央値)の差の中央値の 95% ブートストラップ区間が 0 を含まない。
  順位相関の差は企業を同時に復元抽出(1,000 回、seed 0)した 95% 区間。
- 順位相関は D をまたぐので、**共通の 32 科目への集約で判定する**(ステージ39 と同じ)。各 D の科目での値は参考。
  実データは、class 2 が回復 15 社の 2 年、class 1 が class 1 → class 0 の 1 年の遷移 68 組(ステージ39 と同じ)。
- **必須条件: 14 項目の違反 0**(設定ごと・class ごと。外れ値 3 社を除く 55 社・131 社で数える)。
  満たさない設定は、主指標によらず採用しない。

### 判定の手順

1. **設定 2 − 1**(細分化・下限あり・等重み 対 core)で判定する。両 class で勝ち、必須条件を満たせば細分化を採用。
2. **設定 3 − 1**(細分化・下限あり・持続性 対 core)も同じ規則で判定する。設定 2 が勝たず設定 3 が両 class で
   勝てば、「細分化 + 持続性の重み」として採用する(ステージ39 で細分化の中では持続性が等重みに勝ったため)。
   比較が 2 つあることは報告で明記する。両方勝った場合は設定 2 を採る(仮定が少ない)。ただし 3 − 2 も
   両 class で勝つなら設定 3。
3. どちらも両 class で勝たなければ、**不採用で確定し、canonical の探索を終了する**。

## A.4 「始点 0 → 正」は必須のチェックにしない

実データでも起きる(class 1・2 の 2 年で、土地 8%、建物 17%、機械 7%、建設仮勘定 10%、繰延税金資産 21%)。
行ごとの規則では、正当な出現と区別できない。**診断として科目別の割合を実データと並べて報告する**(B.4)。
判定には使わない。core でも起きている(有形固定資産 0 → 正: class 1 の 81%、自己株式 0 → 負: 79〜95%。
実データは 0〜7%)。
