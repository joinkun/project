## 判定基準

- **符号付き順位相関**: 32 科目について、生成の Δx/A の中央値(企業ごとに seed の中央値)と実データの中央値の
  Spearman 相関。区間は生成の企業を復元抽出したブートストラップ(1,000 回、seed 0)。比較は同じ企業を
  同時に抽出した差で行う。
- **基準値**: T1 は単一遷移(最終設定、class 2 → class 0、55 社)を T1 の実データと比べた値。T2 はステージ36 の
  class 1 始点・等重み(class 2 で学習)を T2 の実データと比べた値。連結は単一遷移を 2 年の回復 15 社と比べた値。

### D.1 段階分割の採否(setting 1 = 等重みで判定)

1. 13 項目の違反 0(T1・連結は 55 社、T2 は 131 社)
2. **符号付き順位相関が基準値より高い**(差の 95% 区間が 0 を超える)。T1・T2 の両方で
3. 連結の純資産の改善と \|総資産変化\| が、単一遷移より有意に劣らない(55 社のペア比較)
4. B.4 の仮説が実データで支持される → **生成の前の確認で「一部のみ支持」だった**(`real_transitions.md`)。
   T1 の資産売却・T2 の設備回復は支持されない。4 は満たさない

2 を最重要とする。1〜3 を満たせば段階分割を採用候補とし、4 を満たさないことは限界として書く。

### D.2 重みの作用点の採否(setting 2〜5 を setting 1 と比べる)

主指標 = 純資産の改善 ↑、\|総資産変化\| ↓、符号付き順位相関 ↑(T1 は債務超過の解消率 ↑ も)。
**T1・T2 の両方で**、主指標の 2 つ以上で有意に優れ、有意に劣るものがない設定だけを採用候補とする。
片方だけの優位は採用しない(ステージ36)。複数あれば純資産の改善で選ぶ。

### D.3 数値条件

射影の重み比の最大、ステージ10.6 の最適性の検定(違反 0 が必要)、速度場の損失の勾配の数値検証
(相対誤差 1e-4 未満が必要)、実行不可能の件数を報告する。最適性の違反か勾配の破綻があれば、その設定は
判定から除く。
