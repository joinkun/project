## A.2 下限の決定

- **α = 0.0019850022055580064**(案 1: 減少した組の比の 1 パーセンタイル)。
- 母集団: 推定用パネル(1 年)で、始点の年度のラベルが class 1・2 で、前期末の資本金が正で当期末に減った **46 組**。
  生成の始点が class 1・2 なので、この母集団を使う。
- 案 2(最小値)を採らない理由: 1 年の母集団の最小は 0 で(メタプラネット、2024 年度の連結 BS の資本金が 0。書類上の値)、
  下限が 0 になり意味を持たない。
- この 1 パーセンタイルは、最小の 0 と 2 番目の 0.0044 の間の補間で決まる(46 組の 1% は 1 組に満たない)。0 の 1 件を
  除けば p1 は約 0.0044 になる。事前に決めた規則どおり、除かずに 0.00199 を使う。
- 参考: 全組(3 遷移、295 組)の p1 は 0.0013、class 1・2 の 2 年(35 社)の最小は 0.0052。
- **対象は資本金だけ**(資本剰余金には下限を課さない。ステージ45 と同じ)。分布を測ったのは資本金で、資本剰余金は欠損填補に
  使われる経路なので。ステージ43 以前の α = 0.5 は資本金と資本剰余金の両方に課していた(設定 3 はそれを再現する)。
- 期間の違い: 下限は 1 年の比から決めたが、生成は 5 年。複数年の減資を重ねると、実際の 5 年の比はさらに小さくなりうる。
- **見込み**: α = 0.00199 は 0.01 より小さいので、「始点の 1% 未満まで減らす」企業の割合は、α = 0 から大きくは減らない
  可能性がある(下限で止まる位置が 0 から 0.2% に変わるだけ)。値は結果を見て変えない。

## B.3 判定(設定 2 を採用する条件。すべて満たすとき)

1. 15 項目の違反 0(両 class)。
2. **減資の深さが実データに近づく**: 「資本金を半減させた企業の割合」と「始点の 1% 未満まで減らした企業の割合」の、
   実データ(class 1・2 の 2 年、171 社: 18.1%、2.3%)との絶対差が、両方とも設定 1 より大きくならず、
   かつ「1% 未満」の差が設定 1 より小さい(両 class)。企業は 3 seed の 2/3 以上で数える。
3. 主指標(純資産の改善、債務超過の解消率、\|総資産変化\|、sparsity)が、設定 1 に対して有意に悪化しない
   (企業単位のペア、差の中央値の 95% ブートストラップ区間)。

満たさなければ設定 1(α = 0)のまま。設定 3 は参考(ステージ44 の判定の循環とステージ45 の行き過ぎの経緯を報告に残す)。

## チェック 8 の扱い

下限を課す場合も、**資本金の下限のチェックは追加しない**(チェック 8 は自己株式の上限のまま、総数 15)。
制約は射影で保証されるので、同じ条件のチェックは、ステージ44 で問題になった循環(課したものを検出する)になる。
資本金の非負は第 1 層の符号制約とチェック 12 で検出する。
