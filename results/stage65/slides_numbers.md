最終設定:
- 対応先は、不均衡 OT(τ0 = ∞、τ1 = 0.01、ε = 0.001)の最大質量の対応先。
- 第 1 項の重みは払込資本 m = 10、移動コストは非対称 L1。
- 制約は第 2 層 + 現金の下限 0.117。

評価対象は class 2 55 社、class 1 128 社(生成の始点は 132 社)。

## 主張 1: 会計恒等式だけでは成立しない

- 第 1 層(恒等式・符号)のみで、**67 / 68 社(98.5%)** が 15 項目のどれかに違反(ステージ27、Flow Matching の生成)
- 本ステージの QP でも、第 1 層のみ(提案の目標・λ)で違反は **class 2 で 6 社、class 1 で 16 社**(λ̃ = 1、class 1 で較正。class 2 の旧値 11 社は λ̃ = 0.1 のリークで、ステージ68 で訂正)
  - 例: 純資産の悪化(項目 6)、不活性科目が動いた(項目 15)、小計が負(項目 2)
  - λ̃ = 3 では、総資産が負(−0.15)の企業が出る(項目 1)
- 提案(第 2 層 + 現金の下限)の違反: **0 / 0**

## 主張 2: 既存の L2 距離は払込資本に支配される(スライド21・22)

- 払込資本(資本金 + 資本剰余金)の寄与率: **54.5%**(1 科目あたり、他の 27 科目の平均の **16.1 倍**)
- 払込資本 / 総資産の中央値: class 2 **1.144**、class 1 0.489、class 0 **0.133**
- 等重み L2 の最近傍の対応先: 0.820(class 0 の中央値の 6 倍)

## 主張 4: 第 1 項の重みが払込資本を制御する(図 2: `figures/fig2_m_saturation.png`)

λ̃ = 3 で、払込資本の m を 1 → 3 → 10 → 30 にしたときの、払込資本を減らした企業の割合:

| | m = 1 | 3 | 10 | 30 |
|---|---:|---:|---:|---:|
| class 2 等重み L2 | 42% | 29% | 24% | 24% |
| class 2 非対称 L1 | 16% | 5% | 2% | 2% |
| class 1 非対称 L1 | 12% | 4% | 3% | 3% |

- m ≥ 10 で飽和する。純資産の改善は悪化しない(class 2 非対称 L1: 0.121 → 0.152)
- 第 2 項(移動コストの重み)では制御できなかった:
  - 再建群の変化量の重み(ステージ57): 82% → 91〜100%
  - 群内分散の重み(ステージ58): 98〜100%
  - 方向別の重み(ステージ59): 資本金の c−/c+ = 0.36(減らすほうが安い)
- **事後選択**: 6 設計から結果を見て選んだ。class 1 の 2 分割の検証の成立 54%
- **事後選択なし(m = 1)との並記(ステージ68、`results/stage69/paper_tables.md` 表 3)**: λ を class 1 で較正すると、m = 1 では λ̃*_0 = 3 が選ばれ、払込資本を減らした割合は class 2 で 16%、class 1 で 12% に収まる(実データ 36% / 23%)。ただし純資産の改善は 0.096 / 0.123 で、m = 10(0.270 / 0.165)より有意に低い(差 −0.142 [−0.183, −0.104] / −0.029 [−0.044, −0.016])。m = 10 の役割は、払込資本だけを抑えて小さい λ̃(= 1)を使えるようにし、純資産の改善を確保すること。上の表(λ̃ = 3 に固定)は、この較正の前の比較

## 主張 6: 重心は実データと区別できる(図 4: `figures/fig4_auc.png`)

| 目標 | 識別 AUC(class 2 / class 1) |
|---|---|
| 実在企業の無作為抽出 | 0.47 |
| **提案(不均衡 OT の argmax、実在企業)** | **0.71 / 0.69** |
| 等重み L2 の最近傍 | 0.85 / 0.75 |
| 無作為な 2 社の平均 | 0.92 |
| **バランス OT の重心** | **0.995 / 0.999** |

- 原因はゼロの構造: 未払金がゼロの企業は、実データで 40%、2 社の平均で 16%(10,000 組。独立なら 0.40² = 16%。ステージ61 の 500 組では 14% で、ステージ69 で差し替え)。ちょうど 0 の科目数は、実在企業の平均 6.70 → 2 社の平均 3.24 → 重心 0.00(命題 2、`results/stage69/verify.md`)。ゼロかどうかだけで AUC 0.86〜0.89
- 重心の AUC 0.995 / 0.999 は LightGBM。ロジスティック回帰では 0.589 / 0.599(木のモデルが「ちょうど 0」で見分ける)
- 生成の主指標(純資産の改善)では、重心は**両 class で提案より有意に劣る**: class 2 で 0.147 対 0.270(差 −0.097 [−0.134, −0.054])、class 1 で −0.051。いずれも手法ごとに class 1 で較正した λ(ステージ68 で訂正。旧値の「class 2 で劣らず(0.394 対 0.327)」はリーク)。根拠は「到達点が実在しない」こと

## 主張 8: 下方硬直性の向きは代表値に依存する(スライド15・42)

## 定理の但し書き(ステージ67 D.2、`results/stage67/start_feasibility.md`)

- 定理(F_i が凸で x_i, y_i ∈ F_i なら、線形補間 z(t) = (1 − t) x_i + t y_i は全時刻で F_i に入る)の前提 **x_i ∈ F_i は、始点の丸め誤差を除いて成立する**。
- 貸借一致の残差が総資産比 1e-6 を超える始点: **class 2 で 13 / 55 社、class 1 で 18 / 132 社**(最大 4.9e-4)。符号の違反は 0。
  - 終点 y_i は Cᵀy_i = 0 を満たすので、補間の残差は Cᵀz(t) = (1 − t) Cᵀx_i で、始点の残差から線形に 0 へ減る。
- 第 2 層の制約を始点で満たさない企業: **各 1 社**(有形固定資産が負で、保持の制約 PPE ≥ 0.3 × 始点 に反する)。
  - 線形なので、違反は t < t* の区間だけ。t ≥ t* では満たす。
- 論文の記述: 「x_i ∈ F_i は、データの丸め誤差(総資産比 5e-4 以下)と、有形固定資産が負の 1 社を除いて成立する」と但し書きを付ける。
