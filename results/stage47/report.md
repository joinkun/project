### 判定の訂正(A.1)

ステージ46 の事前の基準では不採用だったが、**基準の設計が不完全であった**。基準 2 で使った「半減」「1% 未満」の割合は、
下限を 0.2% に置いた時点で変わりようがない(0.2% も 1% 未満に含まれる)。この指標では α の効果を原理的に測れない。
測れる指標(資本金を 0 にした企業)では、α = 0 の 22% / 16% が 0% / 0.8% になり、実データ(295 組中 1 件)に近い。
そのため、ステージ47 で α = 0.00199 を採用した。

## 4. E 記述案

### E.1 資本金の下限

> 資本金の下限を実データの分布から決めた(class 1+2 で資本金が減少した 46 組の比の 1 パーセンタイル、0.00199)。
> これにより資本金が完全にゼロになる出力は 22% から 0% に減ったが、下限ちょうどで止まる企業が多く、実務的には依然として
> 資本金がほぼ消失する経路が生成される(class 2 で 22%、class 1 で 16% の企業が資本金を始点の 1% 未満まで減らす)。
> 実データでは資本金を 1% 未満まで減らす企業は 2.3% である。
>
> 生成の分布を実データに合わせるには下限 0.01 程度が必要だが、それは結果から逆算した値であり、実データの分布から機械的に
> 決めた 0.00199 とは根拠の質が異なる。両者の乖離は、生成が下限に張り付く性質による(資本金が 1% 未満の行は、class 2 で
> 35 行中 34 行、class 1 で 67 行すべてが下限ちょうど)。

### E.2 払込資本の限界

> 苦境企業は欠損を払込資本で支えているため払込資本比率が高い(class 2 の始点で中央値 1.14)。最近傍の目標は 0.82 であり、
> 76% の企業で目標のほうが低い。目標へ向かう経路は、多くの企業で払込資本を減らす方向になる。実際の再建企業は、class 2 の
> 再建群で 60% が払込資本を増やす(増資)ため、生成される経路は実データと逆の方向を持つ。

スペックの案からの変更(数字に合わせた): 「必然的に払込資本を減らす」を「多くの企業で払込資本を減らす」とした。目標のほうが
払込資本比率の高い企業も 24% あり、すべての企業で必然とは言えないため。また 60% は class 2 の再建群(15 社)の値で、
class 1 → class 0 の 57 社では 25% である。目標の比率(0.82)は class 0 全体(0.13)よりはるかに高く、等重み最近傍は
払込資本比率の高い class 0 企業を選んでいる。

ステージ26(`results/stage26/report.md`)で同じ機構が指摘されている: 「GC 企業は欠損を払込資本で支えているため、払込資本の比率がもともと高い」「対応先の払込資本比率が始点より低ければ、経路は資本を減らす方向に動く」。当時の baseline(68 社)では対応先の方が高い社が 22%、今回(55 社、最終設定)は 24% で、整合する。ステージ26 では、旧コスト重み(資本金・資本剰余金の減少を重くする)だと対応先の方が高い社が 54% だった。

### E.3 制約設計の経緯(ステージ44〜47)

| 段階 | 判断 | 問題 |
|---|---|---|
| 44 | α = 0.5 を残す | 判定が循環していた(チェック 8 が制約 (5) とほぼ同じ条件) |
| 45 | α = 0 に外す | 行き過ぎた(資本金 0 が 22%) |
| 46 | 実データから 0.00199 を導出 | 事前の基準(半減・1% 未満)では効果を測れなかった |
| 47 | 採用 | 下限に張り付く問題は残る |

教訓:

- 制約は「あり / なし」の二択ではなく、**値の選択が重要**である。
- 値を機械的に決めても、**何で評価するかで結論が変わる**。評価の指標が、その値の効果を原理的に測れるかを事前に確かめる必要がある。
- **制約として課したものをチェックで検出すると循環する**。資本金の下限のチェックは置かない(チェック 8 は自己株式の上限、総数 15)。

## 5. 想定と違った点

1. 下限は主指標を全く変えなかった(すべて差の中央値 0)。変わるのは資本金の行き先だけ。
2. R1 でも資本金が下限に張り付く(ソフトフロント 0.044 百万円)。
3. 実際の再建群(class 2 → 注記なし)では、資本金を 1% 未満まで減らした企業は 0 / 14 社。苦境企業全体(171 社)の 2.3% より少ない。
4. class 1 では、保有企業の自己株式の増加が 66%(再建群 5%)と大きく残る。自己株式の上限は、分配可能額の代理が正の企業では効かない。
5. R1 の class 1 の順位相関が −0.291 → −0.307 に動いた(差の区間 [−0.015, +0.015])。
6. 会社法の条文(461 条、資本金の最低額)は確認していない。記述は実データの分布だけに依拠した。
7. 報告の初稿で「ステージ26 の結果はこのマシンになく照合していない」と書いたが、誤りだった。`results/stage26/report.md` に同じ機構の記述があり、照合して E.2 に反映した。
